## goal
The command switch and round settlement live in one file per domain, the season-close ledger gap is closed, the squad-investment dial stops multiplying wages, and engine texts write money in the app's notation.

## acceptance
- [v] `operate()` stays the entry point in operations.ts and dispatches to `ops-commercial.ts` (sponsors, campaigns, tickets, facilities, owner support, policy), `ops-squad.ts` (bids, offers, stances, lineup, training, academy, care, contract talks) and `ops-staff.ts` (managers, coaches, coaching, delegation, manager rule). `settleRound` moves to `settlement.ts`. Behaviour is unchanged and existing tests pass.
- [v] Season close: staff renewals and hires (`seasonStaff`) are booked to the new season, so the 이전·기타 장부 line holds nothing a current rule produces (→ECON-10). finance.test.ts covers delegated coach renewal at the close.
- [v] policy.ts: the support dial no longer multiplies wages; it exposes the pay ceiling ×0.9/1/1.1/1.25/1.4 and goodwill −5/0/+5/+10/+15% for contract talks (→ECON-16). Development and recovery stay. finance.ts drops the wage multiplier.
- [v] Engine texts write amounts through `moneyLabel`, which uses the WEB-67 notation (expected strings below). No event, inbox or news text shows raw minor units: the known cases are in operations.ts, staff.ts and academy.ts.
- [v] moneyLabel test (EUR): 9,999,999 minor → €99,999; €100,000 → €100K; €123,456.78 → €123K; €1,234,567 → €1.23M; €12,345,678 → €12.3M; €999,999,999 → €999M; €1.5bn → €1.50B; −€1,500,000 → −€1.50M. For £sd: £12,345 → £12,345 and £1,234,567 → £1.23M.
- [v] `pnpm run typecheck && pnpm run test:unit` pass.

## impl notes
- The notation equals `compactMoney` in apps/web/src/ui/format.ts (whole units below 100,000, then three significant figures, rounded toward zero). T053 uses the same expected strings, so both sides agree without importing each other.
- Wages from older saves stay as they are; the multiplier removal changes no stored amount.
- Goldens change with the wage multiplier and texts; leave them to T062.
