# T944 Market-season harness: many short match-free runs counting moves, flows and tier levels
> st:todo | ssot:ARCH-30 ARCH-32 | base:ARCH@48 | dep:- | touches:scripts/market-seasons.ts scripts/lib/market-seasons.ts scripts/lib/market-seasons.test.ts scripts/lib/start-worlds.ts | lane:npc-market | explore:- | run:claude/sonnet@high

## goal
A scripts-only harness lives worlds for short spans (about five seasons) on the results-only path, many seeds in parallel, and reports transfer counts by type, window, reason and tier flow plus each division's strength, so the market and level work can be tuned by measurement.

## acceptance
- [v] `pnpm exec tsx scripts/market-seasons.ts --start fresh:1951 --burn-in 2 --seasons 2 --seeds 0..1 --jobs 2 --out <scratch>/smoke.json` completes and writes JSON holding, per run and season: paid/free/loan/loan-return move counts, per-club in and out percentiles (p50, p90, max, share with none), season-start XI players lost by fee, a from-tier × to-tier flow matrix per country plus a cross-country count, lower-division top-3 players moving up, releases vs renewals, retirements, youth intake count and mean potential per tier, per-tier mean club strength (LEAGUE-10's stored strength) and its maximum, mean academy level per tier, and books sums per tier (wages, income, cash). A merge (`--merge a.json b.json`) gives mean and spread per season.
- [v] Starts: `fresh:<year>` (historyWorld) refuses a burn-in under 2 and reports burn-in seasons separately; `lived:<year>` builds through liveHistory from 1930 once per seed and stores a gzipped snapshot via `scripts/lib/start-worlds.ts` under `.tmp/market-seasons/` keyed by measurementIdentity, seed and year with a sha256 check and an entry cap; `file:<path>` loads a snapshot. A round-trip unit test proves the stored world equals the canonical one.
- [v] `--config <json>` merges overrides into exported tunables (the pattern of scripts/persisted-world-read.ts:47-51 and scripts/calibrate-transfers.ts:66-71) and echoes the applied values; `--lucks K` reruns each seed with RESULTS_LUCK.season set per season (results-only.ts:65, precedent scripts/era-wage-spread.ts:284); `--jobs N` runs child processes that each load the engine once. Unit tests cover the pure aggregation on synthetic moves (`scripts/lib/market-seasons.test.ts`).
- [v] Task-tier checks pass through `vibe check --tier task`; no engine source changes.

## impl notes
- from review/market-levels-261118 F1
- Ownerless worlds already resolve fixtures through results-only (match.ts:266 → results-only.ts:219, measured 2.4–3.5 s a season; liveHistory 1930→1951 about 131 s, 776 MB). No table synthesiser and no engine seam: clubs nobody owns are the measurement target, and an owner world only when `--owner <club id>` is given (about 27 s a season, used sparingly).
- Observers: PLAYER_MOVE_FLOW.observe (npc-market.ts:275-282, called before the move so tiers, XI and wages are readable), FREE_AGENT_FLOW.observe (free-agents.ts:34), BOOK_COMPETITIONS.observe (books.ts:47). Moves: PlayerMove {year, day, from, to, fee, loan?} (contracts types.ts:1247); loan returns have to equal the parent club, free-agent signings come through movePerson with fee 0 (npc-continuity.ts:247-265). If the observer receives an optional reason argument (added by T945), count by it; otherwise infer and label reasons as inferred (seller: sell-down, surplus, blocked, expiring; buyer: short line, refill, upgrade) using exported functions only.
- Per season: `w.history.at(-1).standings`, tier change across the close for promotion, `club.books.seasons[0]`, mean `club.strength` and XI by country and tier (pattern persisted-world-read.ts:236-253), academy levels from the club's level fields.
- Fresh worlds make 0 moves in their first season (measured 261118), hence the burn-in rule. Do not use the shared world caches (`.git/haeram/worlds`, `node_modules/.cache/haeram-worlds`).
- Usage errors reuse the existing `naturalFootball.usage` message ID (AGENTS.md: reuse IDs); output JSON is machine data, not display copy.
- Wrap long runs in `caffeinate -ims` when run by hand; default `--jobs` = 7.

Heavy `lived:` runs and 8-seed 5-season reads were not run here (T945 measures); browser, build, integration and full suites are left to the shared final gate.
