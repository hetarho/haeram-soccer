## goal
Create one durable recruitment-owned mediation only for a real eligible financial disagreement.

## acceptance
- [ ] During an open market an unmet manager request has a suitable available candidate, the director actually opposes on an existing financial verdict, and no qualifying arrival has met the request: record one mediation with real participants/reasons.
- [ ] Same manager/target request/window cannot emit again after a shortlist refresh, new named candidate, read/close, daily processing or reload. A newly minted shortlist request ID must not defeat this key.
- [ ] No suitable candidate, a failed negotiation or owner refusal alone creates only an ordinary factual report. Closed windows and already-met requests create no new mediation.
- [ ] Direct recruitment produces an unresolved owner stopping decision in both time modes; delegated recruitment is routed to the automatic resolver rather than an extra owner stop.
- [ ] The pending-work preview/handover includes mediation; historical participants/reasons and outcome are retained beyond inbox eviction.
- [ ] mediation.test.ts covers each eligibility/exclusion condition, repeated refreshed requests, two independent targets, owner/delegated routing and changed manager identity.
