## impl notes
- `packages/contracts/src/manager-history.ts` owns `ManagerHistoryFacts`, tenure/outcome fact types, a structural attributed-match type and narrow validators. `manager-history-view.ts` owns `ManagerHistorySource`, `ManagerHistoryPage` and discriminated tenure/legacy-event view rows. Import existing base DTOs as types directly from their defining leaf; do not change or export through `contracts/src/index.ts` yet.
- `ManagerHistoryFacts` retains its tracking boundary, monotonic tenure serial, tenure rows and unique outcome attribution. A tenure carries its stable ID, manager ID, optional person ID, display name, interim flag, tracked-from date, optional exact appointed/ended dates, known-since year and recorded departure information. Allocate IDs from club plus serial without the simulation RNG.
- Outcome sources are discriminated `league-finish` by season/country/tier/group, `cup-title` by season/competition and `promotion` by season/club. Store the responsible tenure and settlement date, with structured from/to division for promotion. Read ranks/winners/names from the supplied authoritative source snapshots rather than persisting duplicate summary totals.
- `packages/engine/src/manager-history.ts` owns `createManagerHistoryFacts`, `recordManagerTenureChange`, `attributeManagerMatch` and `attributeManagerOutcome`, accepting the feature fact object plus explicit identity/date/result inputs. Match annotation returns a structural `MatchRecord & { managerTenure?: string }`; it does not require that field on the existing global MatchRecord yet. T306 supplies the World/settlement adapter.
- `manager-achievements.ts` owns `managerHistoryPage(source, cursor?)`. The source explicitly supplies optional feature facts, own club/current-manager identity, retained attributed matches, season results and personnel events; it is not a canonical World extension. Define `MANAGER_HISTORY_VIEW_CONFIG.pageSize` here as 20. Aggregate in one pass before slicing, using `regulation ?? score` and stable retained event-order keys.
