## goal
Record news and update record counters when facts settle.

## acceptance
- [ ] Introduce shared bounded, versioned contracts/schema for an optional news journal and its incremental record state; save packing/round-trip retains them. Older supported saves reconstruct once on writer activation; read-only inspection preserves disk. Unknown versions and malformed cursors fail explicitly.
- [ ] Generate each own-match headline and event headline once on settlement, using existing rules/thresholds/IDs; keep past text and names stable across later roster changes. Update career maxima, cross-season runs and player goal/debut state from new facts only. Preserve the prior-season record baselines used by existing rules.
- [ ] Preserve stored headlines across season rollover and emit table/honour items once; no duplicate items after repeated refresh, commands, save/reload or import. Seed legacy journals only from facts actually retained, without inventing missing detail.
- [ ] Pure reads of a maintained journal do not rescan archived matches/events. All progression paths (automatic, round, season, cups, playoffs) update the same state; saving and querying cannot change gameplay facts or RNG.
- [ ] Add small independent unit cases for new-only processing, thresholds/streaks across rollover, name snapshots, duplicate/reload safety, migration and malformed/unknown formats. Update existing news/host/persistence integration cases and hand their execution to the final coordinator gate; run affected units, typecheck/lint/format and build.

## impl notes
- Use a shared contracts leaf for journal items/state; engine news must not import browser adapters. Keep existing news builder logic as the semantic reference. Persist only numeric aggregates, stable IDs and compact journal entries, not World/MatchRecord graphs or closures.
- Wire updates at canonical mutation/settlement boundaries, including a flush before closing-season material is reduced and roster names change. A journal absent in hand-built/test worlds may use the legacy pure reader; production writer activation initializes it explicitly. Canonical read calls remain side-effect free.
- Journal indices/cursors refer to stable sources; old ledger events can have their amount/detail updated in place (settlement.book), so do not infer that every event is immutable. Financial non-news updates must not rewrite a published headline.
- Check news.ts context lifetime carefully: season-specific sets/maps/home-away state reset, career goals/appeared and all-competition runs continue, and record comparisons use the existing previous-season baseline. Reconstruct unavailable historical headlines conservatively and label coverage if needed.
- All original facts remain stored; do not prune history or alter economic/match rules to meet capacity. Do not take over T653–T672 or modify their acceptance. Reserve T669–T672 already used on origin/wip/ot03.
