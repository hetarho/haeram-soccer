# T720 move the web UI out of the flat `ui/` folder into Feature-Sliced layers
> st:todo | ssot:ARCH-3 ARCH-4 ARCH-6 ARCH-30 ARCH-32 | base:ARCH@32 | dep:- | touches:apps/web/src apps/web/AGENTS.md eslint.config.mjs scripts tests/config tests/e2e tests/fixtures vitest.config.ts

## goal
Every web UI module lives in an FSD layer (ARCH-3/4 r32): `apps/web/src/ui/` no longer exists, each slice is cohesive behind one `index.ts`, and ESLint enforces the layer direction, so a change and the code a session must read for it stay inside one folder. Behaviour, copy, chunk splitting and test coverage are unchanged — this is a move, not a rewrite.
