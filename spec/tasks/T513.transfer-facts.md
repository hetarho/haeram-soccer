# T513 Record own-club transfer facts and rank them
> st:todo | ssot:HIST-20 ECON-6 SAVE-24 WORLD-6 | base:HIST@18 | dep:T510 | touches:packages/engine/src/transfer-records.ts packages/engine/src/transfer-records.test.ts packages/engine/src/transfers.ts packages/engine/src/ops-squad.ts scripts/lib/architecture.test.ts | lane:transfer-records | explore:-

## goal
Every completed fee signing, sale and loan of ours leaves a transfer fact, and one engine read leaf ranks them, falling back to the older career's ledger entries.

## acceptance
- [v] New leaf `packages/engine/src/transfer-records.ts` (imports contracts only): `recordTransfer(w, fact)` creates `w.transfers ??= { ledgerBefore: w.events.length, facts: [] }` before pushing; `transferRanking(w, { direction, year? })` returns rows sorted by fee in today's money desc (ties: earlier date first), each `{ source: 'fact', fact } | { source: 'ledger', event, index }`.
- [v] Ledger fallback: events with index < `ledgerBefore` (all events when `w.transfers` is absent) of kind `transfer-in` (direction in) or `transfer-out` (direction out) with amount > 0; label is the event's title; no player/club link is derived (→SAVE-24).
- [v] Writers call `recordTransfer` just before their `addEvent`: transfers.ts `completeSigning` (direction in, loan from `bid.loan`, club `bid.club`) and `completeSale` (direction out, club `bid.club`); ops-squad.ts direct signing only when the cost is > 0 (fee or loan fee). Free agents (fee 0), the director's free-agent signing, releases and academy call-ups record nothing.
- [v] `person` from the player's `person` link when present; `currency` as the ledger stores it (`w.currency`); year/day from `careerDate(w)`-equivalent read in the leaf (no orchestration import).
- [v] Today's money: the leaf exports `inTodayMoney(w, amount, year)` = amount × quote(country, w.year) / quote(country, year), exactly ClubTrends' `inToday` (move its quote/ratio reads into the leaf or a leaf it may import); ClubTrends switches over in T514.
- [v] `scripts/lib/architecture.test.ts` leaf case lists `transfer-records`.
- [v] Tests in `transfer-records.test.ts`: "records a fee signing, a loan and a sale", "records nothing for a free agent", "ranks by today's money across seasons", "falls back to ledger entries before the first fact", "filters one season". Existing transfers/ops-squad unit tests pass.
- [v] Fast checks: typecheck, lint, format:check, unit tests of changed files.

## impl notes
- `ledgerBefore` makes the boundary exact without hooks at founding or load: a career that never recorded a fact has all its ledger entries as legacy, and new careers have none.
- If `quote`/`ratio` live in a non-leaf module, import them only if that module is already a leaf; otherwise place `inTodayMoney` beside them in an existing leaf (check `scripts/lib/ui-engine-exceptions.ts`) and re-export.
