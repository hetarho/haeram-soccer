# T774 record local Playwright traces without the screencast
> st:todo | ssot:ARCH-30 | base:ARCH@34 | dep:- | touches:playwright.config.ts | lane:gate-e2e-trace

## goal
Local journeys stop spending CPU on a trace filmstrip nobody reads unless a case fails, so the CPU-bound Chromium stage of the release gate gets faster, while CI's traces and every journey stay as they are.

## acceptance
- [ ] locally (not CI) `use.trace` is `retain-on-failure` without screenshots (DOM snapshots, network, console and sources kept); CI keeps `retain-on-failure` with screenshots
- [ ] no other config value changes: workers, scheduling, timeouts, `expect` timeouts, retries, reporters and projects byte-identical; `pnpm exec playwright test --list --project=chromium` lists the same 348 cases
- [ ] the resolved config is printed once for local and once with `CI=1` to show both trace settings
- [ ] `pnpm run typecheck`, `pnpm run lint`, `pnpm run format:check`; the journeys themselves are the release run's (ARCH-30)
