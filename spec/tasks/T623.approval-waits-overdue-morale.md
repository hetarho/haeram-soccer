# T623 Approval waiting days and overdue morale

## goal
An owner-held approval counts the settled days it waits (STAFF-48). After 7 it is overdue: the owner gets one notice, and each settled round costs squad morale 1 per overdue approval, at most 3 (CLUB-19). The counts persist with the save (SAVE-17).

## acceptance
- [ ] World `approvalWaits` (decision id → waiting days) is optional in types and schema with a bounded size, and absent when nothing waits; an older save without it loads and counts from 0 (schema unit test)
- [ ] at the start of each settled day — `stepDay` and `prepareRound` alike — every `pendingDecisions(w)` entry gains a day and entries no longer pending are dropped, so a delegated category's entries go; a world with nothing pending is unchanged (unit test, including the prepareRound/completeRound path)
- [ ] the day an approval reaches 7 waiting days, one inbox notice names it and its morale cost; there is no repeat while it stays overdue (unit test)
- [ ] `settleMorale` subtracts min(3, overdue approvals) on top of CLUB-19's other terms and changes nothing with none overdue (unit test)
- [ ] all-delegated worlds keep their results: existing golden and parity tests pass
- [ ] engine unit tier, typecheck, lint, format pass

## impl notes
- `pendingDecisions(w)` (stopping.ts) already lists exactly the owner-held, unanswered decisions with stable ids (`decisionId`, versioned per year or term). Counting by id means a new season's vacancy or renewal starts again from 0, and handing a category over drops its entries (→WEB-82).
- Count before the day's settlement: a decision arising during day D has 0 at its end and is overdue on D+7. The round's `settleMorale` (training.ts) then reads the same counts on both day paths.
- Keep the notice in the approval's own inbox kind and ref, so settling the request settles its notice the same way (e.g. contracts `settleTalkItems`). Add no new InboxItem kind.
- Older saves without morale keep CLUB-19's exception: overdue approvals create no morale for them.
- Calibration scripts and golden worlds delegate every responsibility, so nothing waits there.
