## impl notes
- Why streams: `pack` blanks `ownMatches` and rebuilds them from column streams, so any record field without a stream is silently lost. `world` (players, cups, europe fixtures, `discipline`, `Fixture.shootout` on cup/europe fixtures) is inline JSON and needs nothing — but `history[*].heat` would be large inline, so it gets its own stream.
- Stream design (design §14), all optional and written only when some match/season has the field, so old-shaped worlds pack exactly as before:
  - `matchIncidents`: per match a count in a counts stream, then `packBitColumns` rows of width 7: `[minute, added, side, kindIndex, playerRef, otherRef+1 (0 = none), reasonIndex+1 (0 = none)]`. Player refs use the packer's shared string dictionary (find how `pack()` turns club/fixture ids into dictionary indexes and reuse that function).
  - `matchExtras`: per match one row `[flags, lc0, lc1, a0, a1, a2, a3, regH, regA, soH, soA]` with a bit flag per present field (bit0 lineCounts, bit1 added, bit2 added has 4 entries, bit3 regulation, bit4 shootout); absent values 0.
  - `matchMaterial`: per match a flag; for flagged matches four length-prefixed integer arrays (`shots`, `heat`, `network`, `report`) packed with `packBitColumns` width 1 per array (or the file's LEB128 `integers` helper — use whichever the file already uses for variable-length int lists).
  - `seasonHeat`: per season a count of players, then rows `[playerRef, c0..c39]` (width 41) with `packBitColumns(..., 'planes')`.
- `unpack` reads each stream only when present and restores fields in the original key order expected by `canonical` (canonical sorts keys, so order does not matter, but absent fields must stay absent — never write `undefined` or empty arrays for missing fields).
- Bit columns allow widths 1–156 (`bitpacking.ts validateWidth`); all widths above fit.
- Test fixtures: build a world with `createWorld` (+ one `advanceRound`), push a synthetic own `MatchRecord` with all fields (copy an existing own match and add fields; use real player ids from `w.players`), add `heat` to a fake `history` entry; assert `canonical(unpack(pack(w))) === canonical(w)`.
