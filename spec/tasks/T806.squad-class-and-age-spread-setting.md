# T806 Squads with stars, regulars and a bench (behind a setting)

## goal
With a named setting on, a generated squad holds stars, regulars and a bench as real squads do — each generated player carries his own class and an age term, the starters' mean stays the club's strength — while the released flat draw stays the default until T808 measures the gate.

## acceptance
- [ ] a named setting `SQUAD_SPREAD` (`inForce: 'flat' | 'spread'`, default `flat`), following T784's setting pattern; with `flat` every generated squad, refill and potential is byte-identical to the released draw (unit case comparing both for several clubs, seeds and years)
- [ ] with `spread`, each generated player's level is the club's strength plus his class (symmetric, within ±6, drawn once from a stream keyed on his person id, so it is the same every season of his cohort) plus WORLD-6's age term (−7 at 18, −4 at 20, −1 at 22, 0 at 24–29, −1 at 31, −3 at 33, −5 at 35, linear between); bench places sit 3–8 below the starters' mean; then the starters are re-centred so their mean level equals the club's strength — the starters being the eleven the club actually fields (check whether unowned sides field `squad.slice(0, 11)` in match.ts or the XI `ratingOf`/`lineup` pick in world.ts, and re-centre on that eleven)
- [ ] with `spread`, potential headroom follows WORLD-6's table (10–35 at 20 or younger, narrowing linearly to 0–4 at 27 and older), clamped as today
- [ ] with `spread`, the squad's market cost the means level reads (`squadCostAt`, dynamics.ts about lines 65-74) stays within ±5% of the flat draw's for strengths 50, 60, 70, 80, 85, 90 and 95, by choosing the bench offset within 3–8 and the class spread within ±6; the chosen values are constants beside the setting and listed in the result with the measured ratio per strength
- [ ] unit cases with `spread`: the fielded eleven's mean OVR equals the club's strength within 0.5 for strengths 50–95 and all four tactics (where the attribute cap stops it, the case records the strength and the shortfall instead); the eleven's OVR standard deviation is at least 2.5; the bench mean is below the eleven's; players aged 20 or younger average below the eleven; generation stays deterministic
- [ ] the day-loop equivalence tests pass with the default `flat`: `pnpm exec vitest run --project integration packages/engine/src/calendar.progression-eng.test.ts packages/engine/src/season.test.ts packages/engine/src/full-model-throughput.test.ts`
- [ ] `pnpm run typecheck`, `pnpm run lint`, `pnpm run format:check`, `pnpm run validate:i18n`, `pnpm exec vitest run --project unit --changed "$HAERAM_DIFF_BASE" --passWithNoTests`
