# T265 The economy calibration reads the engine's income kinds and gate facts
> st:todo | ssot:ARCH-21 | base:ARCH@12 | dep:- | touches:packages/engine/src/finance.ts packages/engine/src/finance.test.ts packages/engine/src/settlement.ts packages/engine/src/settlement.test.ts scripts/calibrate-economy.ts | lane:engine-money | explore:-

## goal
scripts/calibrate-economy.ts classifies income with the engine's own table and reads gate attendance through a parser paired with the text that writes it, so a new income kind or reworded gate line cannot silently skew the ECON-29 and ECON-9 bands.

## acceptance
- [v] finance.ts exports `INCOME_KINDS` (the keys of the private `incomeKinds`, sponsor slots included) and `isIncomeKind(kind)` (a key of `incomeKinds` or a `sponsor:` kind); the private table itself and `incomeKinds`' labels stay as they are.
- [v] settlement.ts exports `gateDetail(attendance, scale, matchId)`, which `gate()` uses to write today's exact text, and `readGateDetail(detail)` returning `{ attendance, matchId }` or `undefined`.
- [v] calibrate-economy.ts drops its `INCOME_KINDS` copy and its `관중 (\d+)명` regex: `isIncome` is `isIncomeKind`, attendance comes from `readGateDetail`, and an unreadable gate event or an income kind its `sourceOf` maps to `other` (apart from `care:friendly`) ends the run with exit code 1 and the kind or event named.
- [v] Tests: `packages/engine/src/settlement.test.ts` (new) "gateDetail and readGateDetail round-trip with and without the league scale" and "gate() writes a detail readGateDetail reads"; `packages/engine/src/finance.test.ts` "isIncomeKind accepts every income kind and no expense kind".
- [v] Behaviour unchanged — existing tests pass (`pnpm exec vitest run packages/engine/src/finance packages/engine/src/fans packages/engine/src/coach-training packages/engine/src/settlement`, `pnpm run test:contract`), and `pnpm exec tsx scripts/calibrate-economy.ts --quick --seasons 3` prints the same income shares and attendance figures before and after (both outputs summarised in the result).
