- `stage/motion.ts`:
  ```ts
  export type Pace = 'walk' | 'jog' | 'run' | 'sprint';
  export interface Body { pos: [number, number]; vel: [number, number]; face: [number, number] }
  export function paceSpeed(pace: Pace, spec: PlayerSpec): number;
  /** One tick toward `target` at up to `speed` m/s; mutates `body`. */
  export function advanceBody(body: Body, target: Vec, speed: number, dt: number): void;
  export function timeToReach(body: Body, target: Vec, speed: number): number; // dist / speed + motion.reactTime
  ```
  - `advanceBody`: `d = dist(pos, target)`; wanted speed `= d < motion.arriveRadius ? 0 : min(speed, d / motion.arriveTime)`; wanted velocity `= norm(target - pos) * wanted speed`; `dv = wanted - vel`, its length capped at `(len(wanted) >= len(vel) ? motion.accel : motion.decel) * dt`; `vel += dv`; `pos += vel * dt`; when `len(vel) > 0.5`, `face = norm(vel)`.
- `stage/world.ts`:
  ```ts
  export interface Order {
    target: Vec | (() => Vec);
    pace: Pace;
    /** Upper bound in m/s on top of the pace. */
    speedCap?: number;
    /** Added to the pace's speed (the lunge allowance of T796). */
    boost?: number;
  }
  export interface Flight { from: Vec; to: Vec; t0: number; t1: number; apex: number }
  export interface BallState { pos: [number, number]; z: number; mode: BallMode; owner: number; flight?: Flight }
  export interface StageState {
    fixture: Fixture; beats: readonly Beat[];
    t: number; tickCount: number;
    bodies: Body[]; ball: BallState;
    team: TeamId; phase: Phase; beat: number; live: boolean;
    /** When possession last changed sides. */
    turnedAt: number;
    /** The presser closes to `shape.press.tight` during this beat. */
    tight: boolean;
    /** Dead-ball scenes: shapes read this point instead of the ball. */
    shapeBall?: Vec;
    orders: Map<number, Order>;
    score: [number, number];
    frames: Frame[]; events: StageEvent[];
  }
  export function createStage(script: Script): StageState;
  export function positionsOf(state: StageState): Vec[];
  /** Where player `index` goes without an order this tick. `snapshot` = `positionsOf(state)` taken once per tick. */
  export function defaultTarget(state: StageState, index: number, snapshot: readonly Vec[]): { target: Vec; pace: Pace };
  /** One tick: targets for all 22 from one snapshot, then everybody moves, the ball updates, a frame is recorded. */
  export function step(state: StageState): void;
  /** Steps until `done()` is true (checked before each step) or `maxSeconds` have passed. */
  export function runUntil(state: StageState, done: () => boolean, maxSeconds: number): void;
  export function pushEvent(state: StageState, event: Omit<StageEvent, 't' | 'beat' | 'team'> & { team?: TeamId }): void;
  ```
  - time: `tickCount += 1`, `t = Math.round(tickCount * tick * 1000) / 1000` (no accumulated float error).
  - `defaultTarget`: `ref = state.shapeBall ?? (ball.mode === 'flight' ? ball.flight.to : ball.pos)`; `base = nominalSpot({ fixture, ball: ref, team: state.team, phase: state.phase, positions: snapshot }, index)`.
    - a player of the team in possession, any keeper, or anyone while `state.live` is false → `base`.
    - defending team `D`: pressing is on when `toAttack(D, ref)[0] <= shape.press.from[style of D]`. Among `D`'s outfield players **without an order**, sorted by distance to `ref` (lower index first on ties), the first is the presser and the second the cover (computed once per tick per team; cache it in the tick). With `g = norm(ownGoal(D) - ref)`: presser → `ref + g * (state.tight ? press.tight : press.standoff)`, pace `sprint` when farther than `motion.pressSprintBeyond` from it, else `run`; cover → `ref + g * press.coverGap`, pace `run`.
    - every other defender (all of them when pressing is off): the nearest outfield opponent to `base` within `mark.radius` gives `m = opponentPos + norm(ownGoal(D) - opponentPos) * mark.goalSide`; a `DF`-line player takes `[base[0], lerp(base[1], m[1], mark.blend)]`, anyone else `lerp(base, m, mark.blend)`; nobody near → `base`.
    - pace for players without a special rule: `run` while `state.t - state.turnedAt < motion.transitionSeconds` or the target is farther than `motion.jogWithin`, else `jog`.
  - `step`: take the snapshot; for each player an order gives `target` (call it when it is a function) and `speed = min(paceSpeed(order.pace, spec) + (order.boost ?? 0), order.speedCap ?? Infinity)`, otherwise `defaultTarget` and `paceSpeed(pace, spec)`; clamp every target with `clampToPitch(target, -2)`; after all targets are known call `advanceBody` for everyone; advance the time; `updateBall`; record the frame.
  - frame: `{ t, ball: [x, y, z], owner, mode, team, phase, live, beat, p }` with every coordinate rounded to 2 decimals (`Math.round(v * 100) / 100`).
  - `pushEvent` fills `t = state.t`, `beat = state.beat`, `team = event.team ?? state.team`.
  - `createStage`: `t = 0`, `live = true`, `team`/`phase`/`beat` from `beats[0]`, `turnedAt = -Infinity`, the ball held by `beats[0].actor`; every player at his kick-off place: `a = toAttack(team, nominalSpot({ fixture, ball: CENTRE, team: kicking, phase: 'buildUp' }, i))`, then `a[0] = min(a[0], HALFWAY - stage.kickOff.halfMargin)`; a player of the side not kicking who is within `stage.kickOff.circle` of the centre gets `a[0] = HALFWAY - stage.kickOff.circle`; the kicker stands at attack `[HALFWAY - 0.3, 34]`; convert back with `toAttack`; `vel = [0, 0]`, `face` toward the opponents' goal. Record frame 0.
- `stage/ball.ts`: `flightTime(from, to, speed) = max(ball.minFlight, dist / speed)`; `startFlight(state, to, speed, loft): Flight` (from the ball's position now, `t0 = state.t`, `t1 = t0 + flightTime`, `apex = loft ? clamp(dist * ball.loftPerMetre, ball.loftMin, ball.loftMax) : 0`, mode `flight`, owner −1); `giveBall(state, index)` (mode `held`, owner set, flight cleared, position updated at once); `updateBall(state)`: `held` → `pos = ownerPos + ownerFace * ball.carryOffset`, `z = 0`; `flight` → `s = clamp((t - t0) / (t1 - t0), 0, 1)`, `pos = lerp(from, to, s)`, `z = 4 * apex * s * (1 - s)`; `loose`/`dead` → unchanged, `z = 0`.
- `stage/perform.ts`:
  ```ts
  export interface BeatContext { beat: Beat; next?: Beat }
  export type Handler = (state: StageState, ctx: BeatContext) => void;
  /** `shot` for a shot-like beat, `pass` for the other `PASS_KINDS`, else the kind; then `:` and the outcome. */
  export function handlerKey(beat: Beat): string;
  export const HANDLERS: Record<string, Handler>;
  export function setPossession(state: StageState, beat: Beat): void;
  export function ensureOwner(state: StageState, actor: number): void;
  export function performScript(script: Script, options?: { duration?: number }): Playback;
  ```
  - `setPossession`: when `beat.team !== state.team` set `turnedAt = state.t`; then `team`, `phase`, `beat = beat.index`, `tight = beat.reason === 'pressed'`.
  - `ensureOwner`: nothing when the actor already holds the ball. Otherwise set the ball `loose` (unless it is `dead`), order the actor to the ball (`target: () => ball position`, pace `sprint`), and `runUntil` he is within `stage.controlRange` (at most `stage.settleMax`), rolling a `loose` ball toward him by `ball.roll * tick` each tick (`approach`); then drop the order and `giveBall`.
  - `performScript`: `duration = options?.duration ?? PROTO_CONFIG.duration`; `state = createStage(script)`; for each beat in order while `state.t < duration`: look up `HANDLERS[handlerKey(beat)]` (throw `Error('no handler for ' + key)` when absent), call it with `{ beat, next: beats[i + 1] }`, call `step` once if it advanced no tick, and collect the beat as performed. Then keep the frames with `t <= duration`, the events with `t <= duration`, push a final `whistle` event at the last kept frame's time, and return `{ version: 1, seed, hz: PROTO_CONFIG.hz, duration: last kept frame's t, fixture, beats: performed, frames, events, score }` where `score` is the `score` of the last kept `goal` event (`[0, 0]` without one).
- `stage/pass.ts` — `performPass`, registered for `pass:complete` (all `PASS_KINDS`; T796 puts a dead-ball scene in front of restart kinds, T797 branches for `beat.through`):
  1. `setPossession`; `ensureOwner(actor)`; `R = clampToPitch(beat.to, 0.5)`; `speed = beat.loft ? ball.loft : ball.ground`.
  2. hold — orders: actor `{ target: () => actorPos + norm(R - actorPos) * stage.holdDrift, pace: 'walk' }` (he takes a touch toward his pass), receiver `{ target: R, pace: 'run' }`. `canKick = timeToReach(receiverBody, R, sprint speed of the receiver) <= flightTime(ball position, R, speed) + stage.receiveSlack`. `runUntil` (`held ≥ beat.hold` and `canKick`) or `held ≥ beat.hold + stage.maxExtraHold`.
  3. if still not `canKick`: `R = reachablePoint(...)` — start from `P = R` and repeat three times: `T = flightTime(ball, P, speed)`, `reach = max(0, T + stage.receiveSlack - motion.reactTime) * sprint * 0.9`, `P = approach(receiverPos, R, reach)`.
  4. kick: `pushEvent({ kind: 'kick', actor, other: receiver, at: ball position })`; `startFlight(state, R, speed, beat.loft)`; drop the actor's order; receiver order `{ target: R, pace: 'sprint' }`; `runUntil(state.t >= flight.t1)`.
  5. receive: `giveBall(state, receiver)`; `pushEvent({ kind: 'receive', actor, other: receiver, at: R })`; `state.orders.clear()`.
  - export `reachablePoint` and the hold/kick steps as small functions (`holdForPass`, `kickTo`) — T796 and T797 reuse them.
- `stage/carry.ts` — `performCarry`, registered for `carry:complete`: `setPossession`; `ensureOwner`; hold `beat.hold` seconds with the actor ordered to stand (`target: () => his own position`, pace `walk`); then order him `{ target: E, pace: 'sprint', speedCap: stage.dribbleSpeed }` with `E = clampToPitch(beat.to, 0.5)` and `runUntil` he is within `stage.arrive` of `E` (at most `dist / stage.dribbleSpeed * 1.5 + 2` seconds); `state.orders.clear()`. The ball follows him through `updateBall`.
