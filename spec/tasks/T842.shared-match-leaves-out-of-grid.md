## impl notes
- A move, not a rewrite: `git mv` where a whole file goes, a split where a file is half shared and half grid (`record.ts`: the layout, zones and `MaterialTally` go, the grid's `Tally` stays; `setup.ts`: the roster helpers go, `buildGridSetup` stays; `changes.ts`: policy and fatigue go, `planChanges`/`applyChanges` stay; `rules.ts`: `modelAtLeast` stays). The grid files import their former contents from `match/` so the grid still builds and its tests pass until T845.
- Config values: move the named values themselves (a value has one home); the grid's config object reads them from `match/`.
- The web imports through `match.ts` re-exports today (`MATCH_MOTION_CONFIG`, `matchdayRole`, `playerTendencies`) and directly (`FormationPitch.tsx` → `grid/playback`, `StrategyPanel.tsx` → `grid/setup`, the heat and material views → `grid/pitch`): point them at `match/` read leaves (→ARCH-4: a read leaf reaches no orchestration).
