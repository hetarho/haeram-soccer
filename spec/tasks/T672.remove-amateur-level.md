## impl notes
- Shared rules for every T653–T672 task (see T665).
- Takeover worlds already have no amateur club (`historyWorld` calls `generateClubs(seed, false)`) and `promote` skips a relegation with nothing to swap (`if (!entry) continue`), so the LEAGUE-16 behaviour exists; this task removes the dead paths and pins the rule with its test. Write the rule plainly: the last division's loop goes; the promotion/relegation loop between professional tiers stays as it is.
- `stature` ranks only professional ids after the change; reserve ids never ranked in its top seven (their key starts at the amateur tier × 0.35), so no professional club's stature moves.
- Packing tables keep the positions of the codes they keep: `'lower'` is the last entry of `matchModelPacking.ts` `KINDS`, so removing it shifts nothing; check every other table listing it before deleting, and keep a position reserved wherever removal would shift a later code.
- Saves: `World.lower` leaves the schema; the world schema strips unknown keys, so 0.8.0 checkpoints carrying `lower: false` keep loading (test). No 0.8.0 career holds a `'lower'` fixture (SAVE-26 reset every founded career).
