## goal
A pure module that maps any pitch point to its MATCH-14 cell, names it in Korean, gives the geometry the engine needs, and exposes the 40-cell real-data tables.

## acceptance
- [ ] `grid/pitch.ts` exports exactly the API below; `grid/baselines.ts` exports `CELL_BASELINES`, `POSITION_PROFILES`, `OVERALL_PROFILE`, `profileKey`.
- [ ] `grid/baselines.json` is a byte-identical copy of `docs/match-baselines-40.json`.
- [ ] `pitch.test.ts` cases: `maps every lane and band edge to the right cell` (each edge value goes to the higher cell, 105 and 68 go to the last), `names special cells as football media do` (아크 정면, 페널티 스폿 부근, 왼쪽 컷백 구역, 니어 포스트/파 포스트 by ball side, 박스 옆 측면, 코너 부근, plain `왼쪽 하프스페이스 박스 앞`), `mirrors points into the away side's attack frame`, `measures goal distance and the posts' angle` (penalty spot: 11 m, 0.642 rad ±0.001), `converts to playback units and mirrors the second half`, `knows the penalty box and goal area`.
- [ ] `baselines.test.ts` cases: `copies the documented baselines exactly` (compare file bytes with `docs/match-baselines-40.json`), `has 40 cells whose shares sum to 1 (±0.01)`, `maps every position to a profile`.
- [ ] No other module imports it yet; `pnpm run typecheck`, `pnpm run lint`, the two test files pass.

## impl notes
- API (`docs/MATCH-ENGINE-DESIGN.md` §1.1):
  ```ts
  export const PITCH = { length: 105, width: 68 } as const;
  export const LANE_EDGES = [0, 13.84, 24.84, 43.16, 54.16, 68] as const;
  export const BAND_EDGES = [0, 5.5, 16.5, 35, 52.5, 70, 88.5, 99.5, 105] as const;
  export const LANE_KEYS = ['leftWide','leftHalf','central','rightHalf','rightWide'] as const;
  export const BAND_KEYS = ['ownGoalArea','ownBox','defensiveThird','ownMiddle','oppMiddle','frontOfBox','box','goalArea'] as const;
  export type Lane = 0|1|2|3|4; export type Band = 0|1|2|3|4|5|6|7; export type Point = readonly [number, number];
  export function laneOf(y: number): Lane; export function bandOf(x: number): Band;
  export function cellOf(p: Point): number;            // band * 5 + lane
  export function cellLane(cell: number): Lane; export function cellBand(cell: number): Band;
  export function cellKey(cell: number): string;       // `${LANE_KEYS[l]}.${BAND_KEYS[b]}` — the JSON key
  export function cellName(cell: number, post?: 'near' | 'far'): string;
  export function attackFrame(side: 0 | 1, p: Point): Point;   // side 1: [105 − x, 68 − y]; self-inverse
  export function inBox(p: Point): boolean;            // x ≥ 88.5 && 13.84 ≤ y ≤ 54.16
  export function inGoalArea(p: Point): boolean;       // x ≥ 99.5 && 24.84 ≤ y ≤ 43.16
  export function goalDistance(p: Point): number;      // to (105, 34)
  export function goalAngle(p: Point): number;         // |atan2 to post (105,37.66) − atan2 to post (105,30.34)|
  export function distance(a: Point, b: Point): number;
  export function toUnits(p: Point, period: 1 | 2 | 3 | 4): [number, number]; // [x·100/105, y·100/68], periods 2 and 4 mirrored (100 − u)
  ```
  All points passed in are in the acting side's attack frame (y = 0 is that side's left touchline).
- Edges: `laneOf(y)` = the last i with `y >= LANE_EDGES[i]`, capped at 4; same for bands, capped at 7; clamp negatives to 0.
- `cellName` (MATCH-14):
  - lane names 왼쪽 측면, 왼쪽 하프스페이스, 중앙, 오른쪽 하프스페이스, 오른쪽 측면; band names 우리 골 에어리어, 우리 박스, 수비 지역, 우리 진영 중원, 상대 진영 중원, 박스 앞, 박스 안, 골 에어리어.
  - specials first: band 5 + central → `아크 정면`; band 6 + central → `페널티 스폿 부근`; band 7 + leftHalf/rightHalf → `왼쪽 컷백 구역`/`오른쪽 컷백 구역`; band 7 + central → `니어 포스트` when `post === 'near'`, `파 포스트` when `post === 'far'`, `골 에어리어` without `post`; band 6 or 7 + a wide lane → `왼쪽 박스 옆 측면`/`오른쪽 박스 옆 측면` (band 6) and `왼쪽 코너 부근`/`오른쪽 코너 부근` (band 7).
  - near/far is decided by the caller (commentary, T217): a point is at the near post when it is on the same side of y = 34 as the ball came from.
  - otherwise `${laneName} ${bandName}`.
- `baselines.ts`:
  ```ts
  import data from './baselines.json';
  export interface CellBaseline { share: number; pass: number; carry: number; takeOn: number; shot: number; clearance: number;
    crossOfPasses: number; passCompletion: number; forward: number; lateral: number; back: number; lostPer100: number;
    takeOnSuccess: number | null; goalPerShot: number | null; xgPerShot: number | null; shots: number; xT: number }
  export const CELL_BASELINES: readonly CellBaseline[];          // index = cellOf(...), built from data.cells[cellKey(i)]
  export type ProfileKey = 'GK'|'CB'|'FB'|'DM'|'CM'|'AM'|'W'|'ST';
  export interface PositionProfile { forward: number; lateral: number; back: number; passCompletion: number; longShare: number;
    crossShare: number; takeOnPerPass: number; takeOnSuccess: number; progressiveCarryPerPass: number; meanPassLengthYd: number }
  export const POSITION_PROFILES: Record<ProfileKey, PositionProfile>;   // data.positionProfiles.rows
  export const OVERALL_PROFILE = { forward: 0.355, lateral: 0.499, back: 0.145 } as const; // SB open play (MATCH-BASELINES §D)
  export function profileKey(position: Position): ProfileKey; // GK→GK; CB→CB; LB,RB,LWB,RWB→FB; DM→DM; CM→CM; AM→AM; LM,RM,LW,RW→W; ST→ST
  ```
  `resolveJsonModule` is on in tsconfig. Copy the JSON with `cp docs/match-baselines-40.json packages/engine/src/grid/baselines.json`.
