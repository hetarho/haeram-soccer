## impl notes
- Tune named configs only (`NPC_SQUAD`, `NPC_YOUTH`, `CLUB_LEVELS`, `NPC_MARKET`); a target unreachable by them is a rule change, not a code hack.
- The founding draw is one more knob: `SQUAD_SPREAD` at `flat` founds every place at the club's strength with 10–35 points of potential headroom at every age, which real development then spends in the 1930s; `spread` (→WORLD-6) founds classes, an age term and headroom narrowing with age. It changes only when WORLD-6's own gate reads as holding on these worlds; record the read either way.
- Order of work inside the timebox: division levels, then the champions spread, then squad shape, values and books; saves and throughput run once on the configs chosen. Start from T863's first viability read (`scripts/persisted-world-read.ts`).
- Reuse the existing calibration scripts under `scripts/` (champions spread, books, transfer values) on the new world; measure throughput with the paired harness of ARCH-34 (`scripts/season-throughput.ts`).
- `scripts/benchmark.ts` aborts a phase when its own closure changes mid-run: settle every edit before launching it, and run its phase chains in parallel.
- Run long measurements in a `.tmp` worktree with the heavy lock as other sessions do.
