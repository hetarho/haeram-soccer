## goal
Living a world-history season, which a new game does for every season from 1930 to the chosen decade, gets measurably faster on this host with byte-identical results, and the A/B harness can measure history seasons from now on.

## acceptance
- [v] `scripts/perf/workloads.ts` has a `history` workload: the world built once by `historyWorld(seed)` outside the timed reps; each rep lives one season the way `liveHistory` does; label `season`; digest `canonical(w)`; `ab.mjs` and `profile.mjs` carry its DEFAULTS; the header comment lists it
- [v] an A/A run `node scripts/perf/ab.mjs --base HEAD --workload history` reports `sameHash` true and an interval that contains 1 (the noise read)
- [v] `ovrAt`, `bestRoleAt`, `mainOvr` and `weightsFor` keep their exports and return identical values: weights looked up without building a string key, the same summation order over `ATTRIBUTES`, `mainOvr` taking the best role's value from the same pass, no array allocation per improvement, the first role kept when no role exceeds −Infinity
- [v] `node scripts/perf/ab.mjs --base <lane base> --workload history` reports `sameHash` true and an interval below 1 (ARCH-34), or the measured interval is recorded as is when it includes 1
- [v] `sameHash` true for `--workload day`, `aggregate` and `grid` against the lane base (grid and aggregate read these functions)
- [v] `pnpm exec vitest run packages/engine/src/player.test.ts packages/engine/src/world.test.ts packages/engine/src/history.test.ts packages/engine/src/generation-digest.test.ts`, `pnpm run typecheck`, `pnpm run lint`, `pnpm run format:check`
