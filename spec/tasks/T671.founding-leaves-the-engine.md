## impl notes
- Shared rules for every T653–T672 task (see T665); the amateur level's code stays for T672 — this task deletes only tests whose subject is the amateur level, since no world can reach it once `createWorld` is gone.
- `simulatedWorld`'s cache id keeps the shape `sim:${JSON.stringify(input)}:${seasons}:${rounds}:${JSON.stringify(release)}` over `CareerInput`; the fixture file's dependency list gains `career.testkit.ts`.
- e2e: a journey that compares a Node world with the browser's career builds it as the browser does — `generateHistory(seed, decade)` + `takeOver` with the journey's start choices (`tests/e2e/start.ts`); a Node world prepared and loaded into the browser as a checkpoint uses `careerWorld`. T664 named `owner-sheet`, `save-upgrade` and the imports; the rest are those `grep createWorld tests/e2e` lists.
- `scripts/`: measurement and probe scripts take `careerWorld`; the calibration scripts (`calibrate.ts`, `calibrate-economy.ts`, `calibrate-transfers.ts`) take `careerWorld` with tier `midsize` (ECON-29's reference reach) until T668 rebuilds the reference careers on generated worlds. Historical files under `artifacts/` are immutable records (→ARCH-33) and stay as they are; they are outside typecheck.
- `managerMarket.ts`'s fallback `[0, FOUNDING_YEAR]` for a club missing from the market's map becomes `[0, TAKEOVER_DECADES[0]]` from contracts `owner.ts` (history.ts's `HISTORY_START`, imported from contracts to avoid a cycle through `season.ts`); every generated world lists every club, so no world reaches it.
- `World.level` leaves `types.ts`, `schema.ts` (`level: z.enum(…)`), `historyWorld`, `world-market.testkit.ts`, `persistence.testkit.ts` and every test world literal; the world schema strips unknown keys, so stored 0.8.0 checkpoints keep loading (→SAVE-26: 0.7.0 careers are reset, never decoded).
- `Joined` 'founding' and `coverage: 'founding'` stay (stored values the takeover writes; T665's note).
