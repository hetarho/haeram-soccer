## goal
A pure function gives every player's nominal place from the ball, the team in possession and its phase, so the script generator (T793–T794) and the staging (T795–T797) read one table of role behaviour: the inverted full-back inside in build-up, the false nine off the line, the poacher on the last shoulder.

- Tables in `core/shape.ts`. An anchor is `[ax, ay]`: `ax` is the depth inside the team block (0 = back line, 1 = front line), `ay` metres from the pitch's long axis in the team's attack frame (negative = own left, toward `y = 0`). Index = slot; slot 0 (the keeper) is `null`.

- API:
  ```ts
  export interface ShapeContext {
    fixture: Fixture;
    /** Ball position, world frame. */
    ball: Vec;
    /** Team in possession. */
    team: TeamId;
    /** Phase of the team in possession. */
    phase: Phase;
    /** Current positions of all 22 by index (world frame); absent = read the defending line from the nominal block. */
    positions?: readonly Vec[];
  }
  /** A player's nominal place, world frame. */
  export function nominalSpot(ctx: ShapeContext, index: number): Vec;
  /** The offside line `attacking` plays against, as an x in `attacking`'s attack frame, from actual positions. */
  export function offsideLineX(fixture: Fixture, positions: readonly Vec[], attacking: TeamId): number;
  /** The same line read from the defending team's nominal block for this ball. */
  export function nominalLineX(ctx: Pick<ShapeContext, 'fixture' | 'ball'>, attacking: TeamId): number;
  /** `offsideLineX` when `ctx.positions` is given, else `nominalLineX`. */
  export function lineFor(ctx: ShapeContext, attacking: TeamId): number;
  ```
- `offsideLineX`: convert the 11 positions of the other team with `toAttack(attacking, pos)`, take the second largest x (the keeper counts), return `max(that, HALFWAY)`.
- Out-of-possession back line of team `d` for a ball: `b = toAttack(d, ball)`; `raw = clamp(oop.lineBase + oop.lineSlope * b[0] + oop.lineBias[style of d], oop.lineMin, oop.lineMax)`; `oopLine = min(raw, max(oop.lineMin, b[0] - oop.behindBall))` (the line never stands ahead of a ball played behind it). `nominalLineX(ctx, attacking) = max(HALFWAY, 105 - oopLine(other team))`.
- `nominalSpot(ctx, index)` for player `i` of team `T` (`[bx, by] = toAttack(T, ctx.ball)`; work in `T`'s attack frame and convert the result back with `toAttack(T, …)`):
  1. In possession (`T === ctx.team`): `lineX = clamp(ip.lineBase + ip.lineSlope * bx, ip.lineMin, ip.lineMax)`, `depth = clamp(ip.depthBase + ip.depthSlope * bx, ip.depthMin, ip.depthMax)`.
     - keeper (slot 0): `x = clamp(lineX - gap, keeper.minX, max)` with `gap = keeper.sweeperGap`, `max = keeper.sweeperMaxX` for role `sweeperKeeper`, else `keeper.gap` and `keeper.maxX`; `y = 34 + (by - 34) * keeper.lateral`. Return (no further clamps).
     - outfield: `[ax0, ay0] = FORMATIONS[formation].ip[slot]`; `o = ROLE_SHAPE[role]?.[phaseKey] ?? {}` (`phaseKey` per the table note); `ax = o.ax ?? ax0`; `ayAbs = o.ayAbs ?? Math.abs(ay0)`; `side = ay0 !== 0 ? Math.sign(ay0) : o.ayAbs !== undefined ? (by >= 34 ? 1 : -1) : 0`.
     - `line = lineFor(ctx, T)`.
     - role with `onShoulder`: `x = line - shape.shoulderGap`, `y = 34 + ay0 + clamp((by - 34) * shape.poacherLean, -shape.poacherMaxLean, shape.poacherMaxLean)`.
     - otherwise `x = lineX + ax * depth`, `y = 34 + side * ayAbs + (by - 34) * ip.lateral`.
     - then for every outfield player in possession, the poacher excepted: `x = min(x, line - shape.onsideGap)`.
  2. Out of possession:
     - keeper: `d = dist([bx, by], [0, 34])`; `out = clamp(keeper.base + keeper.perMetre * d, keeper.minOut, keeper.maxOut)`; the point `out` metres from `[0, 34]` toward the ball (`[0 + bx / d * out, 34 + (by - 34) / d * out]`; with `d = 0` use `[keeper.minOut, 34]`). Return.
     - outfield: `[ax0, ay0] = FORMATIONS[formation].oop[slot]`; `x = oopLine(T) + ax0 * oop.depth[style]`; `y = 34 + ay0 * oop.width + (by - 34) * oop.lateral`. Role overrides do not apply out of possession.
  3. Outfield only: clamp `x` to `[PROTO_CONFIG.margin, 105 - PROTO_CONFIG.margin]` and `y` to `[PROTO_CONFIG.margin, 68 - PROTO_CONFIG.margin]`.
- Reference values to check the implementation by hand (attack frame of the team named, one decimal): home in possession, `buildUp`, ball `[20, 34]`: slot 1 `(32.4, 25.0)`, slot 5 `(32.4, 34.0)`, slot 9 `(46.3, 34.0)`, slot 0 `(12.4, 34.0)`; home in possession, `finalThird`, ball `[85, 50]`: slot 2 `(56.2, 27.4)`, slot 4 `(85.9, 66.4)`, slot 1 `(67.3, 28.4)`; away out of possession for that ball: slots 1–4 at attack x `11.0`, slots 5–8 at `23.5`.
