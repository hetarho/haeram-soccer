## goal
Match and season heat maps read as smooth hot spots on one continuous colour ramp, drawn with the browser's 2D canvas and no new dependency.

## acceptance
- [ ] New pure module `heatPaint.ts`: `heatField(cells, width, height)` returns a Float32Array intensity field (0–1, scaled to its own maximum) by summing a Gaussian per cell at its centre in pitch coordinates (`HEAT_CONFIG.sigma` in cell widths, default 0.75; cell geometry from materialView's band/lane edges), and `heatColour(v)` maps 0–1 onto `HEAT_CONFIG.ramp` (transparent → blue → cyan → green → yellow → red) with alpha rising from 0 below `HEAT_CONFIG.floor`.
- [ ] `paintHeat(canvas, cells)` writes the field with `putImageData` on an offscreen canvas at `HEAT_CONFIG.resolution` (default 190×100) and returns a data URL; the same cells always give the same pixels (no randomness, no animation).
- [ ] New `HeatPitch.tsx` shows a heat map as an `<image>` layer inside the existing material pitch SVG under the markings; MatchMaterial's heat tab uses it instead of the per-cell `<rect>`s, keeping cell names on tap and the 1.9:1 ratio.
- [ ] PlayerSheetDialog's `HeatGrid` is replaced by the same pitch heat view (attack to the right, same aria label text with total touches); season selector unchanged.
- [ ] Without a canvas (jsdom/old browser) the view falls back to the current cell shading so nothing breaks.
- [ ] An accessible text summary stays (aria-label with total touches and the busiest cell's name); theme pitch colours stay.
- [ ] Tests in `heatPaint.test.ts`: "peaks at the busiest cell", "is zero-alpha where nothing happened", "scales to the map's own maximum", "ramp runs blue to red monotonically in hue", "is deterministic".
- [ ] No new package in package.json. Fast checks: typecheck, lint, format:check, unit tests of changed files, `pnpm run build`.

## impl notes
- Canvas 2D + Gaussian splat is the standard broadcast heat-map technique (as simpleheat/heatmap.js do); 40 cells × 19,000 pixels is trivial on the CPU, so WebGL adds nothing but risk.
- Memoise the data URL per cells array (useMemo) so tab switches never repaint.
- Browser journeys covering the material heat tab and the player sheet (`data-testid="player-heat"`) may need selector updates; list them under result limits for the batch.
