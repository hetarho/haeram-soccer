## goal
Show the automatic pairing in preparation and let the owner explicitly choose home/away/third for that named fixture.

## acceptance
- [v] Preparation displays actual fixture context, both shirt designs, automatic keepers and the unrestricted automatic recommendation.
- [v] Selecting a radio/role updates only a local preview; confirm submits one match-kit command and automatic submits a null role. Saved shirt designs do not change.
- [v] club-identity-preparation.spec.ts cases own home and own away roles map to the correct side, warned manual clash can be confirmed, automatic restores selection, and a fixture change cannot receive a stale choice pass.
- [v] Persisted selection survives reload before that fixture and is consumed only by that fixture’s settlement; future fixtures use automatic selection again.
- [v] Readonly, missing fixture and settled/historical preparation do not expose an effective kit-changing action.
- [v] Skipping preparation and disabling the match-eve stop still permit automatic watching/play-through without an extra acknowledgement; tactic/lineup actions remain independent.
- [v] Targeted verification passes: `pnpm run typecheck && pnpm run build`; `tests/e2e/club-identity-preparation.spec.ts` and `tests/e2e/match-core.spec.ts` are written or updated here and confirmed by the batch Chromium run before the push (ARCH-30), named in `- limits:`.

## impl notes
- Read `docs/CLUB-IDENTITY-CONTRACT.md` sections named below; it owns the stable interfaces used in this task.
- Prerequisites: T241, T249. Read their implemented interfaces/results before editing; extend those modules rather than reproducing a prerequisite.
- Read design §§4–5 and 7. Mount FixtureKitSelector in the real StrategyPanel after client.whenIdle resolves current preparation data. Use nextOwnFixture across competitions.
- Keep selected role and confirm state separate from existing tactic/lineup drafts. Do not route this through a tactics request or manager consent.
- Force the actual own side in selectMatchKits, derive warnings and render the passive KitPitchPreview. Compute recommendation without that force.
- Capture the fixture ID being previewed in the payload; after any stale error refresh the context and retain/clearly reset the preview rather than confirming against a new fixture invisibly.
- Use seeded real fixture/import helpers for league/cup/Europe coverage; do not install a new public progression shortcut solely to reach a test fixture.
