# T801 remember each file's import list for world-cache keys
> st:todo | ssot:ARCH-21 | base:ARCH@38 | dep:- | touches:scripts/lib/source-graph.ts scripts/lib/source-graph.test.ts tests/fixtures/json-cache.ts | lane:cache-key-memo

## goal
Computing a test world's cache key stops re-parsing every imported file with TypeScript in every test process: each file's import list is remembered by its path and content, so the key costs tens of milliseconds instead of 1–3 s, while every key stays byte-identical.

## acceptance
- [ ] `sourceGraph()` takes an optional memo of import lists keyed by sha256 of (repo-relative path, NUL, file bytes), with a header holding a format version, the installed TypeScript version and the sha256 of `source-graph.ts`; a header mismatch or a corrupt memo means an empty memo; imports are still resolved against the live file system every run
- [ ] `json-cache.ts` passes a memo file in its cache base (`runtime-imports-v1.json`; the clone-wide store locally, `node_modules/.cache/haeram-worlds` on CI) and saves it only after misses (read, merge, temp file, rename); no memo with `HAERAM_WORLD_CACHE=off`; the prune loop never removes it; the memo is rewritten with only current entries past a cap
- [ ] optional, only if the keys stay identical: TypeScript is loaded only on a memo miss
- [ ] unit tests: unmemoised, cold-memo and warm-memo keys are identical on the same temp tree; adding a runtime import of a new file changes the key and includes that file; a corrupt memo or another TypeScript version in the header falls back to parsing
- [ ] a comparison over the scope set (scout tv10-I `compare.mts`, 138 scopes) shows every key identical to the repo's current `computationFingerprint`, cold and warm; per-process key time before/after on the same host
- [ ] `pnpm run typecheck`, `pnpm run lint`, `pnpm run format:check`, `pnpm exec vitest run --project unit scripts/lib tests/fixtures --maxWorkers 2`

## impl notes
- from review/test-value-261110 F7
- Scout tv10-I (scratchpad scoutI/): 104 vitest files and 33 e2e specs reach the cache; each vitest file is its own process (`isolate: true`); one key costs 1.1–1.35 s idle, 2.7 s during a gate; 83% is `ts.createSourceFile` (`source-graph.ts:20`), plus about 0.3 s to load TypeScript; prototype memo keys 138/138 identical, 56–71 ms per process warm.
- `ts.preProcessFile` is not an option: it lists `import type`, which changes the file set.
