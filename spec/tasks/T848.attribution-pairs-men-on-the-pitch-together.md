## goal
Revision 11's attribution already matches the two men of every two-man action over the playing time they share (T833's `pairParticipants`, →MATCH-16 r62). This task holds that rule where it is made — on the attribution's own trace over whole matches with substitutions — so that a regression is named at the attribution rather than found later as a script that cannot be played.

## acceptance
- [ ] `aggregate/players.pairs.test.ts` (integration, registered in `tests/config/test-tiers.ts`): over 8 placed 2008 fixtures (at least one of 120 minutes) traced through `players.testkit.ts`, `every pair is on the pitch together` — every `wins`, `recoveries`, `offsidePairs` and foul `pairs` entry names two lines whose playing spans in the group's period share more than zero minutes (`commonSpan` as attribution and detail use it), while the same fixtures hold at least 5 couples of an own and an opposing line sharing no minute of a period (asserted, so the case is not vacuous) and none of those couples appears in a pair
- [ ] same file, `pairs add up to the trace's counts`: per traced move the pairs' second men summed by line equal `won` / `recovered` / `offside`, per foul row `fouler`, and each pair's first man is one of the group's failed attempts (offside passers and losers never counted twice)
- [ ] `aggregate/timeline.test.ts` (unit) gains `commonSpan` / `pairParticipants` edge cases: overlapping spells, a substitution's minute (the man leaving at 79 and the man coming on at 79 share none and are never paired), a matchable draw consuming no draws, and an unmatched second man drawn only among men sharing the first's spell
- [ ] if either integration case finds a pair that never met, the attribution is fixed in `aggregate/` with a unit case naming it; no record is moved after settlement and no check is widened
- [ ] `pnpm run typecheck`, `pnpm run lint`, `pnpm run format:check`, `pnpm exec vitest run --project unit --changed "$HAERAM_DIFF_BASE" --passWithNoTests`; the integration file run once by hand, output pasted into the result
