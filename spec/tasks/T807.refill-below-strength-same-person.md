# T807 A sold place refilled by a lesser player who stays the same person

## goal
A club that sells a player refills his place for the rest of the season with a lesser player of a nearby age, not his double, and that man stays the same person until his cohort ends.

## acceptance
- [v] `replacement` (npc-continuity.ts about 86-103) draws the refill at the club's strength minus k, k an integer 2–6, and at the departed place's age plus d, d an integer −4 to +4 clamped to 17–35, both from the refill's own stream; position, formation role and the `:serial` suffix rule are unchanged; the next summer's squad is drawn at strength again
- [v] the refill's id is keyed on the place's cohort (T805's helper), not the year, so over consecutive seasons of one cohort the same refill (id, name, birth year) is returned and ages a year a season; when the owner signs the refill the next read gets the next `:serial`; the departed check still prevents duplicates (WORLD-11)
- [v] with T806's `SQUAD_SPREAD` set to `spread` the refill also takes his class and age term on top of the lower level (one helper shared with `npcSquad`); with `flat` only this task's level and age rule apply
- [v] T784's `REFILL_SALE` (`world-market.ts`, `kept`) keeps its released default and stays selectable for `scripts/seller-spread.ts`
- [v] unit cases in `npc-continuity.test.ts`: a refill's OVR is 2–6 below the club's strength; its age differs from the departed's for some seeds and stays within 4; the same refill across two seasons of a cohort; a signed refill's successor takes the next serial; `fixture-copy.test.ts` expectations that name `${club.id}:vacancy:N:2000` ids are updated to the cohort key with the reason in the test
- [v] goldens and prepared fixtures holding refills are refreshed with their own scripts after checking the diff is limited to refills; the day-loop equivalence tests pass: `pnpm exec vitest run --project integration packages/engine/src/calendar.progression-eng.test.ts packages/engine/src/season.test.ts packages/engine/src/full-model-throughput.test.ts`
- [v] `pnpm run typecheck`, `pnpm run lint`, `pnpm run format:check`, `pnpm run validate:i18n`, `pnpm exec vitest run --project unit --changed "$HAERAM_DIFF_BASE" --passWithNoTests`
