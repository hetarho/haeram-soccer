## goal
Every season close from 1955/56 archives a Ballon d'Or podium of three, pays a won Ballon d'Or bonus clause, and contract talks price recent podium places and settle the new bonus clause.

## acceptance
- [ ] A season closed from 1955/56 with a whole-season ledger stores `ballonDor` (1–3 places, winner first) on its SeasonArchive; earlier seasons and seasons not tracked whole store none.
- [ ] Points follow PLAYER-27: goals × 4, assists × 3, class (OVR − 70) × 2 above 70, honours europe 40 / europe-final 15 / continental 15 / league 25 / cup 10, each only with a contribution for the winning club in that competition; only 15+ top-flight league appearances are eligible; ties by points, OVR, then ID.
- [ ] Our winner with a `ballonDor` clause is paid wage × percent / 100 once at that close as a `ballon-dor-bonus` expense (debit mandatory), shown in the season ledger as 발롱도르 보너스; a podium place, a loan or no clause pays nothing.
- [ ] talkTerms' demand and the improved-contract test multiply the market wage by `ballonDorPremium` (1.20 winner, 1.10 podium within the last three closed seasons, else 1); the delegated 재계약 기조 ceiling uses the same worth.
- [ ] settleClauses keeps the existing promotion/relegation draws for every player and seed, then draws the Ballon d'Or clause only for players rated 80+ or with a recent podium; clausesLabel names it (발롱도르 수상 시 연봉의 N% 보너스).
- [ ] ballon-dor.test.ts covers: podium order and points on a small synthetic season, honour credit only with a contribution, the 15-appearance gate, no award before 1955/56 or for an untracked season, premium windows, bonus payment at the close, and unchanged promotion/relegation clauses for the same stream.
- [ ] contracts.test.ts covers the premium in demand, floor and the delegated ceiling.
- [ ] The day/round/season equivalence tests (calendar.progression-eng.test.ts, calendar.progression-esp.test.ts, season.test.ts "keeps day round and season advancement equivalent") and full-model-throughput.test.ts pass; the portable golden is regenerated if the contract tier moves.
- [ ] typecheck, lint, format and the changed unit tests pass.

## impl notes
- Types (packages/contracts/src/types.ts): `export type BallonDorHonour = 'europe' | 'europe-final' | 'continental' | 'league' | 'cup'`; `export interface BallonDorPlace { id: string; name: string; club: string; position: Position; goals: number; assists: number; appearances: number; points: number; honours: BallonDorHonour[] }`; `SeasonArchive.ballonDor?: BallonDorPlace[]`; `ContractClauses.ballonDor?: number` (percent of the yearly wage). Optional fields: older saves stay readable, no rules or schema bump (SAVE-10). Three short rows a season fit SAVE-4's century budget.
- New read leaf packages/engine/src/ballon-dor.ts (ARCH-4: imports only contracts types, primitives and pure helpers, so the UI may import it) holding `BALLON_DOR_CONFIG = { first: 1955, goals: 4, assists: 3, classFrom: 70, classWeight: 2, honours: { europe: 40, 'europe-final': 15, continental: 15, league: 25, cup: 10 }, appearances: 15, places: 3, premiumSeasons: 3, premium: { winner: 1.2, podium: 1.1 }, clause: { ability: 80, share: [0.4, 0.9], from: [25, 50], to: [50, 100] } }`, `ballonDorRecord(history, id)` (wins and podium places with years) and `ballonDorPremium(history, year, id)` (`{ factor, place?, year? }` over seasons `year − premiumSeasons … year − 1`). T642 reads these from the UI.
- The award itself (`ballonDorPodium(w, champions)`) needs squads and OVR, so it lives in season.ts or a non-leaf module it imports: run in closeSeason after `champions` is built and before `w.history.push` (club tiers are still the season's, before `promote`). Require `w.year >= first`, `w.npcSeason?.year === w.year` and `w.npcSeason.trackedFrom` at day 1 / round 1. Sum each `npcSeason.competitions[].players[]` entry per id: `metrics[M.goals]`, `metrics[M.assists]`, appearances; top-flight league appearances are `kind === 'league'` contributions for clubs with tier 0 and not representative. Honours: league from `champions[].club`, cup from `w.cupWinners[code]` with kind `cup` groupKey `cup:<code>`, Europe from `w.europe` winners (`key === 'ucl'` → europe; its final's runner-up → europe-final; any other key except the Super Cup → continental), each matched to a contribution for that club in that competition (kind + groupKey). OVR via `overall(p)` of the own `w.players` entry or the club's cached `squad(w, club)` (world.ts) for the club of his last contribution; a player found nowhere gets no class points. Compute OVR only for eligible players.
- Bonus: right after the podium, before the history push (so the closing season's books carry it): when the winner is an active own player without `loanUntil` and with `clauses.ballonDor`, `debit(w, amount, true)` and `addEvent(w, 'ballon-dor-bonus', \`${name} 발롱도르 보너스\`, …, amount)`; add `'ballon-dor-bonus': '발롱도르 보너스'` to finance.ts expenseKinds.
- contracts.ts: `talkTerms` multiplier gains `ballonDorPremium(w.history, w.year, p.id).factor`; `underpaid` compares against `marketWage × factor`; `staffTalkVerdict`'s `ceiling` uses the same worth. `settleClauses` takes an extra `star: boolean` (signingClauses computes it: `overall(p) >= clause.ability` or a premium factor > 1) and always draws two more values after the existing four (has, size) so promotion/relegation outcomes never change; include `ballonDor` only when `star && has`.
- Export the leaf reads from packages/engine/src/index.ts as other reads are.
- Regenerate the golden with `pnpm exec tsx scripts/update-golden.ts --write` then prettier on tests/fixtures/portable-v1.json only if contract tests move.
