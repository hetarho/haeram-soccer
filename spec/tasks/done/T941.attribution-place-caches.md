## goal
Cut the attribution step of aggregate (NPC) fixtures on league round days with bit-identical match results: compute each place-term row once per process, each exposure weight vector once per match, and each shared normaliser once per fitting iteration.

## acceptance
- [v] Place terms (players.ts:369-380): one module-level table keyed by every input `placeDistance` and `placeTerm` read (both sides' shapes or the tactics that fix them, side, cell and possession) holds each slot's term row; `refreshAttributionRoles` (players.ts:165) clears it, so a lab override of an attribution or place leaf through tunables.ts still reaches the next match. Values and arithmetic are unchanged (deterministic; worker, task stage).
- [v] `weightsAt` (players.ts:384-404) caches each result per side's lines by period, role, cell and possession and reads the place row once per call; consumers only read the returned array (typed `readonly`) (deterministic; worker, task stage).
- [v] `fitPlaceWeights` (place.ts:43-63) computes each distinct placed array's normaliser once per iteration, reuses one `actual` buffer and keeps group order, expressions and the convergence test unchanged (deterministic; worker, task stage).
- [v] Units cover a tactic change between two matches in one process, a lab override followed by a match (the table is rebuilt), and `fitPlaceWeights` with groups sharing one placed array against the current implementation.
- [v] Measurement (deterministic; worker, task stage): `node scripts/perf/ab.mjs --base "$GUSTA_DIFF_BASE" --workload aggregate --procs 6 --json artifacts/benchmarks/lifecycle-perf-261117/T941/ab-aggregate.json` and `node scripts/perf/ab.mjs --base "$GUSTA_DIFF_BASE" --workload day --procs 6 --json artifacts/benchmarks/lifecycle-perf-261117/T941/ab-day.json` report equal output hashes and a CPU-ratio interval below 1 for aggregate; a change part without a measured gain is restored with its measurement kept.
- [v] Existing aggregate, `players*`, `place`, `engine`, packages/engine/src/tunables.test.ts and apps/web/src/lab tunables/runner units pass unchanged.
- [v] ARCH-30 task-tier checks pass through `vibe check --tier task`; integration, contract and build stay with the coordinator's final batch gate (handoff only).

## result
