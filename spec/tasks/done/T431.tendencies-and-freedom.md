## impl notes
- Manager flexibility is the hire attribute STAFF-1/STAFF-14 band (0–100); read it from the own manager and from each named NPC manager as the engine already stores them, deriving nothing new.
- 예측력 sets when a player reacts, 위치선정 where he stands and 판단력 what he decides (PLAYER-26); keep the formulas apart so T433 does not count an attribute twice.
- No movement change here; T435 stores the values once per match on revision 2, T432 consumes `freedom`, T433 the other three.
- Runs before T286 and T435 (261025): `playerTendencies` is a pure function the inspector calls and T435 later calls from the grid setup, so it needs no revision gate; leave `grid/setup.ts` to T435.
