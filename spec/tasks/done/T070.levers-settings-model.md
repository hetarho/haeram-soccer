## impl notes
- Criteria shapes. Integers unless noted; omitted optional fields mean "any" or "none":
  - `ManagerCriteria`:
    - `minOvr` 0–99 = 0
    - `schools: ManagerStyle[]` = [] (any), no duplicates
    - `minFlexibility` 0–100 = 0
    - `maxPride` 0–100 = 100
    - `minYouth` 0–100 = 0
    - `traits: ('none' | ManagerTrait)[]` = [] (any)
    - `maxWageOvr?` one of 50, 55, …, 90 (absent = no cap)
    - `priority: 'ovr' | 'potential' | 'wage'` = 'ovr'
    - `term: ContractTerm` = 2
    - `poach: boolean` = false
    - `whenNone: 'wait' | 'best'` = 'wait'
  - `CoachCriteria`:
    - `volunteer: boolean` = false
    - `minAbility` 0–99 = 55
    - `trait?: StaffTrait`, which must be one of `STAFF_INFO[role].traits`
    - `maxWageOvr?` 50–90 in steps of 5
    - `priority: 'ability' | 'wage'` = 'wage'
    - `term: ContractTerm` = 2
  - `TalkRule`:
    - `maxPay` one of 0.9, 1, 1.1, 1.25, 1.4 = 1.1
    - `minOvr` 0–99 = 0
    - `maxAge?` 28–40
- The coach default (55, cheapest first) stands for the old 균형 level, and the talk rule's 1.1 for the default squad investment. The reference club's calibration (T062) therefore keeps its behaviour as closely as the new rule allows; T078 re-measures it.
- The schema validates enums and ranges. The engine setter also checks the department's traits, since contracts cannot import STAFF_INFO.
- Event titles:
  - manager criteria: `감독 선임 기준` with the changed lines;
  - coach criteria: `<부서명> 선임 기준`;
  - talk rule: `계약 협상 기준`.
- Version check in activation: compare indexes in `SUPPORTED_ENGINE_VERSIONS`, or parse the semver. 1.16.0 is unreleased, so worlds already at 1.16.0 are never activated again.
- `managerRule` and `delegation.manager` / `contracts` are 1.16-only, so no released save carries them. T072 removes `managerRule` without mapping it.
- Keep `pushInbox` for the activation item. Activation is pure on its input: clone first, as `activateAgents` does.
