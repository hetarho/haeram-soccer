## goal
Give the standard theme one maintained icon family with clean connected chevrons and consistent navigation, action and trophy symbols.

## acceptance
- [v] All standard-theme semantic icons come from a pinned Lucide distribution; the generator preserves upstream SVG geometry and attribution. Pixel resources retain their existing appearance.
- [v] Shared SVG layers support upstream strokes and round caps/joins without changing existing filled resources or requiring theme-specific component branches.
- [v] Unit cases cover stroked and filled icon rendering and validation; theme/resource checks, typecheck, lint, format and build pass. Manual inspection checks dropdown arrows and navigation at phone and desktop widths.

## impl notes
- Install lucide-static as a pinned development tool and generate the existing JSON pack from its SVG files. Convert SVG primitives to equivalent paths mechanically; preserve upstream path data, stroke width and cap/join values.
- Extend the existing validated IconLayer with optional stroke attributes. Keep the shared SemanticIcon renderer and default filled-resource behavior.
- Map semantic roles to upstream icon names in the generator and include the shipped license beside the generated pack. --check verifies that checked-in resources match upstream data.
- Resolve the owner's club-icon reference separately before changing the game-owned crest presentation; icon-set replacement can proceed independently.
