# T041 Motion throughout app interactions
> st:done@261009 | ssot:WEB-35 WEB-33 WEB-34 ARCH-7 ARCH-18 ARCH-28 | base:WEB@26 ARCH@3 | dep:T039 T040

## goal
Make navigation and decisions feel responsive with accessible, lightweight Motion transitions.

## acceptance
- [v] Motion animates screen/tab changes, dialogs and dropdowns, quick-action entries, disclosures and committed feedback.
- [v] Repeated background ticks do not replay entrance motion; animation does not change focus, engine facts, match timing or block pointer feedback.
- [v] Reduced-motion mode produces immediate stable states; unmounted/changed animations are cleaned up.
- [ ] Supported-browser journeys and reference production-build performance/storage gates pass on the accumulated source.

## impl notes
- Pin motion 14.0.0 and use motion/mini animate over opacity/transform with a small shared adapter; browser-native animation avoids adding the full React motion runtime.
- Use explicit transition keys for React screens/tabs and shared dialog/select lifecycle hooks; bound staggered children to compact interface groups.
- A scoped app interaction observer can animate newly expanded details/tab panels and newly inserted status feedback, but never poll or animate all rows on every world revision.
- Honor matchMedia reduced motion dynamically, cancel animation controls on cleanup, and verify actual Web Animations effects plus reduced-motion suppression in browsers.

## result
- outcome: directional screen slides, staggered CSS entrances on insert/show, dialog and card enter/exit (detached copies fade on every close path), tab/state pops, HUD cash count-up; quick actions were removed earlier (WEB-34 not in force)
- at: -
- verified: browser measurement — 33 animations on a tab change, 3 on dialog open, exit copy removed within 400 ms, 0 animations during 12 daily ticks, 0 under reduced motion; layout audit 0 issues at 360/390/1280
- limits: used native Web Animations instead of pinning motion 14.0.0; production preview performance/storage gates and three-browser journeys not yet re-run
