## impl notes
- Append, never insert: the generation loop draws one `rng()` per attribute in `ATTRIBUTES` order (`player.ts` `generateAttributes` ~L582); appending keeps the first 14 draws, the two new draws come after. Generated worlds still change (new careers only, SAVE-19), hence the golden regeneration.
- Do not name anything `judgement` — `OffPitchQualities.judgement` already exists.
- Position weights (`POSITION_WEIGHTS`, `player.ts` ~L101–166; ×3 primary, ×2 secondary, ×1 tertiary):
  | position key | add secondary | add tertiary |
  |---|---|---|
  | GK | – | decisions |
  | CB | decisions | – |
  | fullBack (LB/RB) | – | decisions |
  | wingBack (LWB/RWB) | – | decisions |
  | DM | decisions | – |
  | CM | decisions | composure |
  | wideMid (LM/RM) | – | decisions |
  | AM | decisions | composure |
  | winger (LW/RW) | – | composure |
  | ST | composure | – |
- Roles (`ROLES` ~L169–228, `promotes`): anchor `[]`→`['decisions']`; deepLyingPlaymaker `['vision']`→`['vision','decisions']`; poacher `['positioning']`→`['positioning','composure']`. No other role changes.
- `AGEING` (~L408): add `decisions: by(32, 33, 0.5), composure: by(32, 33, 0.5)` (the `Record<Attribute,…>` type forces it).
- `DEPARTMENT_ATTRIBUTES` (`staff.ts` ~L151): assistant gets decisions and composure.
- `SCHOOL_PREFS` (`player.ts` ~L437): the motivator school (동기부여형) attributes `stamina`→`stamina, composure`; the data head coach school (데이터 헤드코치) `vision, positioning`→`decisions, positioning`. Find the school keys in that table.
- `GK_ATTRIBUTES` stays the three keeper attributes; outfielders' new attributes are drawn like any other outfield attribute (weight offset), keepers' too (GK: decisions weight 1, composure weight 0).
- Age offset: give `generateAttributes` and `generateProfile` an optional trailing `age?: number`; after the initial per-attribute draw and before the two OVR shift passes, if `age !== undefined && age <= 21` subtract 5 from `decisions` and `composure`. Pass `age` from `makePlayer` (`world.ts` ~L181, it knows the age) and from academy generation if it calls `generateProfile` (grep `generateProfile(`; pass the age where the caller has it, leave others unchanged).
- `PlayerComparison.tsx` / `PlayerProfile.tsx` comments that say "14 attributes" → "16 attributes" (comments only; they iterate `ATTRIBUTES` / `ATTRIBUTE_GROUPS`).
- `scripts/calibrate.ts` keeps its GK list; nothing else there changes.
- Schema: `attributes` in `packages/contracts/src/schema.ts` is generated from `ATTRIBUTES`, no edit needed beyond the "14" comment.
