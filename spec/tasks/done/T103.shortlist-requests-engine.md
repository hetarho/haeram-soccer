# T103 The shortlist, the manager's requests and the 단장's signings

## goal
The chief scout keeps a shortlist all season, the manager asks for roles with a pick, the 단장 signs from them when transfers are delegated, and a window closing with none of the manager's requests met costs 3 trust.

## acceptance
- [v] `World.shortlist?: { year; day; entries: { playerId; role }[]; requests: { role; kind: 'short' | 'upgrade'; pick?: string }[]; window?: { year; opening; roles: Role[] } }`, drawn on a season's first day, on each window's opening day and after every 4th league round: up to three per role from `transferOffers`, free agents first, then ability, potential, id; entries no longer available drop when read
- [v] requests: every short role (the CLUB-33 minimums), then the upgrade role whose weakest starter a shortlisted candidate beats by most, when by 5+; at most three; each with the manager's pick (ablest then potential; a 육성형 or youth-trait manager the highest potential aged ≤ 23 first); an interim asks for none
- [v] at a window's opening the requests are kept as the window's; at its close day, when the window's requests named roles and no player of any of them joined during the window, the manager loses 3 trust with an inbox line saying so; nothing when one was met or there were none
- [v] the 단장's look (delegated) takes requested roles first and the manager's pick first, then the shortlist, then the market list, keeping every other CLUB-33 rule (margins, caps, money checks, one move a look); his reports name the request when the need is one
- [v] tests: signings.test.ts (shortlist order and drop-off, requests with short and upgrade roles, the 육성형 pick, the interim, the 단장 taking the pick, trust −3 at close only when no requested role was filled, by the owner or the 단장); determinism of the draw

## impl notes
- refresh hooks: season start (where the manager market refreshes), `w.round % 4 === 0` after a round (season.ts, next to `refreshManagerMarket`), and `announceWindows` on an opening day (before the 단장's first look).
- a player joining "in the window": the bids of the window completed (direction 'out') or a free agent signed during it, of a requested role.
