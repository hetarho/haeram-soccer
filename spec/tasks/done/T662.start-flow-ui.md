## goal
A compact mobile start flow renders from props: tier cards with reach, trait picks with the count read as difficulty, decade cards with their lines, a generation progress view, the club list with filters and a club sheet, and a takeover confirmation with the direction picker.

## acceptance
- [v] `StartFlow` takes `{ onGenerate(choice: StartChoice), progress?: { season }, listings?: ClubListing[], fortune?, onTakeOver(clubId, preset) }` and holds no runtime calls (T664 wires them)
- [v] tier cards (6, 석유 재벌 first), traits (8, 0–5 picks, the count shown as 하드 … 이지), decades (1930–2000 with one line each; 1940 says the takeover is at the 1946 restart), seed as an advanced setting
- [v] progress view 세계를 생성중… with the season reached; club list with country/division filters showing price, cash, debts, last season income and wage bill, strength, division and affordability; club sheet (squad, manager, stadium, history summary); confirmation with the 구단 방향 picker (WEB-15)
- [v] fits 360x740 and 390x844 with 44px targets (WEB-15/63); pure helpers in `startFlow.ts` with unit tests (affordability, filters, trait count label); design-system stories with fixture data
