- Replace shared tokens and decorative surfaces at their CSS Module owners; avoid a global selector override patch. Keep meaningful status and club colours distinct from the UI accent.
- Use a compact condensed display font for scores/key figures, a readable Korean sans serif for controls and copy; self-host any bundled fonts with their original license.
- Restyle the home stadium's actual stage-dependent illustration and match renderer without substituting hard-coded mock data or a fixed illustration of a different stadium stage.
- Existing behavioral/browser tests cover the interaction and viewport risk; do not add tests that merely assert copied CSS values.
