# T065 Broadcasting index for league distributions
> st:done@261013 | ssot:ECON-31 ECON-28 ECON-26 ECON-3 ECON-2 | base:ECON@16 | dep:- | touches:packages/catalogs/data/football-index.json packages/catalogs/src/index.ts packages/catalogs/src/catalogs.test.ts packages/engine/src/world.ts packages/engine/src/finance.ts packages/engine/src/finance.test.ts packages/engine/src/projection.ts | lane:-

## goal
League distributions (equal share, merit payment, parachute) follow a new broadcasting index per country and year instead of the football index.

## acceptance
- [v] The catalog carries a broadcasting index per country (ENG ESP GER ITA FRA POR NED BEL) and year: eras with `to`, `status` (estimated where no series exists), a provenance note and sources; small before league football was sold to television, growing with each country's rights deals and booming from the 1990s; after the coverage the last real multiple holds and prices are projected (→ECON-2), marked projected.
- [v] `broadcastingIndex(code, year)` in packages/catalogs returns value, real multiple, status and source like `footballIndex`, cached the same way; `broadcastQuote(code, year, units)` in packages/engine/src/world.ts quotes units on it like `footballQuote`.
- [v] `leagueShare`, the merit payment, the parachute and every projection or preview of distribution money use `broadcastQuote`; nothing else moves off the football index.
- [v] catalogs.test.ts: the broadcasting index is below the football index's real multiple in the 1950s and above it from the 2000s for ENG, is estimated with a source in every era, and is projected after the coverage.
- [v] finance.test.ts: a top-flight equal share in 1955 and in 2005 scales by the broadcasting index ratio, not the football index ratio; merit payment and parachute follow it.
- [v] Affected unit tests pass (`pnpm run test:unit`); `pnpm run typecheck` and `pnpm run lint` pass.

## impl notes
- Data lives in `packages/catalogs/data/football-index.json` under a new top-level `broadcasting` key, shaped like the football index: `{ eras: [{ to, status, note, sources }], index: { <CODE>: { real: number[] } } }`, real multiples relative to prices with 1950 as the base year of the file. Its own eras, since broadcasting history differs from commercial football's: suggested breaks 1964 (first regular league highlights), 1983 (first live league contracts), 1992 (pay-television), 2005, 2020, coverage end 2025. Values are estimates from public league TV-deal history (cite Deloitte Annual Review of Football Finance and league histories in `sources`/notes); ECON-3 requires the estimated status and attribution, never presenting them as observations.
- Size the multiples so 1950s distributions are a small fraction of what the football index gives today and 2000s top-flight distributions rise well above it; T062 tunes DISTRIBUTION_CONFIG's shares against ECON-29 afterwards, so get the shape right, not the final level. As a starting point for ENG: 0.15 in 1950, 0.3 by 1964, 1 by 1983, 6 by 1992, 25 by 2005, 45 by 2020, 48 by 2025; other countries scaled down like the football index's `share` and with later breaks where their rights deals came later (ESP/ITA/GER pay-TV mid-1990s, POR/NED/BEL smaller).
- The catalog for rules 1.16.0 is `2026-demo-2` (→T050), unreleased: extend it in place; update the catalog fingerprint/pin expectations in tests if they change.
- Keep DISTRIBUTION_CONFIG's units as they are; only the index they are quoted on changes. Its doc comment must say the units are before the broadcasting index.
- Where the UI shows football-index provenance (ECON-3), show the broadcasting index's provenance for distribution lines the same way; if no such display exists for distributions, none is added.
