## impl notes
- from review/night-perf-261119 F5
- Bit-identical outputs only: no coefficient, rule, draw order, iteration count or arithmetic-order change. `a * b * c / d` evaluated as `((a * b) * c) / d` may be precomputed as `(ab) * c / d` only when `ab` is exactly the same first product.
- T941 (tasks/done/T941.attribution-place-caches.md) already caches place-term rows and `weightsAt` results; its Map-based per-iteration normaliser measured 1.013× slower and was restored. Do not repeat it; an int index of distinct placed arrays computed once per call is allowed only with its own measured gain.
- Do not edit config.ts leaves (the lab tunables catalog test fails on new leaves). Process-wide tables must still be cleared by `refreshAttributionRoles` (`clearPlaceTables`).
- Scout evidence (lived 1950 world, round day ≈ 637 ms engine CPU without helpers): `attributePlayerFacts` 53%, `fitMoves` 29% (`fitPlaceWeights` 19%, `weightsAt` 6%), `settleParticipation` 15%, `generateTeamFacts` 12%; `fitPlaceWeights` 7,019 calls over two round days, 32.4 iterations, 29.1 groups, n = 11.
- The machine is shared and loaded; trust ab.mjs's paired interval, not wall seconds.
