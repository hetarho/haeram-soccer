## goal
Each touch knows its football situation from the players' positions, so decisions, duels and commentary can read it.

## acceptance
- [v] `grid/tags.ts` exports `Tags` and `computeTags(s, side, idx)` exactly as design §5.
- [v] `GridState` gains `lastPass?: { dx: number }` (set by the engine on every completed pass, dx in the receiving side's attack frame) used for orientation.
- [v] `tags.test.ts` cases (positions placed by hand on a testkit state):
  - `counts pressure with goal-side opponents weighing double` (one opponent goal-side at 3 m → 1, one behind at 3 m → 0.5, one at 5 m → 0)

  - `detects in behind against the second-last defender`
  - `detects the CB–FB channel`
  - `reads back to goal after a backward pass under goal-side pressure`
  - `names phases: build-up, progression, final third, counter within 8 s of a regain, set piece`
  - `reports lead, minute and men difference from the carrier's side`
- [v] `pnpm run typecheck`, `pnpm run lint`, the test file pass.

## impl notes
- All computations in the carrier's attack frame (`attackFrame(side, pos)`); opponents converted the same way.
- `pressure`: Σ over opponents on the pitch with distance ≤ 4.6: 1 if opponent.x > carrier.x (goal-side), else 0.5.
- `betweenLines`: MF and DF mean x from `lineX(s, other, 'MF' | 'DF')` (converted into the carrier's frame: opponent frame x → 105 − x), carrier lane in {1,2,3}. `pocket`: `betweenLines && nearest >= 6`.
- `inBehind`: carrier.x > `offsideLine(s, other)`.
- `channel`: lane 1 or 3, |carrier.x − DF mean x| ≤ 6, and carrier.y lies between the nearest opponent CB (slot position `CB`) y and that side's FB (`LB/RB/LWB/RWB`) y.
- `phase`: `setPiece` when called with `{ setPiece: true }` (add an optional third parameter `opts?: { setPiece?: boolean; contest?: boolean }`); `contest` when `opts.contest`; `counter` when `lastRegain.side === side`, `elapsed − lastRegain.at ≤ 8` and at most 5 opponents have x greater than the ball x (attack frame); else band 0–2 `buildUp`, 3–4 `progression`, 5–7 `finalThird`. `settled` is returned when the side has had the ball for more than 20 s without entering band ≥ 5 (track `possessionSince` in the state: add `possessionSince: number`, set when possession changes).
- `orientation`: `backToGoal` if `lastPass.dx < 0` and an opponent within 3 m has x > carrier.x; `halfTurn` if |dx| ≤ |dy|·1 (lateral; store `dy` too) and no such opponent; else `facing`.
- `lead` = own goals − opponent goals; `minute` = floor(elapsed/60) + 1; `menDiff` = own on-pitch count − opponent on-pitch count.
