## goal
The two measurement scripts that judge a generated world's realism report who keeps winning: the Ballon d'Or read gives repeat winners, runs, winner age and line, and the champions read gives each country's longest title run.

## acceptance
- [v] `scripts/ballon-dor-podiums.ts` summary adds, per variant: distinct winners over the seasons read, the most wins of one player, the longest run of consecutive wins, winner age (min, median, max), winner line (GK/DF/MF/FW counts), the share of winners whose club had the season's highest strength, the owner's club's winners counted apart; existing columns and the T783 variant grid are unchanged; `--variants <name,...>` (default all) limits the variants played
- [v] `scripts/era-wage-spread.ts --champions-runs <extra.json ...>` reads archived champion lists and prints, per country and seed, the longest run of consecutive titles, the number of runs of 5 or more and the most titles in any 10-season window, for 1955–2009 and 1980–2009; existing `--champions-*` reads are unchanged
- [v] the counting functions are pure and exported (in the script or `scripts/lib/`) with unit cases on hand-written lists: runs at a list's start and end, ties, a gap season (1939/40–1945/46 not played), a single-club list
- [v] the champions-runs read is run on T698's archived extras (`artifacts/benchmarks/T698/placebos.tar.gz` and `artifacts/benchmarks/T697/rows.tar.gz`, unpacked into the session's scratch folder, never into the repository) and its table is written to `artifacts/benchmarks/T803/champions-runs.md` with the inputs' names
- [v] `pnpm run typecheck`, `pnpm run lint`, `pnpm run format:check`, `pnpm exec vitest run --project unit --changed "$GUSTA_DIFF_BASE" --passWithNoTests`
