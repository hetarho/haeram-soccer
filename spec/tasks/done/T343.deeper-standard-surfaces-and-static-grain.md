# T343 Deepen all standard surfaces and extend efficient grain

## goal
Deepen the full standard palette and texture UI surfaces with an efficient static grain while retaining hierarchy, layout and readability.

## acceptance
- [v] Page, navigation, content and interactive fills are darker, retain distinct saturation/luminance and meet 4.5:1 primary/supporting text contrast.
- [v] Standard UI fills reuse one small pre-rasterized noise texture with no overlay, animated filter or texture over text/art. Pixel retains its existing rendering. If measured rendering cost materially worsens against page-only grain, keep the page-only version instead.
- [v] Record rendering/frame measurements, inspect actual desktop/mobile home and a dialog/dropdown, and confirm theme-switch cleanup. Existing theme/resource-validator unit cases and task static/build checks pass; browser specs remain at the ARCH-30 batch gate.

## impl notes
- Encode the existing SVG grain once as a small local PNG; runtime backgrounds reuse that texture rather than evaluating a noise filter per surface. Keep the texture under the theme asset directory and preserve its existing visual strength.
- Shared background consumers may read optional --surface-grain with none fallback; the active standard stylesheet supplies it. Explicit transparent backgrounds, club identity, pitch rendering and illustration treatment retain their current behavior. No component or theme-ID branch is introduced.
- Compare page-only and all-surface grain in alternating rounds on actual desktop/mobile UI with a paused game and CPU-throttled scroll/frame observations. Use trace paint/raster and frame distributions as evidence, not a claim about every physical device; a consistent material regression selects page-only grain.

## result

A single 160×160 grayscale/alpha PNG (24,557 bytes) now textures semantic UI fills through optional --surface-grain with none fallback across shared CSS. Standard's optional stylesheet owns the texture; pixel has zero textured fills after a theme change. No layout, font, illustration, icon, overlay or gameplay change was introduced. Shared declaration changes were audited against saved pre-edit CSS; only texture composition and formatting changed.
