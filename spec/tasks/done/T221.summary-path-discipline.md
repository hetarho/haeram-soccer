## impl notes
- Poisson draw: Knuth's method with the stream (`L = exp(−λ)`, multiply uniforms until below L).
- Squads: `prepareMatch` already builds both `squads` (starting XIs); use them.
- Goal assignment: one `r()` per goal from a third stream `random(`${w.seed}:scorers:${f.id}`)` so the score stream is untouched.
- Extra time and shoot-out on this path come in T222.
- T224 (261020) already gives own-league fixtures on this path their 22 lines with goals, assists, shots and saves from the chance model's own shooter/creator slots (no extra stream); here only the discipline and injury draws and their `incidents` remain, and the named-lines test case checks that existing assignment.
