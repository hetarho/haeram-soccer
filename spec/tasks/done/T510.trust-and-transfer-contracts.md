## goal
The world contract can hold a manager's trust-floor warning flag and our club's transfer facts, and saves carry them losslessly.

## acceptance
- [v] `Manager` gains optional `trustWarned?: true` (→STAFF-47: set while the warning stands); its zod schema accepts it and rejects any other value.
- [v] New exported `TransferFact` type and `World.transfers?: TransferRecords` with the shape in impl notes; schemas are strict like their neighbours; older worlds without the field still validate unchanged.
- [v] A world carrying both fields survives save → compact checkpoint → load unchanged (canonical equality); if the compact packer in `apps/web/src/adapters` enumerates world keys, it handles `transfers`.
- [v] Tests: `schema.contract.test.ts` cases "accepts a manager trust warning flag", "accepts own-club transfer facts", "rejects a malformed transfer fact"; a round-trip case in the adapters' existing checkpoint test file.
- [v] Fast checks: typecheck, lint, format:check, unit/contract tests of the changed files.

## impl notes
- shape:
  ```ts
  export interface TransferFact {
    direction: 'in' | 'out';
    loan: boolean;
    player: string;      // Player.id
    person?: string;     // PersonCareer id when known
    name: string;        // his name when it happened
    club?: string;       // the other club's id when known
    fee: string;         // minor units, as the ledger amount
    currency?: string;   // as Event.currency at the time
    year: number;
    day: number;         // season day (careerDate)
  }
  export interface TransferRecords {
    /** w.events.length when the first fact was recorded: ledger entries before it are the older career's (→HIST-20). */
    ledgerBefore: number;
    facts: TransferFact[];
  }
  ```
- Reuse the existing `season`/`seasonDay` schema helpers and money-string schema in schema.ts.
- No engine behaviour here: T511 sets the flag, T513 writes the facts. Only contracts and save adapters change.
- Save size: one fact is a few dozen bytes; the 100-season storage profile (→SAVE-13) is measured by the batch, not here.
