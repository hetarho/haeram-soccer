# T208 Decision tables: action mix and target choice

## goal
The ball carrier picks what to do and where to play it by probability: the real-data mix of his cell and position, bent by role, traits, tactic, tags, the score and his 판단력/침착성.

## acceptance
- [v] `grid/decide.ts` exports `DECISION_CONFIG`, `Action`, `Decision`, `actionMix`, `choosePass`, `chooseCarry`, `keeperDistribution`, `decide` (signatures below), following design §6.1–§6.6.
- [v] `decide.test.ts` cases (testkit states, 5000 draws each, fixed seed):
  - `reproduces a cell's real action mix for a neutral carrier` (a CM with all attributes 60, neutral role/traits, no pressure, balanced vs balanced, in `central.oppMiddle`: pass, carry, takeOn shares within ±0.04 of `CELL_BASELINES`)
  - `shoots far more in the central box than in front of the box and never from the own half` (shot share central.box > 3 × central.frontOfBox; 0 shots from bands 0–3)
  - `crosses only from bands 5–7 and cuts back only from the cut-back cells`
  - `reproduces the cell's pass direction mix when every target scores the same` (forward/lateral/back within ±0.05)
  - `lets a high-decisions player pick the best target more often` (decisions 90 vs 30, same situation: the share of the highest-scoring target is higher by ≥ 0.10)
  - `lets pressure scatter a low-composure player's choices`
  - `takes more shots in front of the box with a long-shot trait, more crosses with a crosser, more hold-up with a target man`
  - `plays more patiently under possession and more directly on a counter`
  - `keeps a leading side safer late` (minute 85, lead 1: takeOn share lower than at 0-0)
  - `distributes short more often as a sweeper keeper than a shot stopper`
- [v] `pnpm run typecheck`, `pnpm run lint`, the test file pass.

## impl notes
- Signatures:
  ```ts
  export type Action = 'pass' | 'cross' | 'cutBack' | 'carry' | 'takeOn' | 'shot' | 'holdUp' | 'clearance';
  export interface Decision { action: Action; target?: number; point?: [number, number];
    kind?: 'short' | 'long' | 'switch' | 'through'; lineBreaking?: boolean }
  export function actionMix(s: GridState, side: 0 | 1, idx: number, tags: Tags): Record<Action, number>;  // normalised
  export function choosePass(s: GridState, side: 0 | 1, idx: number, tags: Tags, r: () => number,
    opts?: { crossOnly?: boolean; backBias?: number }): { target: number; kind: Decision['kind']; lineBreaking: boolean } | undefined;
  export function chooseCarry(s: GridState, side: 0 | 1, idx: number, tags: Tags, r: () => number): [number, number];
  export function keeperDistribution(s: GridState, side: 0 | 1, r: () => number): { target: number; kind: 'short' | 'long' };
  export function decide(s: GridState, side: 0 | 1, idx: number, tags: Tags, r: () => number): Decision;
  ```
  `decide` draws the action with one `r()`, then, for passes/crosses/cut-backs, calls `choosePass` (one more `r()`), for carries `chooseCarry`; a goalkeeper in possession always uses `keeperDistribution`. If `choosePass` finds no candidate, fall back to `carry`, then `clearance`.
- Action mix steps 1–9 of design §6.2, in that order, then normalise. Put every factor in `DECISION_CONFIG` (e.g. `DECISION_CONFIG.tactic.possession.pass = 1.10`), never inline literals, so T215 can tune them.
- `actionWeight(role, traits, action)` from `match.ts` gives role × trait weights for `'shot' | 'box' | 'long' | 'dribble' | 'cross' | 'key' | 'hold' | 'run'`; the role is `FORMATIONS[tactic].slots[slot].role`.
- Line factor uses `lineOf(slot position)`.
- Cut-back cells: band 7 and lane 1 or 3 (`cellBand`, `cellLane`).
- `choosePass` (§6.3): candidates = teammates on the pitch except the carrier, within 60 m (70 for GK and CB carriers). For crosses (`crossOnly`), candidates are teammates inside the box. `xT` from `CELL_BASELINES[cellOf(attackFrame(side, pos))].xT`. Lane risk: for each opponent, project onto the segment carrier→target; count it only if the projection parameter is in (0,1); `risk += exp(−d/2)`. Direction: angle of (target − carrier) in the attack frame, forward if |angle| ≤ 45°, back if ≥ 135°, else lateral. Prior uses `CELL_BASELINES[cell].forward|lateral|back`, `POSITION_PROFILES[profileKey(pos)]` and `OVERALL_PROFILE`; divide by the number of candidates in that direction. Weight `prior × exp(score/τ)`; τ from §6.3; `backBias` multiplies back-direction priors (used after a hold-up, 3).
- `kind`: long if distance > 30; switch if |Δy| > 30; through if `through_j > 0`; else short. `lineBreaking` per §6.3 using `lineX` of the opponent DF and MF lines (deepest player of a line = max x of that line's players in the passer's frame).
- `chooseCarry` (§6.4): headings 0°, ±30°, ±90° relative to the goal direction; length `6 + 6·r()`; score `(xT(end) − xT(start))·100 − 0.5·pressureAt(end)`; pick with weights `exp(score/τ)` (same τ); clamp to the pitch (0.5 m margin).
- Style bends (§6.6) apply in `actionMix` (`possession`, `shot`, `defense` for the opponent) — `pass` and `lineHigh/lineLow` are applied by T209/T206 consumers; leave a short comment pointing there.

## result
- outcome: `grid/decide.ts` gives the carrier his action by probability (`actionMix`: real cell mix × position habits × role/traits × tactic × tags × score/time × 판단력, with the hard restrictions) and his targets (`choosePass`, `chooseCarry`, `keeperDistribution`, `decide`); the pass options and their probabilities (`passOptions`, `passProbabilities`, `temperature`) are exported for later tasks and tests.
- at: 60186fa (working tree)
- verified: `pnpm exec vitest run packages/engine/src/grid` 47/47 pass (11 in `decide.test.ts`); typecheck, lint and prettier clean. Batch of T203–T207 (full unit 1065, contract 19, catalogs, build) passed before the push of 60186fa.
- limits: Tests compare mixes in exact form and by sampling (5000 draws) with ±0.05–0.06 sampling bands for the neutral carrier. With xT×100 gains a clearly better target dominates at any temperature, so 판단력 matters mostly when options are close; T215 may rescale `DECISION_CONFIG.pass`. A pass with no receiver falls back to a carry, or to a clearance when pressed in bands 0–2; direct free kicks (the only shot allowed from bands 0–3) are handled by T210.
