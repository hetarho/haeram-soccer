# T724 count knockout rounds with integer arithmetic and guard Math.log2
> st:done@261109 | ssot:ARCH-5 ARCH-9 ARCH-30 | base:ARCH@33 | dep:T722 | touches:packages/engine/src/knockout.ts packages/engine/src/stages.ts eslint.config.mjs | lane:dev-cost

## goal
The two remaining host `Math.log2` calls in engine source become exact integer arithmetic with identical results for every input they receive, so T722's guard can reject `Math.log2` too and the engine has no host transcendental call left (review/gusta-self-improve-261109 F3).

## acceptance
- [v] `knockout.ts` `roundsFor(n)` returns `ceil(log2(max(2, n)))` (at least 1) from an integer form such as `32 - Math.clz32(Math.max(2, n) - 1)` for the whole-number club counts it receives; a unit test compares the new form with the old expression for every n from 0 to 4096
- [v] `stages.ts`'s two-knockout-rounds check uses an integer comparison equivalent to `round < log2(field / qualifier)` for positive qualifier (for example `(era.qualifier << round) < era.field`), checked against the old expression over every European era's field/qualifier and rounds 0–10
- [v] `Math.log2` joins T722's restricted list; `pnpm run lint`, `pnpm run typecheck`, `pnpm run format:check` pass with no disable comment
- [v] results identical: `pnpm run test:contract` passes with the portable golden unchanged, and the knockout/stages/competition unit tests pass

## impl notes
- If `roundsFor` can receive a non-integer or a count above 2^31, keep the old value for that input range explicitly and say so in result rather than changing it.

## result
- outcome: `roundsFor(n)` is `32 - Math.clz32(Math.max(2, n) - 1)`, the bit length of n − 1 (= ⌈log₂ n⌉, at least 1); every caller passes a whole club count (`clubs.length`, `cup.clubs.length`, `t.clubs.length`, `qualified.length`, `left.length`, `era.field` 16–64, and `cupRoundsLeft`'s `cup.clubs.length`), all far below 2³¹, so no non-integer or larger input range needed keeping. stages.ts's check moved into an exported `beforeGroups(era, round)`: `!!era.qualifier && round < 31 && era.qualifier * (1 << round) < era.field` (the impl note's `qualifier << round` would overflow from round 28 at qualifier 8, so the shift stays on 1 and rounds from 31 on are false, as the old expression gives while field / qualifier < 2³¹; `round` is a parsed `\d+`). `log2` joins the T722 block's list and the "joins once…" comment is gone, so no host transcendental `Math.*` is left in engine or contracts source. New `packages/engine/src/knockout-rounds.test.ts` holds the old expressions and compares: `roundsFor` for every n 0–4096 plus 2ᵏ−1, 2ᵏ, 2ᵏ+1 for k 1–31; `beforeGroups` over every distinct field/qualifier `europeanEras` gives for years 1900–2100, rounds 0–10 (only 32/8, 1991–93, has a qualifier: rounds 0 and 1 before the groups, as before); and over every field 1–256 × qualifier 1–64 × round 0–10, plus rounds 28–40 on 32/8. Mutants (`clz32(max(2, n))`, `<=` for `<`) fail all three cases.
