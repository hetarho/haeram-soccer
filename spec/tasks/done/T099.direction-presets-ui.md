## impl notes
- put the founding view of the presets (id, label, model, a one-line row summary) in a tiny `packages/engine/src/presets-summary.ts` or a web module generated from BUILD_PRESETS at build time — whichever keeps the entry under budget; measure with the benchmark's entry size.
- `withStrategy(w, draft, build, name, rows?)`: with rows, set draft.policy to every key differing from the world, draft.ticket when it differs, draft.direction when it differs; without rows, cards only (today).
- composer state is a whole board ({ build, policy, ticket, direction }); its save writes `build` and `rows`.
- SavedStrategy type (adapters/profile.ts): `rows?: { policy?: Partial<ClubPolicy>; ticket?: number; direction?: Partial<Direction> }`; malformed rows drop the rows, keep the cards.
