## goal
Provide one validated game-owned settings model and pure responsibility predicates for all later consumers.

## acceptance
- [v] A new world has exactly seven categories: manager direct, staff delegated, contracts direct, recruitment direct, sales direct, academy delegated, sponsors delegated; automatic mode, match eve on and window opening off.
- [v] Every category independently accepts direct/delegated; there is no eighth playing-coach category or per-department authority. Training is outside this map.
- [v] One settings command validates the entire proposed result before changing any field. Manual with match eve off and disabling match eve while manual both fail without mutations, fees, event writes or revision success.
- [v] Ordinary automatic settings may disable both observations. No trigger other than match eve makes manual valid; validation never silently toggles a setting.
- [v] packages/engine/src/responsibilities.test.ts covers the exact default map, a mixed recruitment/sales map, all-direct/manual-invalid and all-delegated/manual-invalid cases, and unchanged state after an invalid apply.
