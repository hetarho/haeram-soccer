## goal
History seasons and every career's season close spend less CPU pricing generated squads, recording recent results and finding a tie's legs, with byte-identical results.

## acceptance
- [v] `squadCostAt` sums each generated player's stored `wage` when the club's country is the one `npcSquad` priced him with, and keeps `marketWageAt` otherwise (e.g. `euro:*` clubs); same signature and value
- [v] `recordRecentResult` appends without sorting when the club's list is empty or the new result sorts at or after its last entry (after removing the same fixture id), and sorts as today otherwise; stored lists byte-identical
- [v] `legsOf` builds its second-leg key once per call; same output
- [v] `node scripts/perf/ab.mjs --base <T775's integrated commit> --workload history` reports `sameHash` true and an interval below 1 (ARCH-34), or the measured interval is recorded as is when it includes 1; `sameHash` true for `--workload day`
- [v] `pnpm exec vitest run packages/engine/src/dynamics.test.ts packages/engine/src/books.test.ts packages/engine/src/history.test.ts packages/engine/src/recent-results.test.ts`, the cups/competition-keys tests, `pnpm run typecheck`, `pnpm run lint`, `pnpm run format:check`
