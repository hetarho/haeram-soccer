## impl notes
- Follow T466's pattern for a revision: the revision string list and doc comment in `packages/contracts/src/match-model.ts`, the activation writer unchanged (`activatesMatchModel` compares revision numbers), `docs/MATCH-MODEL-CONTRACT.md` names revision 4. Revision gates read `modelAtLeast(s.setup, 4)` from `grid/rules.ts`.
- Define `RESTART_CONFIG.ownThird = 35` (metres from the own goal line in the side's attack frame, MATCH-14's band edge) in `grid/restarts.ts`; T480–T482 do not change it.
- The nearest taker is chosen by distance from each candidate's current position to the spot (ties by roster index) before `place(taker)`; it draws nothing, so revision 4 changes no other stream by itself.
- Archived replays rebuild from stored goals (`apps/web/src/ui/replay.ts`), and a queued playback replays under the revision it settled with, so gating keeps every settled match reproducible.
