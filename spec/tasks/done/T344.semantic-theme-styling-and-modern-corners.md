## goal
Apply restrained modern standard corners through a reusable root-token styling module rather than component theme branches, while retaining layout and the pixel appearance.

## acceptance
- [v] Centralize semantic style-token defaults/resolution and shared root styling. Theme installation remains transactional; shared components read semantic CSS variables, with no theme-ID-dependent class helper or new styling dependency.
- [v] Standard controls/panels/badges/dialogs use coherent radii, its home scene clips rounded corners, and pressed feedback is subtle without geometry/z-index changes. Existing pixel radii, decorative geometry, focus/touch behavior, green palette, grain, art and layout are retained.
- [v] Unit cases cover selected-pack optional defaults without default-theme leakage, own-role overrides, arbitrary extension tokens and immutable resolution. Existing theme/controller/resource unit cases and static/build/spec checks pass; browser specs remain at ARCH-30 batch.
- [v] Inspect actual desktop/mobile home, founding, settings/dropdown and a management view; verify root selection, shape/texture cleanup, no overflow and preserved modal occlusion when switching themes.

## impl notes
- Extract pure themeTokens.ts from theme.ts for semantic role defaults and flattening; share base theme.css for page grain/font treatment. Keep pack-specific values/resources in JSON/optional CSS and existing CSS Modules for geometry. Use data-theme on the document root for inspection, synchronized from the committed controller snapshot.
- Follow the design-token and root-selection principles in official Tailwind theme/dark-mode docs, within ARCH-2's existing CSS Modules stack. Do not introduce a cx helper carrying theme identity or install Tailwind for this change.
- Standard radii: controls 8px, panels 12px, badges 4px, dialogs 18px; pixel retains its current values. Replace literal angular UI radii with semantic roles while preserving physical circles, pitch markers, confetti, compact meters and explicit square tab geometry.
- Neutral optional defaults belong to the common token module, preventing standard-only shape/state values from leaking through registered-default fallback. Shared CSS consumes these roles; pack-specific CSS owns only its visual resource declarations.
