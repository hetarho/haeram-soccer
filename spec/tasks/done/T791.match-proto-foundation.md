- Frames of reference (used by every later task):
  - world frame: metres, `x` 0–105 along the pitch, `y` 0–68 across. Team 0 (home, code `H`) attacks toward `x = 105`; team 1 (away, code `A`) attacks toward `x = 0`. There is no change of ends.
  - attack frame of a team: the frame in which that team attacks toward `x = 105` and `y = 0` is its own left touchline. `toAttack(0, p) = p`; `toAttack(1, [x, y]) = [105 - x, 68 - y]`. The function is its own inverse, so it also converts attack frame → world.
  - player index: `team * 11 + slot`, slot 0 is the goalkeeper.

- `core/rng.ts` — write exactly this algorithm (the reference vectors depend on it):
  ```ts
  export interface Rng {
    /** Uniform in [0, 1). */
    next(): number;
    /** Uniform in [lo, hi). */
    range(lo: number, hi: number): number;
    /** Uniform integer in [lo, hi], both inclusive. */
    int(lo: number, hi: number): number;
    chance(p: number): boolean;
    /** One item by weight (equal weights when omitted). Throws on an empty list or a non-positive total. */
    pick<T>(items: readonly T[], weights?: readonly number[]): T;
    /** An independent generator named by this generator's seed and `label`; draws nothing from this one. */
    fork(label: string): Rng;
  }
  export function hashSeed(seed: string): number {
    let h = 1779033703 ^ seed.length;
    for (let i = 0; i < seed.length; i++) {
      h = Math.imul(h ^ seed.charCodeAt(i), 3432918353);
      h = (h << 13) | (h >>> 19);
    }
    h = Math.imul(h ^ (h >>> 16), 2246822507);
    h = Math.imul(h ^ (h >>> 13), 3266489909);
    return (h ^ (h >>> 16)) >>> 0;
  }
  export function createRng(seed: string): Rng {
    let a = hashSeed(seed);
    const next = () => {
      a = (a + 0x6d2b79f5) | 0;
      let t = a;
      t = Math.imul(t ^ (t >>> 15), t | 1);
      t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
      return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
    };
    // range: lo + next() * (hi - lo); int: lo + Math.floor(next() * (hi - lo + 1));
    // chance: next() < p; pick: u = next() * total, subtract weights in order, return the first item
    // where u drops below 0 (the last item as a guard); fork: createRng(`${seed}#${label}`).
  }
  ```
