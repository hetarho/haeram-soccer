## goal
Find the lowest aggregate fixture cost that keeps complete, calibrated records, as evidence against ARCH-31's fixture budget.

## acceptance
- [v] Profile the aggregate fixture after T323 by stage (preparation, team facts, attribution, settlement) and list what each stage must produce under MATCH-26/27.
- [ ] Try semantics-preserving reductions first (digest-checked as in T285); then measure redesign options that change draws (coarser move groups, attribution by group totals, lazily derived counters), each with its cost and its effect on MATCH-23/29/30 verdicts and parity on calibration seeds.
- [v] Keep only changes whose recalibrated validation readings stay inside every band the aggregate path met before; refresh `docs/benchmarks/aggregate-model-calibration.json` and the throughput artifact with fingerprints; exact invariants hold on every sampled match.
- [v] Interleaved A/B timings against ARCH-31's absolute fixture budget (1 ms median on the recorded reference machine), with the ratio to the summary path reported as context; task checks follow ARCH-30.
- [v] exit: at the timebox record the achieved cost, each option's measured cost-accuracy trade-off and the remaining gap to the budget, claiming the budget only when the reference-machine median meets it; the result is T286's evidence.

## impl notes
- Read T285's `## result`: the fixture costs about 0.82–0.88 ms against the budget's ~0.038 ms (23×), attribution is the largest stage, and T285's changes were bit-identical.
- A redesign that changes draws needs recalibration on calibration seeds and held-out validation (MATCH-28); never trade a band or a parity margin for speed.
- ARCH-31 r19 sets absolute budgets (fixture ≤ 1 ms median, season ≤ 15 s median on the recorded reference machine); T285 measured the aggregate fixture at about 0.82–0.88 ms, so this task keeps that inside the budget with headroom while records stay complete and calibrated.
