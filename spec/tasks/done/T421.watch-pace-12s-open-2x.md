- [v] Task checks (ARCH-30): typecheck, lint, format:check, `vitest run --changed`, `pnpm run build`.

## impl notes
- Speed is session state in `Pitch.tsx` (`useState`); no saved preference exists, so no migration.
- Journeys that wait for minutes to pass get 1.5× longer at the 2x default (6 s against 4 s a minute); prefer raising their chosen speed over longer timeouts, and list every spec touched or still assuming 4 s in the result's limits for the batch run.
- The set-piece preparation is T422; this task changes only the constant and the default.
