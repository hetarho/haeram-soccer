## goal
Serve career statistics and current-season finance from maintained summaries.

## acceptance
- [v] Replace lifetime rescans in ordinary host publication for appearances/cards/heat, milestones, European coefficient and financial breakdown with shared new-fact aggregates or indexed season ranges. Preserve exact metrics, scopes, current-season reset and archived source records.
- [v] Financial reads and recurring settlement-book lookup visit current-season entries only after a one-time initialization; honor in-place installment amount/detail updates, currency transitions and entries assigned to the closing season.
- [v] Publish only the bounded recent news feed and summaries in daily views, omitting the journal/internal read-state itself from projected World. Add a validated read-only paged news query for retained older items and connect an accessible older-news journey without sending the entire journal daily.
- [v] New-fact indexing uses a common helper in an engine read leaf rather than reimplementing invalidation in each consumer. Reads, failed/stale commands and duplicate requests leave canonical facts unchanged.
- [v] Add focused unit tests proving identical totals and no archived-array traversal on maintained reads, including appended matches/events, season/currency transitions, old in-place installments, departed players, cards and heat. Update host/protocol/UI integration and browser tests for the final gate; run affected units, fast checks and build.

## impl notes
- Reuse T673 shared state and record IDs. Keep current season at most its retained actual workload; do not keep complete past match/player objects in cache. Full source scans are acceptable only during explicit initial reconstruction or a user-requested historical query.
- Use a shared event season index keyed by actual event.year/currency, with references to mutable entries so installment updates remain exact; avoid cache keys relying solely on event length when a record mutates.
- Follow existing read-only RPC patterns (manager-history/archive/world-market) for pagination. Configuration owns page/window sizes; stable deterministic order and input bounds protect the worker. Preserve unread/celebration source IDs and show stored wording.
- Current heat material disappears at season close, but existing season heat archives stay; never count a zero-minute unused substitute as an appearance. Milestones may read live player/facility state where appropriate, but should not replay a whole career each day.
