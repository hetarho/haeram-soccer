- outcome: `--workload view` measures a day as the Host plays it, A/B and result-identically: `ab.mjs` takes `packages/` and `apps/web/src` from each side (a git ref exports the parts its cached tree lacks, a directory copies both) and both bundle with the root `node_modules`; the `view` workload builds the `day` career (cash raised) in a `Host` without helpers, takes the fresh activation's `viewSeq` as the first base, and each rep sends one `advance-days 1` command with `viewBase` and makes `structuredClone(forPosting(reply))`, labelled own/other; the posted clones are kept and hashed in `digest()` with the canonical world, outside every timed rep. `pair.mjs` and `profile.mjs` await a rep that returns a promise and run a synchronous rep as before; `view` DEFAULTS are procs 4, reps 60, warm 6 (profile reps 60, warm 6), listed in both headers.
- at: this commit's code tree (the checks ran on 9e0f0ba8, the same scripts/perf code before this task file was updated)
- verified: `node scripts/perf/ab.mjs --base HEAD --workload view --procs 4` (A/A, base = 9e0f0ba8 exported by git archive, cand = the working tree copy): sameBundle true, sameHash true (93655a7f50b2f522 on all 4 processes, both sides); own days 40 pairs CPU ×1.0015 [0.9837, 1.019], other days 200 pairs CPU ×1.0032 [0.9798, 1.0272], both "no difference"; median CPU base/cand own 1033/1023 ms, other 27.4/27.1 ms; load1 25.02, 23.09, 23.65, 22.57, 25.19 (12 cores, shared with sc10 and another session), about 4 min wall. `pnpm exec vitest run scripts/perf/stats.test.ts` (4/4), `pnpm run typecheck`, `pnpm run lint`, `pnpm run format:check` pass.
