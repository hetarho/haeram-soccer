The contracts and schema describe everything the grid engine records — widened team/player detail, incidents, line counts, added time, extra time, shoot-outs, post-match material, discipline state and season heat maps — so later tasks only fill them.

## impl notes
- Types: copy the interfaces from design §2.3 (Incident, MatchRecord additions), §9.4 (MatchMaterial: four `number[]`), §13.3 (DisciplineState, Ban, Unavailable, CompetitionKey). `World.discipline` and `SeasonArchive.heat` are optional.
- Do not touch `MatchEvent`/`MatchFrame`/`MatchPlayback` here — they change in T218.
- Schema bounds (zod; reuse the file's `number`, `id`, `score` helpers):
  - incident: `minute` int 1–130, `added` int 0–15 optional, `side` 0|1, `kind` enum of 5, `player` id, `other` id optional, `reason` enum of 6 optional; `incidents` max 120.
  - `lineCounts`: tuple of two ints 0–30; refine: `lineCounts[0] + lineCounts[1] === players.length` when present.
  - `added`: array of ints 0–15, length 2 or 4.
  - `regulation`, `shootout`: the existing score schema; `Fixture.shootout` the same, optional.
  - material: `shots` max 7×80 ints, `heat` max 40×34 ints, `network` max 3×30 + 3×300 ints, `report` max 60 ints; all non-negative ints ≤ 100000.
  - discipline: `year` int; `yellows` record of id → partial record of competition key (string matching `league|europe|cup:.+`) → int 0–60; `bans` max 5000 of { player id, club id, matches int 1–10, scope string, reason enum of 8 }; `out` max 20000 of { player id, club id, until { year, day } }.
  - `SeasonArchive.heat`: record of id → array of exactly 40 ints 0–1000000.
- `detailConsistent` (schema.ts ~L971): add `crossesCompleted ≤ crosses`, `throughBallsCompleted ≤ throughBalls`, `penaltiesScored ≤ penalties` for TD; per player `crossesCompleted ≤ crosses`, `throughBallsCompleted ≤ throughBalls`; when every own line is present, Σ player `yellowCards`/`redCards` = team value.
- Keep `metrics` length 12 everywhere (packing and UI hard-code 12).
- Test data: build one valid record by copying an existing own match from a short simulated season (see existing tests in the file for the world builder) and attach the new fields with small values.
