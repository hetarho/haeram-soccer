## goal
Let enthusiasts inspect and compare their own football experiments outside the app while keeping the prototype local and mobile-friendly.

## acceptance
- [v] CSV rows come from the displayed loaded match scope, explicitly selected current player scope or all completed summaries; each exposes source identity, scope and count.
- [v] Unicode, commas, quotes and newlines round-trip as CSV text; formula-like text is neutralized while numeric facts and integer-money strings are preserved.
- [v] Mobile download controls stay touchable and disabled for unavailable samples; real browser downloads contain correct headers and sample counts.
- [v] The complete repository verification, storage benchmark and current-build browser benchmark pass before final completion.

- [v] Standings preview retains global ranks and own-club context, labels partial coverage and expands to the full source league.

## impl notes
- Keep pure dataset builders separate from the browser download adapter; use existing archive facts without changing saves.
- Name current player snapshots with the current year instead of pretending to provide historical player skill snapshots.
- Include original currency and minor-unit amount columns for completed season finances; never convert them to floating-point money.
- Validate the final accumulated implementation across all supported browser projects and visually inspect representative mobile and desktop views.
