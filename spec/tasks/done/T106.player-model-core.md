  - `PositionLevel` = 3 (최상) | 2 (준수) | 1 (어색); an unlisted position is 미숙. `Positions = Partial<Record<Position, PositionLevel>>`.
  - `Grade` = 1..5 (매우 낮음..매우 높음); `Personality` = { professionalism, adaptability, ambition: Grade }.
  - `PlayTrait` = workrate (활동량), technician (테크니션), playmaker (플레이메이커), speedster (스피드스터), linebreaker (라인 브레이커), targetman (타겟맨), longshot (중거리 슈터), crosser (크로스 전문가), aerial (공중 장악), tackler (태클러), buildup (빌드업), leader (리더).
  - `RoleId` (27, PLAYER-5 order): sweeperKeeper, shotStopper, stopper, coverDefender, ballPlayingDefender, defensiveFullBack, overlappingFullBack, invertedFullBack, defensiveWingBack, attackingWingBack, anchor, ballWinner, regista, boxToBox, mezzala, deepLyingPlaymaker, wideMidfielder, widePlaymaker, attackingMidfielder, shadowStriker, trequartista, traditionalWinger, invertedWinger, targetMan, poacher, falseNine, completeForward.
- engine/src/player.ts (pure; takes an `Rng = () => number` from primitives `random(stream)` for draws):
  - labels: `ATTRIBUTE_LABEL`, `ATTRIBUTE_GROUPS` (PLAYER-2 groups), `POSITION_LABEL` (골키퍼, 센터백, 왼쪽 풀백, 오른쪽 풀백, 왼쪽 윙백, 오른쪽 윙백, 수비형 미드필더, 중앙 미드필더, 왼쪽 미드필더, 오른쪽 미드필더, 공격형 미드필더, 왼쪽 윙어, 오른쪽 윙어, 스트라이커), `ROLE_LABEL`, `TRAIT_LABEL`, `GRADE_LABEL`, `LINE_LABEL` (골키퍼, 수비, 미드필드, 공격).
  - `lineOf(position)`, `mirrorOf(position)` (LB↔RB, LWB↔RWB, LM↔RM, LW↔RW, others themselves).
  - `POSITION_WEIGHTS[position] = { primary, secondary, tertiary }` exactly PLAYER-6's table; `ROLES[id] = { positions, promotes }` exactly PLAYER-5/6 (LB and RB share the full-back roles, LWB/RWB the wing-back roles, LM/RM the wide roles, LW/RW the winger roles).
  - `weightsFor(position, role?)`: Record<Attribute, 0|1|2|3> — primary 3, secondary 2, tertiary 1, other 0, then each promoted attribute one tier up (0→1→2→3, 3 stays).
  - `ovrAt(attrs, position, role?)` = Σ weight × attribute / Σ weight, unrounded; `bestRoleAt(attrs, position)` = the role of that position with the highest ovrAt, first in table order on ties; `mainOvr({ attrs, position })` = ovrAt at the best role.
  - `levelFactor(positions, position)`: 3→1, 2→0.92, 1→0.80, unlisted→0.60. `gainLevelFactor`: 3→1.0, 2→0.8, 1→0.5, unlisted→0.2 (PLAYER-12).
  - `adaptationMultiplier(a)`: clamp a to 0.3–1.0, linear between (0.3, 0.70), (0.4, 0.76), (0.6, 0.88), (0.8, 1.00), (0.9, 1.025), (1.0, 1.05).
  - `PROFESSIONALISM_RATE = [0.70, 0.85, 1, 1.15, 1.30]`, `ADAPTABILITY_RATE = [0.60, 0.80, 1, 1.20, 1.40]`, `AMBITION_UNHAPPY = [0, 0, 0, 0.25, 0.50]` (index grade − 1).
  - `adaptationStart(adaptability, joined: 'founding' | 'academy' | 'domestic' | 'abroad')`: 0.80, 0.80, [0.45, 0.50, 0.55, 0.60, 0.65][g − 1], domestic − 0.10.
  - `adaptationAfter(current, gain, { trainingOnly })`: the part of the gain that lands above 0.80 counts half (split a gain that crosses 0.80); training-only never ends above max(current, 0.80); result ≤ 1.0, rounded to 4 decimals. `MATCH_GAIN = { start: 0.020, sub: 0.008 }`, `TRAINING_GAIN = { recovery: 0.002, balanced: 0.004, hard: 0.007 }`; the caller passes gain = base × adaptability rate × gainLevelFactor × school factor.
  - `managerChangeLoss(a, sameSchool)`: a ≤ 0.50 unchanged, else a − (a − 0.50) × (sameSchool ? 0.10 : 0.30).
  - `overshootFactor(excess)`: excess ≤ 0 → 1; anchors (0, 1), (1, 0.25), (3, 0.10), (5, 0.05), (10, 0.02), interpolated linearly in log(factor) between anchors; beyond 10 → 0.02 × 10 / excess. PLAYER-16's gate (adaptation 0.90+) is the caller's.
  - `AGEING[attribute] = { growUntil, declineFrom, perSeason }` exactly PLAYER-17's table.
  - `SCHOOL_PREFS[style] = { attributes, traits }` exactly STAFF-21; `schoolFactor({ style, neutral }, { attrs, traits, age })` = neutral (founding or interim) → 1.0, else 0.8 + 0.1 per preferred attribute ≥ 65 + 0.1 per preferred trait + 0.1 for age ≤ 21 under 'developer', at most 1.3.
  - `FORMATIONS[tactic] = { name, slots: { position, role }[] }` exactly STAFF-22 in slot order GK, then the DF line left to right, then MF, then FW (3-5-2 lists LWB, CB, CB, CB, RWB as its DF line and DM, CM, CM as MF); `slotLine(tactic, index)`.
  - `personalityRange(grade, scoutAbility | undefined)`: 80+ → [g, g], 60–79 → [g−1, g+1], below 60 or none → [g−2, g+2], clamped to 1–5 (PLAYER-18).
  - generation `generateProfile(rng, position, rating, role?)` → { attrs, positions, personality, traits }:
    - each attribute = rating + offset by its weight at (position, role ?? none) — 3: +4, 2: +1, 1: −3, 0: −10 — + (rng() × 2 − 1) × 9; an outfielder's three GK attributes are 8 + rng() × 12 instead; a goalkeeper's finishing, dribbling and crossing take −20. Then shift every attribute that took the offset rule by (rating − ovrAt) once, clamp 15–95, round to integers. Check the ±1 acceptance over the ovr of the best role (or the asked role).
    - positions: the main at 3; extra count by 1 (25%), 2 (35%), 3 (22%), 4 (10%), 5 (5%), 6 (3%) positions in all (a GK always has only GK); extras drawn in order from `NEIGHBORS[position]` then their neighbours: GK —, CB [DM, RB, LB], LB [RB, LWB, LM, CB], RB [LB, RWB, RM, CB], LWB [RWB, LB, LM, LW], RWB [LWB, RB, RM, RW], DM [CM, CB], CM [DM, AM, LM, RM], LM [RM, LW, LWB, CM], RM [LM, RW, RWB, CM], AM [CM, ST, LW, RW], LW [RW, LM, AM, ST], RW [LW, RM, AM, ST], ST [AM, LW, RW]; each next candidate is taken with 0.7, skipped otherwise; levels: the mirror 3 (15%) / 2 (35%) / 1 (50%), others 3 (15%) / 2 (50%) / 1 (35%).
    - personality: each grade 1..5 at 8 / 22 / 40 / 22 / 8%.
    - traits: count 0/1/2/3 at 20/45/28/7% (rating ≥ 75: 5/35/40/20%); candidates by affinity attribute + rng() × 10 — workrate stamina, technician dribbling, playmaker vision, speedster pace, linebreaker positioning (FW, AM only), targetman strength (FW only), longshot finishing (MF, FW), crosser crossing (wide positions), aerial heading (not GK), tackler tackling (DF, MF), buildup passing (DF, DM, GK), leader any (score rng() × 70); the highest-scoring allowed ones win.
