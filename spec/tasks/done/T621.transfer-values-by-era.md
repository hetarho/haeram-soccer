## impl notes
- The premium is one global table in `MARKET_CONFIG` (every country), applied in `marketValueUnits`, so every value consumer follows: asking fees, incoming bids, listings, loans (10% of value), pre-Bosman compensation, squad value and club valuation (HIST-12).
- Fast fits: price fixed top-flight squads at each year (static OVR, age, potential) before spending career runs; careers then confirm, since the best OVR drifts from about 92 to 95 over a career.
- Leave wages, division shares and the football index alone: the top flight's turnover already measures at real levels (2020s £318m against the Premier League's £315m average), so only fees were off.
- Other countries' currency levels (ITA, FRA and others far below real nominal amounts before 1960 coverage) are a separate catalog matter, not this task.
