## goal
Clubs of one tactic no longer field the same ages in the same places: each club's squad still holds one player of each age from 18 to 35, but its ladder starts at its own point and orders its places its own way.

## acceptance
- [v] one shared helper gives a squad place's age and birth cohort from the seed, the club and the year: `age = 18 + ((year + π(i) + k) % 18)`, `cohort = floor((year + π(i) + k) / 18)`, with k in 0–17 and π a permutation of the 18 places, both drawn from a stream keyed on the seed and the club id; `npcSquad` (world.ts, about line 349) and `replacement` (npc-continuity.ts, about line 97) both use it, and no other copy of the old formula remains
- [v] unit cases: two clubs of one tactic differ in some place's age in the same year; every squad still holds ages 18–35 once each; a place's person (id, name, birth year) is the same across the 18 seasons of his cohort and ages one year a season; the same seed, club and year give the same squad; a first season's squads place keepers and forwards across the age range (inbox suggest 261105 T702)
- [v] identity: person ids keep their `${club.id}:p:${i}:${cohort}` shape with the new cohort; retained people (WORLD-11) keep their stored ids and facts; surnames stay distinct within a run (`names.test.ts`)
- [v] goldens, catalog fingerprints and prepared fixtures that hold generated people are refreshed with their own scripts (`scripts/update-golden.ts`, `scripts/fingerprint-catalog.ts`, and whatever regenerates `tests/fixtures` worlds), after checking that the diff is limited to generated people's ids, names, ages and the facts that follow from them; the refreshed files are listed in the result
- [v] the day-loop equivalence tests pass: `pnpm exec vitest run --project integration packages/engine/src/calendar.progression-eng.test.ts packages/engine/src/season.test.ts packages/engine/src/full-model-throughput.test.ts` (a recorded digest that moves is re-recorded only with the diff explained in the result)
- [v] `pnpm run typecheck`, `pnpm run lint`, `pnpm run format:check`, `pnpm run validate:i18n`, `pnpm exec vitest run --project unit --changed "$GUSTA_DIFF_BASE" --passWithNoTests`
