# T723 incremental typecheck and cached format check
> st:done@261109 | ssot:ARCH-22 ARCH-30 | base:ARCH@33 | dep:- | touches:package.json | lane:dev-cost

## goal
Repeated task checks reuse the previous typecheck and format work in the same checkout, so a warm `pnpm run typecheck` and `pnpm run format:check` take seconds instead of about 27 s and 18 s, while a fresh checkout or CI behaves exactly as before (review/gusta-self-improve-261109 F4).

## acceptance
- [v] `typecheck` runs `tsc --noEmit --incremental --tsBuildInfoFile .tmp/tsc/tsbuildinfo` (or the equivalent that works with this tsconfig); `format:check` adds `--cache --cache-strategy content --cache-location .tmp/prettier-cache`; script names unchanged, caches only under the gitignored `.tmp/`
- [v] still strict: with a warm cache, an introduced type error fails `typecheck` and an introduced formatting error fails `format:check` (each checked, then reverted)
- [v] cold and warm timings of both scripts recorded in result

## impl notes
- ESLint's cache stays off: the local i18n rule plugin's changes might not invalidate it.
- Worktrees share `node_modules`, which is why the caches belong in each checkout's `.tmp/`.
