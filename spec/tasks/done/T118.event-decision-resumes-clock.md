## goal
An event that stops a running clock is decided on its card; the decision plays the clock on once no stopping event is left (owner's report 261015: "선택을 해도 계속 멈춰있어"). A choice that opens another view leaves it stopped.

## acceptance
- [v] after an event stops a running clock, 확인, accept/reject, 역제안 accept/reject, 감독 재계약 and 모두 재계약 resume it when no other stopping event waits; with another waiting, it resumes after the last
- [v] …보기, 협상하기, 하한 제시하기 and 자동 결정 설정 leave it stopped; a clock the owner stopped himself, or that stopped for anything else, never restarts on a decision
- [v] tests: unit (two events, the owner's pause); e2e at level 1 deciding the first non-eve event resumes the clock

## impl notes
- ProgressionController: `resumeAfterEvents` set when a tick stops for a fresh event, cleared by every stop and start; `eventDecided()` starts the clock when set and `stoppingEvents` is empty.
- EventCenter: `decide(item, action?)` runs the action, reads the item, then calls `eventDecided()`.

## result
- outcome: a tick that stops for a fresh event marks the clock to resume; every card decision (확인, accept/reject, 역제안 accept/reject, 감독 재계약, 모두 재계약) reads the item and calls `eventDecided()`, which starts the clock once no stopping event is unread; any other stop or start clears the mark; 보기/협상하기/하한 제시하기/자동 결정 설정 leave the clock stopped
