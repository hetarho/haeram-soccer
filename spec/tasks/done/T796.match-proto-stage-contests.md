## goal
The ball changes sides the way the script says without anyone teleporting: the named opponent gets to the pass or the carrier in time (cued one beat ahead, replaced by a nearer man or given a lunge only when he cannot), balls leave play and come back through a dead-ball scene, and a pressed pass shows its presser.

  ```ts
  export interface CutPlan {
    opponent: number;
    /** Where on the ball's path he meets it, and its 0–1 position along the path. */
    point: Vec; param: number;
    /** Seconds after the kick at which the ball is there. */
    time: number;
    /** His time to get there minus `time`; ≤ stage.cutSlack means he makes it. */
    margin: number;
  }
  export function planCut(state: StageState, opponent: number, from: Vec, to: Vec, flight: number, range: readonly [number, number], boost?: number): CutPlan;
  export function resolveCut(state: StageState, scripted: number, from: Vec, to: Vec, flight: number, range?: readonly [number, number]): { plan: CutPlan; flight: number; recast: boolean; stretch: boolean };
  export function nearestOpponent(state: StageState, index: number): { index: number; distance: number }; // outfield opponents of that player's team
  export function cueNext(state: StageState, ctx: BeatContext, at: Vec): void;
  ```
  - `planCut`: `{ point, t } = closestOnSegment(from, to, opponentPos)` with `t` clamped to `range`; `time = t * flight`; `margin = timeToReach(body, point, sprint + (boost ?? 0)) - time`.
  - the range, unless `resolveCut` is given one, is `[stage.keeperCutMin, 1]` for a keeper and `[stage.cutMin, stage.cutMax]` otherwise.
  - `resolveCut`: (1) the scripted opponent's plan when its margin ≤ `stage.cutSlack`. (2) else the plan with the smallest margin among the scripted opponent's outfield teammates (the keeper too when the scripted opponent is the keeper); when that margin ≤ slack → it, `recast: true`. (3) else, among the scripted opponent and those teammates, the plan with the smallest margin computed with `boost = stage.lunge` → `stretch: true`, `recast` when it is not the scripted one; if even that margin is above the slack, lengthen the flight: `flight = min(dist(from, to) / ball.minSpeed, (plan.time + plan.margin - stage.cutSlack) / plan.param)` and recompute `plan.time = plan.param * flight`. Ties go to the lower index.
  - `cueNext` (called when a beat's ball is on its way or its carrier is running, `at` = where the ball will be when the beat ends): nothing when there is no `next` or `next.team !== beat.team`. When `next.reason === 'pressed'` set `state.tight = true`. When `next.opponent` is an outfield player: for `next.outcome === 'intercepted'` order him `{ target: lerp(at, next.to, stage.shadowAt) + norm(ownGoal(his team) - that point) * stage.shadowOff, pace: 'run' }`; for `tackled`, `foul`, `blocked`, or a `takeOn` of any outcome order him `{ target: at + norm(ownGoal(his team) - at) * stage.jockey, pace: 'run' }`. These go into `state.cues`, not `state.orders`, so they outlive the handler's `orders.clear()` until the next beat starts.
