## goal
Before a match the owner sees who the manager put on the bench and on set pieces, who is out and why, the era's substitute rule, and a tactic lab that reads the same numbers the engine plays.

## acceptance
- [v] The preparation dialog shows, under the formation, the named substitutes (`benchFor` for the next own fixture), the penalty, direct free-kick and corner takers (`takersFor`), and unavailable players with reason (injury days or ban matches and scope) — all read-only (the manager decides, MATCH-20/CLUB-6).
- [v] The era rule line: e.g. `교체 명단 9명 · 최대 5명 교체 (3회)`, `교체 없음 (1965년 이전)`, `부상 교체 1명` (from `eraRules(w.year)`).
- [v] `compareTactics` uses `ownTacticalProfile(w, players, tactic, opponent)` so manager style and synergies are included (MATCH-9), and `TacticalLab` shows each tactic's formation with the lineup (WEB-21) using `FormationPitch`.
- [v] `tacticComparison.test.ts` `includes the manager style in the lab` (a style with pass +2 changes the shown pass modifier by 2); e2e `analysis.spec.ts` `compares tactical rules as previews…` updated and passing.
- [v] typecheck and lint pass.
