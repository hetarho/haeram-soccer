# T133 Readable pixel typography and spacing
> st:done@261015 | ssot:WEB-38 WEB-10 WEB-17 | base:WEB@77 | dep:- | touches:apps/web/src/ui apps/web/public/fonts

## goal
Restore the pixel-game identity while improving reading size, contrast, hierarchy and spacing in the actual interface.

## acceptance
- [v] Self-hosted Galmuri14 reading text and Galmuri11 Regular/Bold labels/headings replace the local Pretendard trial; font terms are bundled.
- [v] Primary reading text is 15px with line height at least 1.7; supporting copy is at least 12px and meets 4.5:1 contrast without group opacity.
- [v] Training focus options, coach explanations, player training/adaptation lists and page/HUD labels use clear spacing and wrap on phones.
- [v] Existing founding, training, mobile and match geometry/navigation cases pass across Chromium, Firefox and WebKit; inspect actual phone/desktop captures and loaded fonts.
- [v] Type/lint/format and production build pass; preserve the charcoal/grass-green palette, pixel art and icons, fixed shell, game behaviour and save data.

## impl notes
- Use Galmuri14 at its native 15px reading size and Galmuri11 at 12px for compact labels; use its real bold face for emphasis rather than synthetic bold.
- Keep large headings and key values distinct, remove dense negative tracking and normalise sub-12px supporting text. Allow vertical scrolling where longer readable text needs it.
- Verify the existing journeys rather than add implementation-mirroring CSS unit tests. Capture representative home/training/people/dialog screens.
- This local design iteration continues T132; leave the user's world and dev process on port 19500 alone and verify on a separate built preview.
