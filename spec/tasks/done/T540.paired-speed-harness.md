## goal
Commit the paired A/B harness ARCH-34 judges speed-ups with, and show on same-tree runs that it calls no difference.

## acceptance
- [v] `node scripts/perf/ab.mjs --base <ref|dir> [--cand <ref|dir>] --workload grid|aggregate|day [--procs n --reps n --warm n --seed s --json out]` bundles each side's `scripts/perf/workloads.ts` from a scratch copy of its own `packages/` with esbuild, runs `--procs` processes of `pair.mjs` (both bundles loaded in one process, reps alternated A B / B A, the side loaded and built first alternating across processes) and prints per label (`grid`, `aggregate`, `own`/`other` days) the medians and the CPU and wall calls, `sameBundle` and `sameHash`.
- [v] `--base HEAD --cand HEAD` gives `sameBundle: true`, `sameHash: true` and call "no difference" for `aggregate` (16 processes) and `grid` (16 processes); intervals and host load recorded in result.
- [v] `scripts/perf/stats.test.ts` (unit): `trimmed` drops an eighth of the values at each end from 8 values on and none below; `verdict` calls "faster" on logs all near −0.05, "slower" near +0.05, "no difference" on logs spread around 0; the same input gives the same interval twice.
- [v] typecheck, lint, format:check and `pnpm exec vitest run --project unit scripts/perf/stats.test.ts` pass.

## impl notes
- Port the session's working harness (`../haeram-soccor-perf/scripts/perf/`); move `median`, `trimmed`, `verdict` into `scripts/perf/stats.ts`, imported by `ab.mjs` directly (Node 24 strips types; erasable syntax only).
- esbuild 0.28.2 becomes a direct devDependency (already in the lockfile through tsx; no new download).
- Defaults: `grid` 16 processes × 18 reps after 6 warm (one fixture a rep, in turn), `aggregate` 16 × 20 after 4, `day` 4 × 60 after 0. Primary measure main-thread CPU (`process.threadCpuUsage`), wall beside it.
- Measured 261028 while building it (shared 12-CPU host, load 7–14): one side per process gave A/A intervals ±3% (aggregate) and ±5% (grid); in-process pairing with a fixed load order and bundles differing only in path comments read the same tree 0.987 (0.975–0.998), i.e. a false "faster"; with identical bundles and alternating load order aggregate A/A read 0.999 (0.990–1.007). V8 `--single-threaded` raised process spread (CV 3.0% → 7.4%) and is not used.
