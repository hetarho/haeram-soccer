## result
- outcome: completed. New leaf `apps/web/src/adapters/identityPacking.ts` exports `PackedAppearances` `{ version: 1, values, refs }`, `packAppearances(matches)` and `readAppearances(stream, records)`. `packAppearances` returns nothing when no record has an appearance; otherwise it interns each snapshot once by `canonical(snapshot)` in first-occurrence order, literal colour spelling kept, with one ref per record (0 absent, n = `values[n-1]`). `readAppearances` first rejects a newer stream or snapshot version (`SaveCompatibilityError`, via `assertAppearanceFormatVersion` per entry, before any structural check, so a newer game is never called corrupt). It then rejects as corruption: any other version, more than 100,000 values or more values than records, a ref count other than the record count, negative, fractional, text, out-of-range, skipped or unused refs, duplicate values, values failing the strict `matchAppearanceSchema`, and sides other than the rebuilt record's home then away. All of this is checked before anything is attached; each record then gets its own `structuredClone` and ref-0 records keep no appearance key. `packing.ts` adds the optional `Packed.appearances` beside the other match streams and calls `readAppearances(p.appearances, matches)` right after the own records are rebuilt from their columns. `Club.identity` and `World.kitChoice` stay ordinary packed-world JSON fields; no other stream, budget or retention changed. `docs/SAVE-FORMAT.md` documents the side channel, its checks and the size measurement. Measurement (tsx scratch, one simulated season, seed `identity-command`): 32 own matches, 31 distinct snapshots, 15,505 canonical characters of side channel; the encoded checkpoint grows from 66,587 to 67,235 characters (+648), with an exact canonical round trip. Running `scripts/update-golden.ts --write` and then Prettier leaves `tests/fixtures/portable-v1.json` byte-identical, because its facts project only sporting data (scores, metrics, players, money, events): this confirms T240–T243 changed no sporting fact, and the file is therefore not modified. Build: the codec worker grew 1,630.91 → 1,633.22 kB raw and the engine worker 1,996.31 → 1,997.64 kB; entry and lazy chunks are unchanged.
