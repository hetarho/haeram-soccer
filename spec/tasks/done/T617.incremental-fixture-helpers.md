## goal
Retain unchanged generated rosters on fixture helpers by replicating ordered record changes, preserving fixture results, single-writer settlement and the existing fallback.

## acceptance
- [v] Behaviour unchanged: existing helper-pool/client/host tests remain applicable; engine entry points and save/model versions stay compatible.
- [v] A pure read leaf owns the fixture-copy key/types and roster-input signature; existing round-jobs exports remain compatible. The client helper configuration imports no engine orchestration.
