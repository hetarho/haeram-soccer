The owner opens `/lab`, generates and edits both sides, edits engine numbers, runs simulations and compares each run against a pinned baseline.

## impl notes
- Korean labels; value paths shown as code. Plain React + CSS module like the game; no new dependency. The lab page imports only tunables.json, protocol.ts, `LAB_CONFIG`/types from sides.ts if sides.ts stays a read leaf (it imports makePlayer → world generation: so generation happens in the worker through protocol.ts's `generate`/`setOvr` messages (T574); keep the page free of engine runtime imports, ARCH-4).
- Layout: two columns on desktop (sides | values) with the run bar and results below; single column under 900 px. No game chrome, theme or save code.
- Kept run record: `{ id, at, count, runSeed, sides (seed, tactic, average, spread, ovrs), overrides, summary }`.
