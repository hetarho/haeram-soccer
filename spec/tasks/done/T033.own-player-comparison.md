## goal
Let football enthusiasts assess rotation and player profiles side by side on a mobile screen.

## acceptance
- [v] Two selectors cannot compare the same ID and both production panels use the same selected scope.
- [v] Career mode retains sold and retired identities with explicit status; current-season mode selects active players only.
- [v] Mobile selectors and close controls meet touch bounds, focus returns to the opener, and comparison leaves the game date unchanged.

## impl notes
- Use the existing Dialog and PlayerPerformance components; compare existing attributes with accessible progress bars.
- Derive valid selected IDs on every render so roster changes cannot leave stale or duplicate selections.
- Initialize scope from the roster selection and keep the comparison's shared scope as UI-only state.

## result
- outcome: Own-player comparison exposes distinct identities, role skills, fatigue and shared-scope production without affecting gameplay.
