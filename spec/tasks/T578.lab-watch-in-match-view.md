## goal
On `/lab`, 관전 plays one match between the current sides with the current values and shows it in the game's unchanged `Pitch` component; 다시 보기 replays the same match with edited values, 새 경기 a new one.

- [ ] Pool: `LabPool.watch(seed, sides, overrides)` and `LabPool.world()` (fetched once and cached) on worker 0; a newer watch makes an older pending one resolve as superseded. pool.test.ts covers both.
- [ ] Page: `apps/web/src/ui/Pitch.tsx` is imported and rendered as is (no fork, no wrapper restyling) with `playback` and the lab `world`; its `actions` slot holds 다시 보기 and 새 경기. ## impl notes
- Refactor playLabMatch so it and watchLabMatch share one setup builder (`labSetup(lab, sides, seed, index, observe)`); keep every T572 digest.
- Overrides reach what the worker computes (match and frames). Presentation constants the page's own modules read (e.g. `MATCH_MOTION_CONFIG`, `PLAYBACK_CONFIG` values Pitch/figure code imports) stay at code values on the page; list in result limits which tunable groups this affects, and mark those groups in the values panel as "관전 화면에는 적용 안 됨" if the page can tell them apart (they are the groups whose leaves the page bundle reads; the worker's probe already shows what the engine reads).
- startPresentation.tsx: move the controller construction and provider rendering from apps/web/src/main.tsx into `startPresentation(root, children)` (same dynamic imports, so the game's initial chunk does not grow); apps/web/src/main.tsx calls it with `<App />` and `<PresentationSettings />`, the lab with `<LabPage />`. Import the same CSS (theme.css, imageUi.css, themeTransition.css) the game entry imports.
- The world crosses once (about 2.5 MB structured clone); keep it in page state, not localStorage.
- Pitch may call `onFinish`/`onPlaybackStart`; the lab needs neither. Pitch reads `world.clubs` for names/crests, `clubManager(world, club)` for the details panel and `MatchReport` for match details: all work with the lab world.
- Layout: the match view on top at full width when watching; sides | values below on desktop, single column under 900 px. No game chrome (HUD, tab bar, saves).
