## goal
A cup tie level after 90 minutes plays 2 × 15 minutes on the same engine and then a kick-by-kick shoot-out; ties are decided by what was played, never by a coin.

## acceptance
- [ ] Grid: with `setup.decide`, after period 2 the engine checks level (design §8.4: aggregate with `decide.first`, away goals when `decide.awayGoals`) and plays periods 3 and 4 (15 minutes each, added 0–3, substitutions allowed by era); still level → `shootout.ts` runs five kicks each then sudden death, order by 0.6 슈팅 + 0.4 침착성 among players on the pitch with the keeper last, each kick `resolvePenalty`.
- [ ] Record: `score` includes extra-time goals, `regulation` = 90-minute score, `shootout` = kicks scored, `added` has 4 entries, `metrics[side][10] = 120` and players' minutes count extra time; the existing highlight `{ minute: 120, side, player: '승부차기', action: '승부차기 홈 승리' | '승부차기 원정 승리' }` is pushed for the winner.
- [ ] Summary path: the same decision rule; extra time = 30 more team-level minutes of the existing minute model; shoot-out kicks scored with p = 0.76 each from `random(`${w.seed}:shootout:${f.id}`)`.
- [ ] Plumbing: `simulateMatch(..., decide)` → `playFixture(w, f, settlement, observe, decide?)`; cups and Europe pass `decide` for a single-leg tie and for the second leg of a two-legged tie (`first` = first-leg score oriented to this fixture, `awayGoals` = Europe and `w.year < 2021`); `resolveTie` (playoffs) passes `{ awayGoals: false }`. Fixtures get `f.shootout` when a shoot-out was played.
- [ ] `decideTie` and `resolveTie` decide by aggregate, away goals, then `f.shootout`; the coin-flip code is removed (4.0.0 has no unrecorded ties); `CupFinal.decided = 'pens'` and bracket outcome bits still set as today.
- [ ] Tests: `shootout.test.ts` (`plays extra time only when level`, `respects away goals before 2021`, `alternates kicks and goes to sudden death`, `orders takers by skill with the keeper last`, `scores about 76% of kicks between equal sides`); `knockout.test.ts` (`decides a level cup tie by the played shoot-out`, `keeps the shoot-out highlight for the UI`).
- [ ] `pnpm exec tsx scripts/update-golden.ts --write`; typecheck, lint, unit and contract tests pass.
