## goal
The amateur level swaps places with the last professional division in one exchange: the bottom two of each last-division group for as many amateur clubs, chosen by the amateur table while the own club plays in it.

## acceptance
- [v] promote(): in the own country, for a season the own club played in the amateur league, the entrants are the amateur table's top (places − 1) plus the winner of a playoff among the next four (`tournament`, key `lower-promotion`, archived as now →LEAGUE-4); places = clubs relegated from the last division (two per group).
- [v] The own club among the entrants goes up like any of them: `w.lower = false`, tier = last, the promotion event (프로 무대 입성 / 프로 무대 복귀) as now.
- [v] The separate replacement block after promote() in closeSeason (the `ranked(...).at(-1)` drop) is removed; no club is relegated twice in one close, and a club relegated into the last division in this close never drops to the amateur level in the same close.
- [v] Countries and seasons without a played amateur league keep the strength order.
- [v] season.test.ts: own club champion → promoted with exactly the bottom two of the last division relegated and entrants = table top + playoff winner; own club third → plays the playoff; ITA (three last-division groups) gets six entrants and keeps every group's capacity; no double relegation (the former ITA:1:0:2 and GER:1:0:15 cases).
- [v] world.test.ts capacity conservation still passes.
- [v] `pnpm run typecheck && pnpm run test:unit` pass.
