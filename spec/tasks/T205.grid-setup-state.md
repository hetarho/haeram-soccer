## goal
Build everything a grid match needs before kick-off from the same strength/form/shift computation the current engine uses, and a match state with positions and the per-player skill function.

## impl notes
- `prepareMatch(w, f): Prepared` returns the existing `MatchSetup` fields plus `{ teams: [Club, Club]; ownSide?: 0 | 1; style?: StyleEffects; synergy?: SynergyEffects; squads: [Player[], Player[]] }`. Move code, do not change arithmetic or the order of `random(...)` construction.
- `grid/spots.ts`:
  ```ts
  export const SPOTS: Record<Tactic, readonly Point[]>;   // MATCH_MOTION_CONFIG.formations[t][slot] mapped [u·1.05, u·0.68] (side 0 attack frame, metres)
  export const ROLE_SHIFT: Partial<Record<RoleId, readonly [number, number]>>; // roleShift × [1.05, 0.68]
  ```
  Copy the numbers from `motion.ts` `MATCH_MOTION_CONFIG.formations`/`roleShift` (do not import motion.ts — it is replaced later); add a test that they equal `MATCH_MOTION_CONFIG` values × the factors while motion.ts still exists.
- `grid/setup.ts` (types from design §3.2):
  ```ts
  export interface EraRules { named: number; maxSubs: number; injuryOnly: boolean; windows: number | undefined; cards: boolean }
  export function eraRules(year: number): EraRules;
  export interface Takers { penalty: number; directFreeKick: number; corner: number }   // roster indexes
  export function takersFor(xi: readonly Player[]): Takers;
  export function benchFor(w: World, club: Club, xi: readonly Player[], era: EraRules, unavailable?: (p: Player) => boolean): Player[];
  export interface StyleBend { pass: number; possession: number; shot: number; defense: number; lineHigh: number; lineLow: number }
  export interface SubPolicy { fatigueFrom: number; laterFrom: number; earlyPress: boolean; protectLead: boolean; chaseWhenBehind: boolean; youth: boolean; data: boolean; delay: number }
  export const DEFAULT_SUB_POLICY: SubPolicy = { fatigueFrom: 60, laterFrom: 70, earlyPress: false, protectLead: false, chaseWhenBehind: false, youth: false, data: false, delay: 0 };
  export interface DecideRule { first?: Score; awayGoals: boolean }
  export interface GridSetup { /* exactly design §3.2 */ }
  export function buildGridSetup(w: World, f: Fixture, opts: { observe: boolean; recordPlayers: boolean; decide?: DecideRule }): GridSetup;
  ```
  - `cards = year >= 1970`.
  - bench (design §3.2): own club from `activePlayers(w)` minus the XI, minus `isInjured`, minus `unavailable` (T219 passes bans); NPC from `squad(w, club)` places 11–17 in order, minus `unavailable`. Take `era.named` players.
  - takers: indexes into the XI by the keys of design §3.2 (ties: lower index).
  - bends: own side from `prepareMatch().style`/`synergy` (`pass, possession, shot, defense` = style + synergy; `lineHigh` = style.lineHigh + synergy.lineHigh; `lineLow` = style.lineLow); NPC side all zero.
  - `managers`: both `DEFAULT_SUB_POLICY` here (T214 derives the own manager's).
  - `r`: the same `random(`${w.seed}:match:${f.id}`)` stream object as `prepareMatch` creates (the grid engine replaces the duel chain, so it owns the stream).
- `grid/state.ts`:
  ```ts
  export interface GridPlayer { side: 0 | 1; idx: number; player: Player; slot: number; pos: [number, number];
    onPitch: boolean; yellow: boolean; sentOff: boolean; injured: boolean; onAt: number; offAt?: number;
    base: Float64Array; run?: { kind: 'behind' | 'overlap' | 'box'; until: number; target: [number, number] } }
  export interface GridState { setup: GridSetup; players: [GridPlayer[], GridPlayer[]]; ball: [number, number];
    owner?: [0 | 1, number]; possession: 0 | 1; period: 1 | 2 | 3 | 4; t: number; elapsed: number; score: [number, number];
    lastRegain?: { side: 0 | 1; at: number }; lastLoss?: { side: 0 | 1; at: number } }
  export function createState(setup: GridSetup): GridState;
  export function skill(s: GridState, side: 0 | 1, idx: number, a: Attribute): number;
  export function minutesOn(s: GridState, gp: GridPlayer): number;
  export function enterSlot(s: GridState, gp: GridPlayer, slot: number): void; // recompute base for that slot
  ```
  - `pos` is in the engine frame (design §1.1). Kick-off: each starter at its `SPOTS` point in its own attack frame with x capped at 50, converted with `attackFrame(side, …)`; bench players `onPitch:false, slot:-1`. Ball at (52.5, 34), `owner` = side 0's first FW-line slot (`lineOf(slot.position) === 'FW'`), `possession` 0.
  - `base[a]` (index = `ATTRIBUTES.indexOf(a)`) per design §3.3 using `levelFactor`, the side's `multiplier`, `fatigueLoad`, `unhappyPenalty` from `world.ts`/`player.ts`.
  - `skill = base + shift[side] − drainRate × minutesOn`; `drainRate = (100 − attrs.stamina)/12 × (pressing ? 1.3 : 1) × drain[side] / 90`; `minutesOn = (elapsed − onAt)/60` (elapsed = match seconds since kick-off across periods).
