## result
- outcome: completed. New engine leaf `packages/engine/src/identity-legacy.ts` holds the old `crestMap` algorithm unchanged as `legacyCrestMap` (own club probed first, odd-stride probing over ID order, nearest-palette own primary kept in its stored spelling, the WeakMap cache keyed on the clubs array and invalidated by seed, player club and own colour) with `LegacyCrest` (required primary/secondary), `luminance`, `contrast`, `inkOn`, `colourDistance`, `CREST_PAIRS`, `CREST_FIELDS` and `CREST_COMBINATIONS`; catalog constants and part types come from `packages/contracts/src/identity.ts`; it imports only the contract leaves and `./primitives`. `apps/web/src/ui/crests.ts` is a facade: re-exports the catalog, parts types and colour helpers, `Crest = LegacyCrest`, `crestMap` delegates to `legacyCrestMap`, and keeps `crestOf`, its fallback crest and `kits` (grass/clash rules) as before. New `identity-legacy.test.ts` (11 cases) freezes literals recorded from the original module before the move: nine club IDs (ENG:club, ENG/ESP/GER/ITA domestic, euro:0/42/159) plus a whole-map digest and a domestic-only digest for seeds crests/legacy-a/legacy-b and the mixed-case own colour `#3A7bC2`, the unreadable-own-colour and ownerless maps, a seed (s6) where own-first probing decides a contested field, colour-maths values and pair-table digest; relation cases cover own-first key order, unchanged domestic crests after `ensureRepresentatives`, an untouched world and identical re-created world, cache invalidation on an own-colour change, and the leaf's import list. `crests.test.ts` is unchanged.
