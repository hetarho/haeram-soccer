## impl notes
- Why the cases fail (inbox 261107): `playerWorth` raises the Ballon d'Or factor to `starPaySpread(country, year)` (contracts.ts:326), which is 0 for England through 1960 (`STAR_SPREAD_CONFIG.own.ENG`), so the 1950 England world's ×2 winner reads ×1 (98731 against 197462); and under LEAGUE-10's means level with ECON-36's competition money no club nobody owns owes anything after 1930/31, so `find` returns nothing. The rules are as specified; the cases assumed the released ones.
- Spread override: a local helper beside the describe, as `market-prices.test.ts`'s `withSpread` does: keep a shallow copy of `STAR_SPREAD_CONFIG`, `Object.assign` the table for the run, restore it in `finally`. Modern: `{ shared: [[2008, 1]], own: {} }` (every year up to 2008 then reads 1). Shared alone: `{ own: {} }` over the kept table.
- Build every world (`talking(80)` for winner, second, faded and kept) before entering an override, and read only terms, worths and contract talks inside it: a world built under an overridden table could be stored in the shared test-world cache (`tests/fixtures/worlds.ts`) under the released key.
- Wages at OVR 80 never move with s (CLUB-48), so `marketWage` reads the same on every table; only the premium changes, which keeps the ×2/×1.4 expectations exact at s = 1.
- Prepared debt: `pricedClubs(w).find((priced) => BigInt(priced.club.books?.cash ?? '0') > 0n && pays(w, priced, fortune))`, then `debt = books.cash` and `club.books = { ...books, cash: '0', debt }` on that club (the object in `w.clubs`), before `takeOver`. The books' cash is already in the money of the season in play (`settleNpcBooks` carries it), so the debt is too, and the close keeps cash to `CLUB_BOOKS.cashSeasons` of income, below the `CLUB_BOOKS.debtSeasons` write-off: a state ECON-36's close can leave. A debt lowers the price (ECON-37), so the club stays affordable. Import `takeoverLoan` from `packages/engine/src/takeover` beside `takeOver`.
- Alternatives not taken: the expected worth computed through `factor ** starPaySpread(...)`, which restates the implementation; moving the lived world's year to 2008, which its calendar, catalogs and history do not follow; living the ownerless world more seasons until a club owes, which the means level may never leave and which ties the case to the economy's outcome; dropping the loan assertions, which loses SAVE-27's loan round trip.
