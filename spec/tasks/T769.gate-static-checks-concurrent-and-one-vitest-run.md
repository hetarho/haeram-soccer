# T769 run the gate's static checks concurrently and its three vitest tiers as one run
> st:todo | ssot:ARCH-22 ARCH-30 | base:ARCH@34 | dep:- | touches:scripts/verify.mjs | lane:gate-vitest

## goal
`pnpm run verify:batch` and `pnpm run verify` spend no time on idle cores between stages: the static stages run side by side before the tests, and unit, integration and contract run as one vitest run, while every check, case, timeout and per-tier report stays as it is.

## acceptance
- [v] typecheck, lint, format:check, validate:catalogs, validate:presentation, validate:i18n and build start together; the tests start only after all of them pass, and a failing static stage fails the gate with its own exit code and output
- [v] one `vitest run --project unit --project integration --project contract` replaces the three tier runs; `.tmp/verification/{unit,integration,contract}-results.json` are still written, split by `testTier()`, with the same case counts as three separate runs (unit 2316, integration 1183 including its 4 existing skips, contract 46 on 6fc0813d)
- [v] each project keeps its own `testTimeout`; no test selection, retry or timeout changes; browser stage unchanged (batch: Chromium; full: every browser)
- [v] `.tmp/verification/latest.json` still records every stage's command, start, finish, elapsed time and exit code, and `passed` only when every stage passed
- [v] `pnpm run typecheck`, `pnpm run lint`, `pnpm run format:check`; the split reports are checked once against separate tier runs' case counts (`vitest list` per project is enough)

## impl notes
- from review/test-gate-time-261110 F3
- Static stages are mostly single-threaded (typecheck 65.7 s, format 42.3 s cold, lint 21.7 s); keep them out of the vitest phase so they do not contend with the 30 s unit limit.
- Vitest puts all three projects in one pool when they share group order and worker count (`node_modules/.pnpm/vitest@5.0.3*/dist/chunks/index.DpLw24bj.js:11866-11925`).
- Console output is development-tool copy (AGENTS.md): reuse the existing `Recorded …` line shape; add no new prose.
- T771 adds the world warm-up hook to this runner; keep the runner easy to extend with a background job that starts with the vitest phase.
