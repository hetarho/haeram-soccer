# T963 The first leg of a tie at index 2 is a first leg
> st:todo | ssot:MATCH-22 | base:MATCH@68 | dep:- | touches:packages/engine/src/knockout.ts packages/engine/src/competition-keys.ts | lane:- | explore:- | run:claude/sonnet@medium

## goal
Two-legged ties recognise their legs by the fixture's leg field, not an id ending in ':2', so the first leg of the tie at index 2 (e.g. `1990:cwc:k2:2`) is no longer played as a single match with penalties.

## acceptance
- [ ] Unit test: in a two-legged round with at least three ties, the first leg of the third tie draws without penalties and the second leg decides on aggregate; single-match rounds still go to penalties on a draw.
- [ ] Simulation results move on purpose: affected fixtures this change moves are regenerated and named in the result; the portable golden (`pnpm exec tsx scripts/update-golden.ts --write`) and integration expectations are handed to the batch gate in result limits, not run here.
- [ ] Task-tier checks pass through `npx @haeram/gusta vibe check --tier task`.

## impl notes
- `tieRule` (knockout.ts:124) is the only reader of the ':2' suffix; read the leg from the fixture data the draw already writes (or add an explicit leg number where fixtures are created).
- Cause (mapped 261118): first-leg tie ids are 0-based `${year}:${key}:k${round}:${t}` (competition-keys.ts `tieId` L23-31), so tie t=2's first leg also ends in `:2`; `tieRule` (knockout.ts L119-137) then treats it as a second leg, finds no first leg and plays it to a winner. The return leg id is made at knockout.ts L85 (`${first.id}:2`). Callers: cups.ts:187/202, europe.ts:221; `legsOf` competition-keys.ts L60. Make the leg explicit rather than inferred from the suffix.
