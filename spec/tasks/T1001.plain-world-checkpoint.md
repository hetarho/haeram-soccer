## goal
A checkpoint stores `JSON.stringify(world)` gzipped, in a new checkpoint container 5 that is the only supported one; the compact packing is no longer on the save or load path.

## acceptance
- [ ] `encode` writes the bytes of `JSON.stringify(w)` with envelope `schema: PLAIN_WORLD_CHECKPOINT_SCHEMA` (5); `decode` parses that JSON, runs `assertIdentityFormatVersions`/`assertMatchModelFormat` and `validateWorld(value, LOAD_CATALOG)` and the existing world/envelope consistency checks.
- [ ] Any other container number (1–4, `compact1` payloads) or unknown future number is a `SaveCompatibilityError` (protected, exportable), unit-tested.
- [ ] Round trip on the cached ten-season world: `canonical(decode(encode(w)).world) === canonical(w)` (existing `persistence.long-career.test.ts`/`persistence.test.ts` cases, adapted); a world with the match model and manager history round-trips in the same container.
