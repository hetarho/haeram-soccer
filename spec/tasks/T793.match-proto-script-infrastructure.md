## goal
`generateScript(seed)` produces a continuous, validated list of beats (the probabilistic script) from a pluggable table of moves, with turnovers, restarts, a continuity validator and script statistics; this task ships the machinery with four basic moves, T794 adds the football catalogue.

- `script/cast.ts` — who plays a part:
  ```ts
  export interface CastRule { role?: RoleId; position?: Position; line?: Line; w: number }
  /** Weight of a player under the rules: a matching role rule wins, else a matching position rule, else a matching line rule, else 0. */
  export function ruleWeight(p: PlayerSpec, rules: readonly CastRule[]): number;
  /**
   * One teammate of the holder (never the holder) drawn by `ruleWeight × extra(index)`; undefined when every weight is 0.
   * `extra` defaults to 1; it must return a finite number ≥ 0.
   */
  export function castReceiver(state: ScriptState, rules: readonly CastRule[], extra?: (index: number) => number): number | undefined;
  /** Whether `castReceiver` would find anyone (draws nothing). */
  export function canCast(state: ScriptState, rules: readonly CastRule[], extra?: (index: number) => number): boolean;
  /**
   * The opponent of the team in possession whose nominal spot is nearest to `point` (world frame);
   * outfield only unless `keeper` is true (then the keeper competes too); `lines` restricts the lines
   * and is ignored when it leaves nobody.
   */
  export function castOpponentNear(state: ScriptState, point: Vec, opts?: { lines?: readonly Line[]; keeper?: boolean }): number;
  export function keeperOf(state: ScriptState, team: TeamId): number; // index of that team's slot 0
  /** `clamp(base + (attr - 60) * k, 0.02, 0.98)`. */
  export function prob(base: number, attr: number, k: number): number;
  /** One outcome by its probability; the entries need not sum to 1 (they are normalised). */
  export function drawOutcome<T extends string>(rng: Rng, table: readonly (readonly [T, number])[]): T;
  ```
  - aim helpers (world-frame results, clamped with `clampToPitch(p, PROTO_CONFIG.margin)`): `feetPoint(state, index)` = his `spot` moved `grammar.showFor` metres toward the ball, plus `rng.range(-jitter, jitter)` on each axis; `stridePoint(state, index, ahead)` = his `attackSpot` plus `[ahead, 0]`, converted back.
  - draw order matters for determinism: `castReceiver` draws exactly one number when a candidate exists and none otherwise; `feetPoint` draws two (x then y).
- `script/emit.ts` — the only place that appends beats and moves the state:
  ```ts
  export interface BeatInput {
    move: string; kind: BeatKind; actor: number; to: Vec; outcome: BeatOutcome; hold: number;
    receiver?: number; opponent?: number; loft?: boolean; through?: boolean; header?: boolean; reason?: BeatReason;
    /** Required with outcome `out`: the restart that follows. */
    then?: Restart;
  }
  export function emit(state: ScriptState, input: BeatInput): Beat;
  /** The ball changes sides in open play: `newHolder` has it now. */
  export function turnover(state: ScriptState, newHolder: number): void;
  ```
  - `emit` builds the beat (`index = beats.length`, `possession`, `team`, `phase` and `from = state.ball` from the state; `loft`, `through`, `header` default to false), pushes it and `state.times.push(state.clock)`, then adds `hold + travel` to `state.clock`, where `travel = dist(from, to) / speed` and the speed is `speeds.carry` for `carry`/`takeOn`, `speeds.shot` for a shot-like beat (`isShotLike`), `speeds.loft` when `loft`, else `speeds.ground`.
  - then by outcome:
    | outcome | effect |
    |---|---|
    | `complete` | `carry`/`takeOn`: `ball = to`. Any other kind: `holder = receiver` (throw if missing), `ball = to` |
    | `intercepted` | `ball = lerp(from, to, grammar.interceptAt)`; `turnover(state, opponent)` |
    | `tackled` | `ball = lerp(from, to, grammar.tackleAt)`; `turnover(state, opponent)` |
    | `foul` | `ball = lerp(from, to, grammar.tackleAt)`; `pending = { kind: 'freeKick', team: state.team, spot: ball }` |
    | `offside` | `pending = { kind: 'freeKick', team: other(state.team), spot: to }` |
    | `out` | `ball = to`; `pending = input.then` (throw an `Error` when it is missing) |
    | `goal` | `score[team] += 1`; `pending = { kind: 'kickOff', team: other(team), spot: CENTRE }` |
    | `wide` | `pending = goalKickFor(state, other(team))` (from `restarts.ts`) |
    | `saved`, `blocked` | nothing; the move that shot decides what follows (T794) |
  - after that, when nothing is pending and the phase is not `counter`: `state.phase = phaseAt(state.team, state.ball)`.
  - `turnover`: `state.team = other(team)`, `state.possession += 1`, `state.holder = newHolder`, every flag reset (`counterBeats = 0`, booleans false), then the phase: with `x = toAttack(newTeam, ball)[0]`, if `x < grammar.counter.fromX`, the phase the losing side was in is `progression` or `finalThird`, and `rng.chance(grammar.counter.chance[style of the new team])` → `phase = 'counter'` and `flags.counterBeats = rng.int(...grammar.counter.beats)`; otherwise `phaseAt`. Draw the chance only when the first two conditions hold.
- `script/restarts.ts`:
  - spot helpers: `throwInFor(state, team, at: Vec): Restart` (spot `[clamp(at[0], 1, 104), at[1] < 34 ? 0 : 68]`), `goalKickFor(state, team): Restart` (spot = world of `team`'s attack `[5.5, 34 + 6 * side]`, `side` −1 or +1 drawn with one `rng.chance(0.5)`), `cornerFor(state, team, attackY: number): Restart` (spot = world of `team`'s attack `[105, attackY < 34 ? 0 : 68]`).
  - out helpers returning `{ to: Vec; then: Restart }` for a beat by the team in possession: `outToTouch(state, attackX)` — the ball leaves over the nearer touchline (nearer to the ball's current `y`) at that attack x clamped to 1–104, throw-in to the other side; `outOverByline(state, attackY)` — over the opponents' goal line at that attack y (`to` = attack `[106.5, attackY]`), goal kick to the other side; `outForCorner(state, attackY)` — the same line last touched by the defenders, corner to the team in possession.
  - `playRestart(state)`: takes `state.pending` (clear it first), sets `state.team = r.team`, `state.possession += 1`, `state.ball = r.spot`, `state.phase = r.kind === 'corner' ? 'setPiece' : phaseAt(r.team, r.spot)`, resets the flags, adds `grammar.dead[r.kind]` to the clock, then emits one beat (`move` = the restart kind, `hold = rng.range(...grammar.hold.restart)`):
    | kind | actor | receiver | `to` | outcome |
    |---|---|---|---|---|
    | `kickOff` | the team's slot 9 | `castReceiver` over positions `DM` w 2, `CM` w 2 | world of attack `[45, 34 + rng.range(-6, 6)]` | `complete` |
    | `throwIn` | among positions `LB RB LW RW LM RM` of the team, the one whose `spot` is nearest to the restart spot | the nearest other outfield teammate by `spot` | the point `clamp(distance, ...restart.throwRange)` metres from the spot toward the receiver's `spot` | `complete` with `restart.throwComplete`, else `intercepted` by `castOpponentNear(to)` |
    | `goalKick` | the keeper | `castReceiver` over `CB` w 3, `LB` w 1.5, `RB` w 1.5 | world of attack `[rng.range(10, 16), 34 ± rng.range(16, 22)]` on the receiver's side (the sign of his in-possession anchor's `ay`; left for 0) | `complete` with `restart.goalKickComplete`, else `intercepted` by `castOpponentNear(to, { lines: ['FW'] })` |
    | `freeKick` | the outfield player of the team whose `spot` is nearest to the restart spot (a `CB` or the keeper when the spot's attack x is below `grammar.phaseX.progression`) | the nearest other teammate by `spot` | `feetPoint(receiver)` | `complete` with `restart.freeKickComplete`, else `intercepted` by `castOpponentNear(to)` |
    | `corner` | the outfield player with the highest `passing` (lowest index on a tie) | the nearest other teammate by `spot` (a short corner; T794 replaces this row with a delivery) | `feetPoint(receiver)` | `complete` with `restart.cornerShortComplete`, else `intercepted` by `castOpponentNear(to)` |
    - set `state.holder = actor` before emitting; after a `corner` or any restart the phase follows `emit`'s rule (a corner's `setPiece` phase becomes `phaseAt` after its beat).
- `script/moves.ts`:
  ```ts
  export interface MoveDef {
    id: string;
    phases: readonly Phase[];
    /** 0 = not available now. Must draw no random number. */
    weight(state: ScriptState): number;
    /** Emits at least one beat through `emit`. */
    run(state: ScriptState): void;
  }
  export const SAFE: MoveDef;            // fallback when no move is available
  export const DEFAULT_MOVES: readonly MoveDef[];
  ```
  - four basic moves now (T794 rewrites `DEFAULT_MOVES`; `circulate` and `carryForward` are already in their final form):
    - `safe` (all phases, weight 1): pass to the teammate (outfield, not the holder) whose `spot` is nearest to the ball; `to = feetPoint`; `hold` in `hold.build`; `complete` with `p.safe`, else `intercepted` by `castOpponentNear(lerp(ball, to, interceptAt))`.
    - `circulate` (`buildUp`, weight 3): receiver = `castReceiver([GK w 1, CB w 3, LB w 2, RB w 2, DM w 2] as position rules, extra = exp(-dist(spot(i), ball) / grammar.shortRange))`; `to = feetPoint`; `hold` in `hold.build`; `reason = 'reset'` when `to` is more than 6 m behind the ball in attack x; `complete` with `prob(p.circulate, passing of the actor, 0.001)`, else `intercepted` by `castOpponentNear(lerp(ball, to, interceptAt), { lines: ['FW', 'MF'] })`. Weight 0 when `canCast` is false.
    - `carryForward` (`buildUp`, `progression`, `finalThird`, `counter`; weights 1.2, 2, 1, 2.5; 0 when the holder is a keeper): `d = rng.range(...carry[phase])`; attack target `[bx + d, by + rng.range(-carry.drift, carry.drift)]`, in `finalThird` the `y` moved a quarter of the way toward 34, `x` capped at 100; `to` = that in the world frame, clamped to the margin; `hold` in `hold.carry`; outcome by `drawOutcome`: `complete` `prob(p.carry[phase], dribbling, 0.002)`, `foul` `p.carryFoul`, `tackled` the rest (at least 0.01); `opponent = castOpponentNear(lerp(ball, to, tackleAt))` for `tackled` and `foul`.
    - `hoofOut` (all open-play phases, weight `p.hoof`): `kind: 'clearance'`, `loft: true`, `{ to, then } = outToTouch(state, bx + rng.range(15, 30))`, outcome `out`, `hold` in `hold.carry`.
- `script/generate.ts`:
  ```ts
  export interface GenerateOptions { seconds?: number; moves?: readonly MoveDef[]; fixture?: Fixture }
  export function generateScript(seed: string, options?: GenerateOptions): Script;
  ```
  - `limit = options.seconds ?? PROTO_CONFIG.duration * grammar.nominalFactor`; `fixture = options.fixture ?? demoFixture()`; `rng = createRng(seed)`.
  - loop while `clock < limit` and `beats.length < grammar.maxBeats`: when `pending` → `playRestart`; else gather the moves whose `phases` include `state.phase` and whose `weight(state) > 0`, `rng.pick` one by weight (use `SAFE` when none), remember `beats.length`, the phase and the team, `run` it, throw an `Error` naming the move if it emitted nothing, then counter bookkeeping: only when the move started in phase `counter`, the same team still has the ball, the phase is still `counter` and nothing is pending, `flags.counterBeats -= 1`; when it reaches 0 or the ball's attack x ≥ `phaseX.finalThird`, `phase = phaseAt(...)` and `flags.counterBoost = phase === 'finalThird'`.
  - return `{ seed, fixture, beats, times, nominalSeconds: clock }`.
- `script/validate.ts`: `export function validateScript(script: Pick<Script, 'beats' | 'fixture'>): string[]` — messages `rule N: beat I: …`; empty = valid. Rules:
  1. the first beat is a `kickOff`; indexes run 0, 1, 2, ….
  2. actor and receiver (when present) belong to `beat.team`; opponent (when present) belongs to the other team; all are valid indexes; receiver ≠ actor.
  3. required fields: a `PASS_KINDS` beat that is not shot-like has a receiver; outcomes `intercepted`, `tackled`, `foul`, `saved`, `blocked` have an opponent; `offside` only on a `pass` with `through`; `through` only on kind `pass`; `header` only on kind `shot`; shot outcomes only on shot-like beats; `tackled`/`foul` only on `carry`/`takeOn`.
  4. `hold` within 0.1–6 and `to` within 8 m of the pitch.
  5. after `complete`: pass-like or clearance → the next beat's actor is the receiver and its team the same; `carry`/`takeOn` → the next actor is the same actor.
  6. after `intercepted` or `tackled`: the next actor is the opponent, the next team the other team, the next possession one higher.
  7. after a dead ball: `offside` → next is a `freeKick` of the other team; `foul` → a `freeKick` of the same team; `out` → a `throwIn`, `goalKick` or `corner`; `goal` → a `kickOff` of the other team; `wide` → a `goalKick` of the other team; and every restart beat's possession is one higher than the beat before it.
  8. after `saved`: next is a `corner` of the same team, or the opponent acting for the other team; after `blocked`: a `corner` of the same team, a `throwIn`, the opponent acting for the other team, or any player of the same team acting. A restart kind appears only where rules 7–8 allow one (and as the first beat).
  - the last beat has no successor and is exempt from rules 5–8.
- `script/stats.ts`:
  ```ts
  export interface TeamStats {
    beats: number; passes: number; completed: number; shots: number; onTarget: number; goals: number;
    offsides: number; crosses: number; corners: number; throwIns: number; goalKicks: number; freeKicks: number;
    tackles: number; interceptions: number; fouls: number; throughBalls: number; takeOns: number;
    possessions: number; counters: number;
  }
  export interface ScriptStats {
    teams: [TeamStats, TeamStats];
    /** Beats per move id. */
    moves: Record<string, number>;
    /** Receivers flagged offside, one entry per call. */
    offsideBy: number[];
    /** Receivers of completed through balls. */
    throughTo: number[];
    /** Move id → receivers of its completed beats. */
    receivedBy: Record<string, number[]>;
    score: [number, number];
  }
  export function scriptStats(beats: readonly Beat[]): ScriptStats;
  ```
  - `passes` = `PASS_KINDS` beats that are not shot-like, `completed` those with `complete`; `shots` = shot-like beats, `onTarget` = `goal` or `saved`; `offsides` to the beat's team; `crosses` = beats with move `cross`; `corners`/`throwIns`/`goalKicks`/`freeKicks` by kind; `tackles`, `interceptions`, `fouls` are credited to the opponent's team (the fouling side for `fouls`); `throughBalls` = beats with `through`; `takeOns` by kind; `possessions` = distinct `possession` values whose first beat is the team's; `counters` = those of them holding a beat in phase `counter`; `score` from `goal` outcomes.
- Keep every function small and pure except for the `state` it is handed; `weight` functions must not draw from the rng (the order of draws is part of the script's identity).
