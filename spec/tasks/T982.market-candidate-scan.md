## result
- outcome: Part 1 and part 2 are both in, and the world is bit-identical.
  - Part 1 (npc-market.ts `targetsFor` and `attempt`): `tried` is now a `Map` from buyer id to the `Set` of player ids that buyer asked for today. `triedBy(buyer)` is hoisted out of the candidate loop and shared with `attempt`; the rival loop reads `tried.get(rival.id)?.has(p.id)` without allocating. The scan runs the side-effect-free `continue` filters first (`club === buyer`, `moved`, `salesLeft`), then the set lookup, then `npcCanSell`. Listed-only segments walk `listedList(key)`: a per-settlement list per (country, tier, line), built lazily the first time it is read. It is the sorted index filtered by `listedDown(listed.get(id))`, in the same order. The `listed` map and the index are never mutated inside a settlement, so the list stays valid. The players it leaves out only ever reached `continue`, so they never changed `bound()`. That means `firstAtMost` and the `cand.ovr + slack < bound()` break fall at the same points.
  - ids: no club or player id can contain `|`. Club ids are `${code}:${tier}:${group}:${n}` (world.ts). Player ids are `${club}:p:…`, `${club}:y:${year}:${serial}`, `${club}:founding:${year}:${suffix}` or `${base}:${serial}` (world.ts, npc-careers.ts, persisted-squads.ts, npc-continuity.ts), all joined by `:`. The old composite key was therefore injective, and the per-buyer sets answer exactly as it did.
  - Part 2 (player-state.ts, npc-market.ts `npcMarket`): `slotOvr(p, slot, multiplier = 1)` reads the open settlement's `SlotRatings` when `multiplier === 1`. Otherwise it calls `freshSlotOvr`, the unchanged formula, now exported. `withSlotRatings(ratings, run)` opens the scope and restores the outer one in `finally`, so a thrown error closes it too. `npcMarket` runs everything after building its settlement inside `withSlotRatings(settlement.ratings, …)`. `SettlementRatings.of`/`other` and the market's own `rating` call `freshSlotOvr`, so they never read through the scope. Nothing is plumbed through world.ts or persisted-squads.ts. The `npcMarket` body is re-indented by one level (prettier); `git diff -w` shows the real change.
