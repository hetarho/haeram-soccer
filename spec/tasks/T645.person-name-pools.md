## impl notes
- Pools move out of `COUNTRIES` literals into `packages/catalogs/data/names.json`: `{ "references": [<https urls>], "note": <how the lists were curated>, "countries": { "<CODE>": { "given": [...], "family": [...] } } }`. `index.ts` imports it and fills each profile's existing `given`/`family` fields from it, so `CountryProfile` and every reader stay as they are. Belgium mixes Flemish and Walloon names; Dutch surnames keep their particle (`van Dijk`, `de Jong`). Names are common names of the country for men born across the twentieth century — not footballers' names (→WORLD-4). No name library: a locale bundle such as faker's weighs megabytes in the browser, carries present-day names and sits outside the fingerprinted catalog.
- References (ARCH-10 provenance): `https://en.wikipedia.org/wiki/List_of_most_common_surnames_in_Europe` and `https://en.wikipedia.org/wiki/List_of_most_popular_given_names`; `validate-catalogs.ts` checks the names file carries https references and the pool sizes.
- `personName(code, r, surname?)` in `world.ts`: draws the given index then the surname index from `r` (two `integer` calls, always); with `surname` set, the surname is `family[surname mod length]` instead of the drawn one. Draw count is the contract for WORLD-12's "never shifts other draws".
- Squad surnames, stateless (NPC squads regenerate each season from seed, so no registry): export `SURNAME_STRIDE = 97` (prime) from `world.ts`; a squad's surname slot is `(hash(\`${seed}:${clubId}:surnames\`) + key * SURNAME_STRIDE) mod family.length`.
  - NPC (`npcSquad`): key = the member's join year `18 * cohort - i` (constant while his cohort lasts; the 18 members of a season have 18 consecutive join years), so the 18 surnames are distinct when `family.length` is not a multiple of `SURNAME_STRIDE`.
  - founding squad (`createBase`'s `found`): key = the founder index `i`.
  - `makePlayer` gains a trailing optional `surname?: number` passed through to `personName`; other callers (academy, youth, vacancies, squad-target, ops-squad, lab) pass nothing and draw freely.
  - `names.test.ts` asserts `family.length % SURNAME_STRIDE !== 0` for every country (catalogs must not import the engine).
- Catalog bump: `CATALOG_VERSION = '2026-demo-5'`; `PRIOR_CATALOG_HASHES['2026-demo-4'] = '1381bd5891d2bad9f879a83b2f9965f106151c71747232b3c550d180b9785e97'` (the current hash); `PARITY_LEVEL_CATALOGS` unchanged (demo-4 is already re-levelled). Update the doc comment above `PRIOR_CATALOG_HASHES`. The writer-activation transform already moves any recognised pin; no persistence code change expected.
- `persistence.test.ts`: the legacy-pin loop gains `2026-demo-4` and expects `CATALOG_VERSION` `2026-demo-5`; add one non-English (ITA) 2026-demo-4 save that loads and moves its pin.
- Checks per the owner's speed rule: unit tests + typecheck/lint/format/validate:catalogs only; integration/e2e run once in the batch on main after push. Integration or e2e cases that pin a specific generated name (none found by grep for old pool names outside `cupRoute.ts` docs and the contract fixture `'Arthur Cole'`) are fixed if they fail and listed in limits.
