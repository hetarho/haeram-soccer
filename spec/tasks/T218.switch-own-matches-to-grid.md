## impl notes
- Dispatch (design §12):
  ```ts
  const prepared = prepareMatch(w, f);
  const own = prepared.ownSide !== undefined;
  if (own || (keepPlayers && OWN_LEAGUE_ENGINE === 'grid')) {
    const setup = buildGridSetup(w, f, { observe, recordPlayers: keepPlayers || observe || own, decide });
    const result = playGrid(setup);
    return { record: result.record, frames: observe ? buildFrames(result, setup, w.seed) : [], squads: setup.rosters };
  }
  return summaryMatch(prepared /* + decide, keepPlayers handled in T221 */);
  ```
  For an own match without `observe`, `recordPlayers` must still be true (own lines are saved by `recordMatch`).
- `decide` is accepted and passed through now; extra time is implemented in T222 (until then the grid engine ignores it).
- Keep the `summaryMatch` path byte-identical for NPC fixtures (calibrated); the golden changes only through own/own-league matches.
- The schema: `MatchFrame`/`MatchEvent` are not part of saves (observation only); only TS types change.
- Search for every import of `visibleEvents`, `MatchMotion`, `MATCH_DUEL_CONFIG`, `actionWeight`, `ROLE_ACTION`, `TRAIT_ACTION` across `packages`, `apps`, `tests`, `scripts` and fix them (keep `actionWeight`/`ROLE_ACTION`/`TRAIT_ACTION` exported from `match.ts` — the grid engine uses them).
- `apps/web/src/ui/playerAnalysis.ts` comment "the engine has no substitutions" stays until T229.
