## goal
Every player view shows the 16 attributes, cards and bans, season heat maps and the new counters; the squad and home show who is banned; the league shows its discipline table.

## acceptance
- [v] Player sheet (WEB-59): attribute groups include 정신 (판단력, 침착성) automatically; adds `징계` (yellows and reds this season / career from `ownMatches` incidents, current ban with matches and scope) and `시즌 히트맵` (this season's from material, earlier seasons from `SeasonArchive.heat` via `seasonHeat`, a season selector).
- [v] `PlayerAdvancedStats` / `playerAdvanced` add box entries, line-breaking passes, xT added, cut-backs, progressive carries (totals and per 90).
- [v] Appearances (HIST-13) count own-match records whose line for the player has `metrics[10] > 0`, starters and substitutes alike (not `floor(minutes/90)`, which also overcounts added time); a line with 0 minutes gains none. Season = the season in progress, career = every record in `w.ownMatches`. Every caller of `appearances` (PlayerSheetDialog, Rich, CareerRecordBook) uses it; the "no substitutions" comment in `playerAnalysis.ts` is removed; sub appearances shown as `교체 n`. Minutes / 90 stays only as the per-90 denominator.
- [v] Squad cards (WEB-68): a ban badge `출장 정지 · n경기 (리그|컵|유럽)` and a warning badge `경고 누적 주의` (`yellowWarning`), next to the injury badge.
- [v] Home team state (WEB-44): the squad tile counts injured and suspended (`부상 n · 정지 n`); warning with 3+ injured or suspended, critical with fewer than 14 available.
- [v] League 선수 기록 (WEB-40): a `징계` table (player, club, yellows, reds, current ban) for the selected league and season in progress, from `w.discipline` and this season's records; closed seasons show `지난 시즌 징계 기록은 보관하지 않아요` (HIST-16).
- [v] Tests: `teamState.test.ts` `counts suspended players with the injured`, `playerAnalysis.test.ts` `counts one appearance per own match with minutes, substitutes included`, `gives no appearance for a line with 0 minutes`, `discipline.test.ts` (new, UI read model) `lists the league's cards and bans`; e2e `player-profile.spec.ts` checks 판단력 and 침착성 in `profile-attributes`; `contract-talks.spec.ts` badges still pass.
- [v] typecheck and lint pass.

## impl notes
- Discipline read models belong in a small new `apps/web/src/ui/discipline.ts` reading `w.discipline` and incidents.
- Appearance counts: one pass over `w.ownMatches` builds `Map<playerId, { season, career, sub }>` per world revision (memoised), so squad tables do not rescan every row; a line is a substitute iff its id appears as `other` in a `sub` incident (as T220).
- Ban scope labels: `domestic` → 국내, `league` → 리그, `cup:*` → 컵, `europe` → 유럽.
