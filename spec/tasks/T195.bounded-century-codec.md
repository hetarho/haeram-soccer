## impl notes
- Use brotli/compress and brotli/decompress from exact 2.1.0 (MIT with upstream notices). The encoder is static Emscripten-generated JavaScript, not WASM/eval. Dynamic import keeps it out of initial entry and small-save paths. Native APIs may not support Brotli in Chromium; use the same portable implementation in tests/Node and all browsers.
- Quality 11/window 24. Bound JSON input/output to the existing 16 MiB; cap allocations for malformed meta-blocks before growth and windows before ring-buffer allocation using a committed dependency patch; do not trust an uncompressed-size claim. Preserve fatal UTF-8 and SHA-256 validation.
- BMP alphabet: U+0100..U+D7FF then U+E000..U+FFFD excluding U+FDD0..U+FDEF (63198 characters). Fixed 127-byte big-endian integers become 64 base-63198 digits, including leading zeros. Header U+4E00+last-byte-count (zero only for empty payload). The final block must fit its declared byte count; reject invalid lengths/digits, excess integer bits and oversized encoded input before allocation. This opaque payload is stored verbatim, never Unicode-normalized.
- Update exact codec vocabulary and compatibility ownership without weakening unknown/future protection or legacy classification. Codec-internal text is private; envelope/checksum/generation/manifest contracts stay unchanged.
- The native window-24 diagnostic was 1514608 compressed bytes with exact pure-JavaScript decompression (94ms); native figures are feasibility only. Use actual production encode/decode and browser tests before acceptance.
