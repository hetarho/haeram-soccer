## goal
Establish one versioned result, timed-path and aggregate-state contract before dependent implementations.

## acceptance
- [v] Capture the actual pre-football-change baseline with T272's runner on the source after T255; retain its fingerprint, settings and actual measurements independently of the candidate source.
- [v] Implement the contract document's model revision, optional world activation/coverage metadata, `FullMatchRecord`, `NpcSeasonStats`, explicit frame/ball timestamps and transient intention observation fields. Preserve older record optionality and existing Metrics/TD/PD indexes and units.
- [v] Declare `FULL_MODEL_CHECKPOINT_SCHEMA` as the next container after the identity container, retaining the existing writer selection for unactivated worlds until the new codec/activation is ready. Retain supported older containers and reject future model/container metadata with the existing typed compatibility error; supported rules-4.0.0 worlds never become resettable legacy data.
- [v] `packages/engine/src/match-model.ts` exports shared `validateFullMatchRecord` and `MATCH_MODEL_RELEASE`; production activation is initially disabled. Grid setup accepts an internal explicit candidate revision for tests/measurements, while ordinary setup reads the world's active model.
- [v] `match-model.test.ts` covers `accepts missing metadata on supported careers`, `rejects unknown model revisions`, `preserves old optional record fields`, `validates aligned monotonic path timestamps`, `requires every full-model counter`, and `rejects impossible participation and contribution sums` with small synthetic records.
- [v] Protocol validation carries supported model metadata and typed future-version failures without activating a world or mutating its facts. Task checks and build follow ARCH-30.

## impl notes
- Read the contract document's candidate model, time-coordinate and aggregate-state sections. This task owns new public DTOs and validators; downstream code must use them.
- Define the new checkpoint-container literal here once; T282 consumes the exported constant. Do not change gameplay engine compatibility or add a legacy-reset rule.
- The candidate adapter is a test/measurement seam, not a player-facing engine choice. It must not perturb generation, recruitment or financial random streams.
- T255 is an explicit barrier because its identity implementation changes the same contracts and protocol files. Preserve its appearance and identity fields exactly.
