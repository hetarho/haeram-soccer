## goal
Connect a passive real-scale pitch preview to the editor using the same selection and drawing kernels as live observation.

## acceptance
- [v] KitPitchPreview accepts only MatchAppearance and two labels; it draws both sides and automatic keepers using the shared painter at actual small-marker scale.
- [v] The editor offers own home/away/third and light/dark opponent examples labelled 미리보기; switching them changes only local preview state.
- [v] identityPreview.test.ts cases preview preserves the explicitly selected own role and custom colours, opponent examples produce independent readable previews, and warnings/keepers match the shared selector pass.
- [v] No createWorld/simulateMatch/command/save/progression call, real fixture insertion or invented score is used by preview modules.
- [v] Large samples and preview markers share geometry, colours and trim. The component cleans up drawing/resizing work on unmount and does not add an endless simulation loop.
- [v] The caption/accessible description identifies own role, opposing example, keeper distinction and any clash warning.
- [v] Targeted verification passes: `pnpm exec vitest run apps/web/src/ui/identityPreview.test.ts apps/web/src/ui/kitPainting.test.ts packages/engine/src/kit-selection.test.ts && pnpm run typecheck`.

## impl notes
- Read `docs/CLUB-IDENTITY-CONTRACT.md` sections named below; it owns the stable interfaces used in this task.
- Prerequisites: T239, T246, T248. Read their implemented interfaces/results before editing; extend those modules rather than reproducing a prerequisite.
- Read design §§4 and 7. Put fixed light/dark synthetic identities and a pure editorPreviewAppearance helper in identityPreview.ts; derive the pair via selectMatchKits with the selected own role forced.
- The passive component uses a small static formation on the normal grass colour and a 1.9:1 pitch. Static preview positions are clearly an example; live Pitch continues to use real engine motion.
- Use a ResizeObserver/effect and the cached painter to redraw on size/appearance changes, then disconnect on unmount. A preview needs no rAF clock to demonstrate colours.
- If the own preview is shown as away, explicitly switch side indices and labels; do not invert only the badge while forcing the home shirt slot.
- Avoid rendering two implementations of striped/checkered regions: the shared sprite geometry is the source for both the large sample and pitch markers.

## result
- outcome: completed.
  - New pure `apps/web/src/ui/identityPreview.ts` imports only the contract identity types, `selectMatchKits` and `describeShirt`. `KIT_ROLE_LABELS` moved here; the editor imports and re-exports it, so T248's test is unchanged.
  - `PREVIEW_OPPONENTS` holds two deep-frozen synthetic opponents: 밝은 상대 예시 (`preview:light`, three light shirts) and 어두운 상대 예시 (`preview:dark`, three dark shirts). Each keeps its tone whichever shirt the selector picks.
  - `editorPreviewAppearance(own, role, opponent)` returns `{ appearance, labels, ownSide }`. The own home shirt plays at home (side 0); away and third are worn away. In that case the own club really is side 1, with its own label, crest and keeper; the badge is not just swapped.
  - The pair comes from `selectMatchKits(home, away, { side: ownSide, role })`, so shirts, roles, goalkeepers and warnings are the shared selector's. The own shirt is the saved design with its literal colours, and crests are copies.
  - `previewLines(appearance, labels)` builds the caption: a 미리보기/example line, each side's venue, label, role and `describeShirt`, the automatic keeper colours, and every warning in Korean (or 경고 없음). There is no score.
  - New `KitPitchPreview.tsx` takes only `{ appearance, labels }`. `paintKitPreview` draws the live pitch's ground: the same colours, mown stripes, markings and 6.5% border as `Pitch`. It then draws an 11-player static shape per side, each in its own half and mirrored for away, all through the shared `createKitPainter`. Markers use the live radius `max(6, width × 0.011)`, the `#ffffffcc` outline, numbers 1–11 in the live font size, the selected outfield shirt, and each keeper as a plain shirt in its automatic colour.
  - The component keeps one painter per mount. It draws in an effect and redraws through a `ResizeObserver` disconnected on unmount, with no rAF or interval. The canvas is a 1.9:1 `role="img"` whose `aria-describedby` points to the visible caption.
  - `ClubIdentityEditor` now has a 경기장 미리보기 section. The preview wears whichever of 홈/원정/서드 the shirt selector has chosen, and a `Select` (미리보기 상대 예시) switches the light/dark example. Both are local state, and the preview is memoized on value/role/opponent.
