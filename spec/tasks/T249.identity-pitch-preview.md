## goal
Connect a passive real-scale pitch preview to the editor using the same selection and drawing kernels as live observation.

## acceptance
- [ ] KitPitchPreview accepts only MatchAppearance and two labels; it draws both sides and automatic keepers using the shared painter at actual small-marker scale.
- [ ] The editor offers own home/away/third and light/dark opponent examples labelled 미리보기; switching them changes only local preview state.
- [ ] identityPreview.test.ts cases preview preserves the explicitly selected own role and custom colours, opponent examples produce independent readable previews, and warnings/keepers match the shared selector pass.
- [ ] No createWorld/simulateMatch/command/save/progression call, real fixture insertion or invented score is used by preview modules.
- [ ] Large samples and preview markers share geometry, colours and trim. The component cleans up drawing/resizing work on unmount and does not add an endless simulation loop.
- [ ] The caption/accessible description identifies own role, opposing example, keeper distinction and any clash warning.
- [ ] Targeted verification passes: `pnpm exec vitest run apps/web/src/ui/identityPreview.test.ts apps/web/src/ui/kitPainting.test.ts packages/engine/src/kit-selection.test.ts && pnpm run typecheck`.

## impl notes
- Read `docs/CLUB-IDENTITY-CONTRACT.md` sections named below; it owns the stable interfaces used in this task.
- Prerequisites: T239, T246, T248. Read their implemented interfaces/results before editing; extend those modules rather than reproducing a prerequisite.
- Read design §§4 and 7. Put fixed light/dark synthetic identities and a pure editorPreviewAppearance helper in identityPreview.ts; derive the pair via selectMatchKits with the selected own role forced.
- The passive component uses a small static formation on the normal grass colour and a 1.9:1 pitch. Static preview positions are clearly an example; live Pitch continues to use real engine motion.
- Use a ResizeObserver/effect and the cached painter to redraw on size/appearance changes, then disconnect on unmount. A preview needs no rAF clock to demonstrate colours.
- If the own preview is shown as away, explicitly switch side indices and labels; do not invert only the badge while forcing the home shirt slot.
- Avoid rendering two implementations of striped/checkered regions: the shared sprite geometry is the source for both the large sample and pitch markers.
