## goal
The engine names the club's direction 방향 (기본 방향, 맞춤 방향, events titled 방향 · <name>) and reads titles recorded as 운영 전략 the same way.

## acceptance
- [ ] `buildLabel` returns 기본 방향 for an all-standard build and 맞춤 방향 for any other unnamed build; a preset or a saved name is unchanged
- [ ] applying a build records an event titled `방향 · <name>`; the build command's errors read 방향 부문을 확인하세요. and 방향 카드를 확인하세요.
- [ ] one exported reader turns a stored build title `운영 전략 · 기본 전략` / `운영 전략 · 맞춤 전략` / `운영 전략 · <preset or saved name>` into `방향 · 기본 방향` / `방향 · 맞춤 방향` / `방향 · <name>`, and leaves a `방향 · …` title as it is
- [ ] club news for a build event reads `<club>, 방향 '<name>' 발표` through that reader, for old and new titles; a vision event still reads 구단 비전
- [ ] owner-facing engine texts that name the old tab read the new homes: the cancelled-reservation notice (`예약했던 방향 ‘<name>’ 취소`, detail 방향은 이제 바로 적용돼요. 방향 탭에서 다시 고를 수 있어요., unnamed default 기본 방향), the milestone line (방향 › 증축에서 경기장 증축하기), the empty sponsor reminder (방향의 후원 탭) and the growth-factor term label (방향)
- [ ] tests: packages/engine/src/build-cards.test.ts (titles and labels updated, new case "reads build titles recorded before the rename"), packages/engine/src/build.test.ts, packages/engine/src/activation.test.ts updated and passing; `pnpm run test:contract` passes unchanged (no fixture applies a build)

## impl notes
- the reader lives in build.ts beside `buildLabel`, e.g. `readBuildTitle(title: string): string` plus `buildTitleName(title)` returning the part after ` · ` already mapped; news.ts and the web (T087, T088) call it instead of splitting titles themselves.
- no rules version change and no save migration: only new events carry the new words, older ones are read through the reader (ECON-22).
- keep event kinds, command shapes and the strategy library storage (SAVE-15) as they are; only words change.
- `STRATEGY_NAME_LIMIT` and saved names are untouched; a saved name that happens to be 맞춤 전략 is mapped like the default (acceptable, it reads the same).
