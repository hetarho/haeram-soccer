## goal
`playGrid(setup)` plays a whole 90-minute match touch by touch and returns a schema-valid `MatchRecord` (metrics, highlights, xG; detail zero-filled until T212), plus a trace when observed.

## acceptance
- [ ] `grid/engine.ts` exports `playGrid(setup): GridResult` and `ACTION_SECONDS`, `ADDED_CONFIG`; `grid/record.ts` exports `Tally`; `grid/trace.ts` exports `TraceEntry` and `Tracer`.
- [ ] Loop per design §8.2: kick-off (period 1 home, period 2 away; after a goal the conceding side), tags → decide → resolve/restart → apply → time → `moveAll(dt)` → `startRuns`; possession changes only through an outcome (no draws per minute).
- [ ] Added time per design §8.3 (credits; first half 1–6, second half 2–10); `record.added = [a1, a2]`; a period ends at the first dead ball or completed action after `45·60 + added·60` s.
- [ ] Records per design §9.1 and §9.3: 12 metrics per side and per player line; goals push `{ minute, side, player: name, action: '골' }`; assists from the last completed pass of the possession unless the shooter beat his man with a take-on immediately before the shot; `xg = [home, away]` rounded to hundredths; `detail` present and zero-filled (`emptyTeamDetail`/`emptyPlayerDetail`); `players` = all 22 lines in roster order when `recordPlayers`, else `[]`; `lineCounts = [11, 11]` when `players` is filled; `metrics[side][10] = 90`, `metrics[side][11]` per design §2.3.
- [ ] `engine.test.ts` cases:
  - `plays deterministically for a seed` and `returns the same record whether observed or not`
  - `keeps the record consistent` (for 60 matches: Σ player goals = team goals per side; completions ≤ attempts; on target ≤ shots; possession minutes sum to 90; every player 90 minutes)
  - `never hands the ball over without an event` (trace: consecutive entries switch possession only after intercepted/tackled/loose/out/foul/offside/shot/goal)
  - `ends each half after its added time`
  - `produces plausible football before calibration` (200 matches between equal sides: mean goals per match 1.0–5.0, passes per team 250–800, shots per team 5–25, no shot from the shooter's own half)
  - `traces every touch with 22 positions when observed and nothing otherwise`
- [ ] Runtime: one unobserved grid match under 15 ms on the developer machine (report the measured mean in the result).
- [ ] `pnpm run typecheck`, `pnpm run lint`, the test file and `pnpm run test:unit` pass (nothing calls `playGrid` outside its tests yet).

## impl notes
- `GridResult = { record: MatchRecord; trace?: TraceEntry[]; elapsed: number }`.
- Main loop outline (pseudo-code, keep this order of draws):
  ```
  state = createState(setup); tally = new Tally(setup); restart = kickoff(side 0)
  while (true):
    if restart: res = playRestart(state, restart, r, ctx); apply(res); t += restart.dead + ACTION_SECONDS[res.kind]; restart = undefined
    else:
      [side, idx] = state.owner; tags = computeTags(state, side, idx)
      d = decide(state, side, idx, tags, r)
      o = resolve(d)                      // T209 function by action; offside check first for passes (T210)
      apply(o)                            // ball, owner, possession, regain/loss times, tally, trace, restart if any
      dt = ACTION_SECONDS[d.action or kind] × (0.85 + 0.3·r()); t += dt; elapsed += dt
    moveAll(state, dt); startRuns(state, state.possession, r)
    if periodOver(): next period (kick-off) or stop after period 2
  ```
- `ACTION_SECONDS` = design §8.2 table keyed `short, long, switch, through, cross, cutBack, carry, takeOn, shot, holdUp, clearance`; dead times come from `RESTART_CONFIG` (T210); a goal adds 55 s and a kick-off restart.
- `ADDED_CONFIG = { credits: { goal: 45, sub: 30, injury: 90, card: 20, penalty: 60 }, bounds: [[1, 6], [2, 10], [0, 3], [0, 3]] }`.
- Apply rules: a completed pass/cross/cut-back moves the ball to the receiver's position (receiver becomes owner, set `lastPass {dx, dy}`); a carry or take-on success moves the owner and the ball; intercepted/tackled/loose → the winner owns the ball at that point, `lastRegain = {side: winner, at: elapsed}`, `lastLoss = {side: loser, …}`, `possessionSince = elapsed`; out → `classifyOut` restart; foul → `foulRestart` (cards come in T213); shot → per outcome (goal: score, highlight, kick-off; save hold: keeper owns; corner/goal kick: restart; loose: winner owns).
- `Tally` (record.ts) is the only place counting; methods: `pass(side, idx, ok, from, to, receiver?)`, `shot(side, idx, xg, recordedXg, result)`, `tackle(side, idx)`, `interception(side, idx)`, `dribble(side, idx)`, `save(side, idx)`, `goal(side, idx, assister?)`, `possession(side, seconds)`, `finish(state): Pick<MatchRecord, 'metrics' | 'players' | 'highlights' | 'xg' | 'detail' | 'lineCounts'>`. Give it the hooks T212 will extend (counters receive the same arguments).
- `Tracer` (trace.ts): `push(entry)` only when `setup.observe`; `positions = Float32Array(44)` engine-frame metres of roster slots 0–10 of each side as currently on the pitch (NaN for an empty slot).
- Goal highlights use the match minute; an added-time goal is recorded at 45 or 90 (design §9.3).
- Build `record` as `{ ...f, score: {home, away}, ...tally.finish(state), tactics: setup.tactics, added }`.
