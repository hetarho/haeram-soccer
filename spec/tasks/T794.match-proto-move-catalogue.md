## goal
The script reads as football: build-up through the pivots, a false nine linking play, switches, wide play and crosses, through balls flagged offside by the runner's `decisions`, shots with their aftermath, deliveries from corners — and a seed search that finds ten eventful minutes showing all of it.

- `script/follow.ts` — shared pieces (each takes `state`, emits through `emit`):
  - `takeFlags(state)`: returns a copy of `flags.counterBoost`, `beatMan`, `boostLong`, `boostSwitch` and sets all four false. **Every** catalogue move's `run` starts with it; `weight` reads the live flags.
  - `offsideChance(decisions)`: `clamp(offside.base * Math.exp(-(decisions - offside.pivot) / offside.spread), offside.min, offside.max)`.
  - `boxPoint(state, zone)`: `[x, off] = G.box[zone]`; `side = by >= 34 ? 1 : -1`; `A(x, 34 + side * off)`.
  - `goalPoint(state, outcome)`: attack y = `rng.range(POST_LOW + 0.4, POST_HIGH - 0.4)` for `goal`, `saved`, `blocked`; for `wide` one `rng.chance(0.5)` picks the post and y lies `rng.range(0.8, 4)` outside it; the point is attack `[105, y]` in the world frame, not clamped.
  - `finish(state, kind, beatKind = 'shot')` with `kind` one of `oneOnOne | header | firstTime | box | edge | freeKick`: actor `H`; `T = p.shot[kind]`; `goal = prob(T.goal, kind === 'header' ? heading : finishing, p.shotAttr[kind])`; outcome by `drawOutcome([goal, T.saved, T.blocked, max(0.05, 1 - goal - T.saved - T.blocked) for wide])`; `to = goalPoint`; opponent = the other keeper for `saved`, `castOpponentNear(point G.blockAhead metres from the ball toward the goal, { lines: ['DF', 'MF'] })` for `blocked`; hold from `hold.firstTime` (header, firstTime), `hold.edgeShot` (edge, freeKick) or `hold.shot`; `header: kind === 'header'`; move id = `kind` + `Shot` for `box`/`edge`/`freeKick` (`boxShot`, `edgeShot`, `freeKickShot`), the kind itself otherwise (`oneOnOne`, `header`, `firstTime`); then `afterShot`.
  - `afterShot(state, beat)`: `goal` and `wide` are settled by `emit`. `saved`: with `p.saveHold` the keeper holds — `state.ball = lerp(beat.from, beat.to, 0.9)`, `turnover(state, keeper)`, `gkDistribute(state)`; else `state.pending = cornerFor(state, beat.team, attack y of beat.to)`. `blocked`: one `rng.next()` `u`: below `p.blockedCorner` → corner pending as above; below `+ p.blockedDefender` → `state.ball = ` the point `G.blockAhead` metres along `from → to`, `turnover(state, beat.opponent)`, `defensiveClear(state)`; otherwise the attack keeps it: `state.holder = castReceiver([L:MF 2, L:FW 2], extra = exp(-dist(spot(i), ball) / 15)) ?? beat.actor`, `state.ball = A(clamp(bx - rng.range(4, 9), 72, 100), 34 + rng.range(-12, 12))`, `state.phase = phaseAt(...)`.
  - `gkDistribute(state)` (the holder is a keeper): with `p.gkLong[style]` → `playLongBall(state, 'gkLong', 'pass')`; else move `gkShort`: receiver `castReceiver([P:CB 3, P:LB 2, P:RB 2, P:DM 1])`, `to = feetPoint`, `hold.keeper`, `complete` with `restart.goalKickComplete`, else `intercepted` by `castOpponentNear(to, { lines: ['FW'] })`.
  - `playLongBall(state, moveId, kind)`: receiver `castReceiver([R:targetMan 4, R:falseNine 0.8, P:ST 2, P:LW 1, P:RW 1, P:LM 1, P:RM 1])` (none → `SAFE.run(state)` and return); `to = spot(receiver)` with ±3 m jitter, clamped; `loft: true`; `reason: 'pressed'` when `boostLong` was set (pass the taken flags in); hold `hold.keeper` for a keeper, else `hold.build`; `win = prob(p.longWin, heading of the receiver, 0.004)`; outcome `complete` `win` | `intercepted` `p.longLose` | `out` `max(0.02, 1 - win - p.longLose)`. `complete` → then `layOff(state)`. `intercepted` → opponent `castOpponentNear(to, { lines: ['DF'] })`, then `defensiveClear(state)`. `out` → `outOverByline(state, attack y of to)` when `to`'s attack x ≥ 90, else `outToTouch(state, attack x of to)`.
  - `layOff(state)` (move `layOff`, `reason: 'layoff'`): receiver `castReceiver([P:CM 3, P:DM 2, R:invertedFullBack 2, P:LW 2, P:RW 2, P:LM 1.5, P:RM 1.5, P:LB 1, P:RB 1], extra = exp(-dist(spot(i), ball) / 12))` (none → `SAFE.run`); `to = feetPoint`; `hold.quick`; `complete` with `p.layOff`, else `intercepted` by `castOpponentNear(lerp(ball, to, interceptAt))`.
