## goal
Open match-model revision 5 and, on it, make the carrier's choices read as a sensible player's: he carries into open ground ahead, plays a backward or sideways ball only to a free receiver along a clear lane (a contested pass is only ever a forward one), and around the opponents' box with room he shoots, carries on or holds rather than playing it far back. Revisions 1–4 keep their football draw for draw.

## impl notes
- Follow T479's pattern for a revision (contracts list and doc comment, activation writer unchanged, web/contract tests that name the next unknown revision).
- Config, defined here: `DECISION_CONFIG.candidate.revision5 = { space: { cone: 40, from: 8, full: 25, carry: 3, keep: 5, most: 18 }, contested: { mark: 3 }, room: { from: 75, space: 6, back: 10 } }`; the explore may tune `space.carry`, `space.from/full`, `space.most`, `contested.mark` and `room.*`, never turn a rule off.
- Pass directions follow `passOptions`' angle split (forward ≤ 45°, back ≥ 135°, lateral between). The lane read is `reachOnPath(s, side, me.pos, gp.pos, 0)` which the candidate already computes for `risk`; reuse its result.
- Restarts and keeper distribution keep their pass choice (they call `passOptions` directly); only `choosePass` filters.
- Back-pass share is not a target (MATCH-16 rules concern which passes, not how many); MATCH-23 rows are reported, not tuned toward, inside the timebox.
