## goal
A day of automatic play spends less Host CPU projecting the view, with every posted reply and the world byte-identical.

## acceptance
- [v] `ownLeagueGames` counts with an indexed loop on the same condition and the same `Math.max(1, n)`
- [v] the engine offers a read scope for one world (e.g. `readingOnce(w, read)`): while it is open for that exact `w`, `ownStarters(w)` without a fixture is computed once and reused (frozen); the scope is restored in `finally`, so a nested or different world misses it; `ownStarters(w, f)` with a fixture is never memoised
- [v] `Host.view` runs inside the scope; no simulation or world mutation runs inside it (the view stays synchronous)
- [v] a new test shows a scoped read equals an unscoped one and that the scope is cleared after an exception
- [v] `node scripts/perf/ab.mjs --base <T777's integrated commit> --workload view` reports `sameHash` true and an interval below 1 for days without an own match (ARCH-34), or the measured interval is recorded as is

## result
- outcome: `ownLeagueGames` counts with an indexed loop on the same condition and returns `Math.max(1, n)`. The engine's `readingOnce(w, read)` (world.ts) opens a read scope for that exact world: inside it `ownStarters(w)` without a fixture is chosen once and the same frozen XI reused; `ownStarters(w, f)` with a fixture, another world (including the officeRead `{...w, policy}` copies) and a scope opened inside it choose their own, and the outer scope is restored in `finally`. `Host.view` projects the view inside `readingOnce` (the body moved unchanged into `projection`); the day's simulation and `ViewPublisher.publish` stay outside it, and the view stays synchronous. New test `world.test.ts` › read scope: a scoped XI and scoped reads (`effectLedger`, `synergyStates`, `autoTrainingAdvice`, canonical) equal the unscoped ones, the scope reuses one frozen XI, misses fixtures, other worlds and nested scopes, and is closed after a return and after an exception (an unfrozen XI that no longer holds a starter retired afterwards).
