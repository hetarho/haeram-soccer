## impl notes
- from review/match-engine-split-261110 F1
- Follow T791's chain rules. The viewer is presentation only (→ARCH-7): it interpolates recorded frames and never computes football. It shows **no authored prose** (→ARCH-32 untouched): digits, symbols, and identifiers that come from the data (`beat.move`, `beat.kind`, `beat.outcome`, `beat.reason`, role ids, `H`/`A` + shirt number). No `title`, `aria-label`, `<label>` or text paragraph; the HTML `<title>` is `match-proto`.
- Plain TypeScript and Canvas 2D, no React, no CSS file, no dependency besides `esbuild` (already a root devDependency) in `build.ts`. `viewer/` may use `requestAnimationFrame` and `performance.now` (it is outside the deterministic part).

- `viewer/model.ts` (pure, no DOM):
  ```ts
  export interface PlayerSample { x: number; y: number; fx: number; fy: number }
  export interface Sample {
    t: number; ball: [number, number, number]; owner: number; players: PlayerSample[];
    team: TeamId; phase: Phase; live: boolean; beat: number;
  }
  /** The state at `t`: positions and the ball interpolated linearly between the two frames around it. */
  export function sampleAt(playback: Playback, t: number): Sample;
  export function clockLabel(t: number): string;
  export interface View { scale: number; ox: number; oy: number }
  /** Pixels per metre and the pixel position of world (0, 0) so the pitch plus `pad` metres fits `width × height`, centred. */
  export function fitPitch(width: number, height: number, pad: number): View;
  export function toCanvas(view: View, p: Vec): [number, number];
  export function scoreAt(playback: Playback, t: number): [number, number];
  /** `#<index> <move> · <kind> · <outcome>[ · <reason>]  <actor>[ → <receiver>][ × <opponent>]` from the beat at `t`. */
  export function captionAt(playback: Playback, t: number): string;
  export interface Flash { kind: StageEventKind; at: Vec; line?: number; age: number }
  /** `goal`, `offside`, `save`, `block`, `tackle`, `intercept` events of the last `viewer.flashSeconds`. */
  export function flashesAt(playback: Playback, t: number): Flash[];
  /** World x of the offside line each team attacks against, from the sample's positions. */
  export function offsideLines(playback: Playback, sample: Sample): [number, number];
  ```
  - `sampleAt`: clamp `t` to `[0, playback.duration]`; `i = floor(t * hz)`, `u = t * hz - i`; frames `i` and `min(i + 1, last)`; discrete fields (`owner`, `team`, `phase`, `live`, `beat`) come from frame `i`. Facing `(fx, fy)` = the unit vector of the displacement between the two frames; when that displacement is below 0.02 m, look back frame by frame (at most 30 frames) for the last displacement above it; with none, face the opponents' goal.
  - `captionAt`: the beat = the performed beat whose `index` equals the sample's `beat`; players are written with `playerLabel`.
- `viewer/draw.ts`: `export interface DrawOptions { offsideLines: boolean; roles: boolean; trail: boolean; width: number; height: number }` and `export function drawScene(ctx: CanvasRenderingContext2D, view: View, playback: Playback, sample: Sample, options: DrawOptions, trail?: readonly Vec[]): void`. Draw in this order:
  1. grass: fill the canvas with `grassB`, then the pitch in ten vertical stripes alternating `grassA`/`grassB`;
  2. markings in `line` (line width 2 px): outline, halfway line, centre circle (radius 9.15 m) and spot, both penalty boxes (16.5 × 40.32 m), goal areas (5.5 × 18.32 m), penalty spots (11 m), both goals (7.32 m wide, drawn 2 m deep outside the goal line);
  3. overlays when `options.offsideLines`: each team's line from `offsideLines` as a dashed vertical line in that team's colour;
  4. the trail when `options.trail` and `trail` is given: a fading polyline of the ball's recent positions;
  5. players: a filled circle of radius `max(viewer.minPlayerPx, viewer.playerRadius * view.scale)` in the team colour (keepers in the keeper colours), a short facing tick from the centre to the rim, the shirt number centred (`options.roles` shows the role id under the circle instead of nothing); a ring in `owner` colour around the ball's owner;
  6. the ball: a shadow ellipse at its ground position, then the ball drawn `z * 0.6` metres up-screen from it with radius `viewer.ballRadius * (1 + z * 0.12)` metres (at least 3 px), `ball` fill and `ballEdge` stroke;
  7. flashes from `flashesAt`: `offside` → a solid vertical line in `offside` colour at `line` and a small flag-shaped triangle at `at`, fading with `age`; `goal` → an expanding ring at `at`; the others → a small fading ring at `at`;
  8. HUD on a `hud`-coloured bar across the top: `H <home score> – <away score> A` (the two codes in their team colours), the clock label, and the caption; a small pause symbol when the sample is not `live` is not needed.
- `viewer/main.ts`:
  ```ts
  export interface ViewerState { t: number; playing: boolean; speed: number; offsideLines: boolean; roles: boolean; trail: boolean }
  export interface ViewerDeps {
    getContext?: (canvas: HTMLCanvasElement) => CanvasRenderingContext2D | null;
    raf?: (cb: (ms: number) => void) => number;
  }
  export interface Viewer { state: ViewerState; tick(seconds: number): void; render(): void; destroy(): void }
  export function createViewer(root: HTMLElement, playback: Playback, deps?: ViewerDeps): Viewer;
  ```
  - builds inside `root`: a `<canvas>` (width = `min(root width or window width, viewer.maxWidth)`, height from the pitch's aspect plus the HUD bar; scaled by `devicePixelRatio`) and a controls row: a play/pause `<button data-act="play">` showing `▶` or `❚❚`; one `<button data-speed="…">` per `viewer.speeds` showing `1×`, `2×`, `5×`; an `<input type="range" data-act="seek" min="0" max="<duration>" step="0.1">`; toggle buttons `<button data-toggle="offsideLines">` `⇥`, `data-toggle="roles"` `#`, `data-toggle="trail"` `∿` (an active button gets the class `on`). Styles are set from JS or a `<style>` in the page template; no external resource.
  - `tick(seconds)`: when playing, `t += seconds * speed`; at `playback.duration` clamp and pause. `render()`: `sampleAt`, `drawScene`, move the seek bar. Without a 2D context (`getContext` returns null) `render` only updates the controls.
  - initial state: `t = 0`, `playing = true`, `speed = viewer.speeds[0]`, `offsideLines = false`, `roles = false`, `trail = false`.
  - keys on `window`: space toggles play; `ArrowLeft`/`ArrowRight` seek by `viewer.seekStep`; `1`/`2`/`3` choose a speed; `o`, `r`, `t` flip the toggles.
  - the loop: `raf` (default `requestAnimationFrame`) calls `tick((now - last) / 1000)` capped at 0.1 s a frame, then `render()`. `destroy()` cancels it and removes the listeners.
  - the entry at the bottom of the file: when `window.__MATCH_PROTO__` and `#app` exist, `createViewer(app, window.__MATCH_PROTO__)`.
