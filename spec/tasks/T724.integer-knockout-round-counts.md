# T724 count knockout rounds with integer arithmetic and guard Math.log2
> st:todo | ssot:ARCH-5 ARCH-9 ARCH-30 | base:ARCH@33 | dep:T722 | touches:packages/engine/src/knockout.ts packages/engine/src/stages.ts eslint.config.mjs | lane:dev-cost

## goal
The two remaining host `Math.log2` calls in engine source become exact integer arithmetic with identical results for every input they receive, so T722's guard can reject `Math.log2` too and the engine has no host transcendental call left (review/self-improve-local-261109 F3).

## acceptance
- [ ] `knockout.ts` `roundsFor(n)` returns `ceil(log2(max(2, n)))` (at least 1) from an integer form such as `32 - Math.clz32(Math.max(2, n) - 1)` for the whole-number club counts it receives; a unit test compares the new form with the old expression for every n from 0 to 4096
- [ ] `stages.ts`'s two-knockout-rounds check uses an integer comparison equivalent to `round < log2(field / qualifier)` for positive qualifier (for example `(era.qualifier << round) < era.field`), checked against the old expression over every European era's field/qualifier and rounds 0–10
- [ ] `Math.log2` joins T722's restricted list; `pnpm run lint`, `pnpm run typecheck`, `pnpm run format:check` pass with no disable comment
- [ ] results identical: `pnpm run test:contract` passes with the portable golden unchanged, and the knockout/stages/competition unit tests pass

## impl notes
- If `roundsFor` can receive a non-integer or a count above 2^31, keep the old value for that input range explicitly and say so in result rather than changing it.
