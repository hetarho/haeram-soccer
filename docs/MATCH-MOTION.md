# 경기 움직임과 계수 조정

관전 중 선수는 각자 상태, 목표 위치, 속도, 판단 난수, 최소 유지 시간을 가진다. 팀 전체에 같은 사인파를 적용하던 움직임을 없애고, 선수의 능력·성향과 감독의 전술·철학을 확률 가중치로 계산한다. 계수는 `packages/engine/src/motion.ts`의 `MATCH_MOTION_CONFIG`에서 조정한다.

## 시간과 재현성

- 축구 결과는 기존의 90분 이벤트 시뮬레이션이 결정한다. 움직임 엔진은 관전할 때만 실행되며, 득점·기록을 계산하는 난수를 사용하지 않는다.
- 한 경기 분을 움직임 시간 8초로 압축하고, 0.2초 간격으로 적분한다. 경기 분마다 위치 샘플 8개를 보낸다. 화면은 샘플 사이를 보간한다.
- 판단 확률은 `1 - exp(-rate × dt)`다. 프레임 수를 늘려도 판단 빈도가 불필요하게 증가하지 않는다. 최소 유지 시간 뒤에만 다시 판단하며, 현재 상태의 가중치에 `hysteresis`를 곱해 잦은 반전을 줄인다.
- 성향 난수의 seed는 선수 ID, 판단 난수의 seed는 경기 seed와 선수 ID다. 선수는 다음 경기에서도 같은 기본 성향을 유지하지만, 경기 상황에 따른 판단 경로는 달라진다.
- 결과에 포함되는 `MatchRecord`에는 움직임이 없다. 현재 관전용 `MatchFrame.motion`에 시간, 공 위치, 선수 위치·속도·상태·목표, 공의 단계와 소유자를 담는다. 기존 기록의 재생은 선택 필드 없이 계속 동작한다.

## 선수와 감독의 결합

모든 성향은 0~1 범위다. `playerTraits(player)`는 공격, 패스, 수비, 체력과 ID에서 파생한 고정 성향을 결합한다. 현재 저장 형식에 별도 성격 수치를 추가하지 않고도 서로 다른 움직임을 만들기 위한 기본 모델이다.

| 성향 | 주요 입력 | 행동에 미치는 영향 |
| --- | --- | --- |
| 자유도 `freedom` | 공격, 패스, 고정 성향 | 포메이션 이탈, 빈 공간 침투, 배회 폭 |
| 규율 `discipline` | 수비, 패스, 고정 성향 | 포메이션 유지, 마크, 복귀 확률 |
| 적극성 `aggression` | 수비, 공격, 체력, 고정 성향 | 공 근처 압박 확률 |
| 예측 `anticipation` | 수비, 패스, 고정 성향 | 판단 빈도, 지원, 마크, 패스 받을 위치 예측 |
| 창의성 `creativity` | 공격, 패스, 고정 성향 | 지원 위치, 침투 방향, 운반 방향 |
| 기동력 `pace` | 체력, 공격, 고정 성향 | 최대 속도와 가속도 |
| 지구력 `endurance` | 체력 | 경기 후반 움직임 저하 |

감독의 적용 전술 비중은 `0.55 + 0.35 × flexibility`다. 나머지 비중에는 감독 철학을 사용한다. 유연한 감독은 요청한 전술을 더 강하게 적용하고, 경직된 감독은 자신의 철학을 더 많이 유지한다. 감독 능력은 포메이션 결속, 판단 빈도, 복귀 속도를 높인다.

| 전술 | 기본 대형 | 상대적인 행동 |
| --- | --- | --- |
| 균형 | 4-3-3 | 포메이션 유지와 지원을 균형 있게 선택 |
| 점유 | 4-3-3 | 넓은 패스 선택지, 높은 결속, 지원 |
| 역습 | 4-1-4-1 | 낮은 수비선, 적은 압박, 선택적인 전진 |
| 강한 압박 | 4-2-3-1 | 높은 수비선, 여러 명의 국소 압박, 높은 자유도 |

## 선수 상태 기계

골키퍼는 `keeper`로 고정된다. 필드 선수는 명시적인 전이 표에서만 다음 상태를 선택한다. 공격 상황에서는 지원·침투·운반, 수비 상황에서는 압박·마크, 많이 벗어난 상황에서는 복귀 가중치가 생긴다. 공을 받는 선수는 예상 도착 지점으로 지원하고, 공을 소유한 선수는 운반한다.

| 상태 | 한국어 | 목표 계산 |
| --- | --- | --- |
| `shape` | 대형 유지 | 포메이션 기준점 + 선수별 배회 오프셋 |
| `support` | 패스 지원 | 공 뒤쪽 거리 + 자신의 측면 위치 + 선수별 편차 |
| `run` | 공간 침투 | 기준점 + 전진 거리 × 위험 성향 × 자유도 |
| `press` | 압박 | 공 근처 예측 지점. 가까운 1~3명만 압박 후보가 됨 |
| `mark` | 대인 마크 | 가까우면서 자기 골문에 위험한 상대의 뒤쪽 |
| `recover` | 대형 복귀 | 포메이션 기준점 |
| `carry` | 공 운반 | 소유자의 전진·측면 목표 또는 공을 제어할 위치 |
| `keeper` | 골문 보호 | 골문 근처 + 공의 측면 방향에 대한 반응 |

대표적인 가중치 계산은 다음과 같다. 실제 식은 역할 보정, 피로, 거리, 현재 상태 유지 가중치도 적용한다.

```text
유효 자유도 = 선수 자유도 × 팀 자유도
대형 유지 = formationWeight × (0.25 + 규율 × 결속) × (1 + 대형 이탈 거리 / 35)
지원 = supportWeight × (0.2 + 예측 × 창의성) × (0.35 + 유효 자유도)
침투 = runWeight × 유효 자유도 × 팀 위험 성향 × 남은 체력 × 역할 보정
압박 = pressWeight × 팀 압박 × 적극성 × 공 접근도 × 남은 체력
마크 = markWeight × 규율 × 예측 × 역할 보정 × (1 - 팀 압박 × 0.3)
복귀 = recoverWeight × (대형 이탈 거리 / recoveryDistance - 1) × 규율 × 결속
선택 확률 = 해당 가중치 / 가능한 다음 상태의 가중치 합
```

포메이션 기준점은 적용 대형, 소유권에 따른 전진·후퇴, 감독의 수비선, 공 방향으로의 약한 이동을 합한다. 공으로의 이동은 기준점의 작은 보정이다. 선수 모두가 공에 붙는 것을 막기 위해 지원은 측면 위치를 유지하고, 압박 인원을 제한하고, 선수 사이의 분리 힘을 적용한다.

## 공과 소유권의 상태 기계

공은 임의의 화면 좌표로 움직이지 않는다. 현재 소유자를 따라 운반되며, 실제 선수의 위치로 패스한다. 패스 받을 선수도 예측 도착 지점으로 이동해 공이 도착하고 제어 거리 안에 들어오면 소유자가 된다.

```text
restart → possession → pass → possession
possession / pass → transition → possession
possession / pass → shot → restart
shot → possession  (골키퍼가 선방한 공을 잡았을 때)
```

`transition`은 소유권이 바뀌는 상황, `restart`는 득점·슈팅 이후의 재개다. 새 단계에서도 공의 이전 위치를 유지하고 제한된 속도로 이동하므로 경기 분 경계에서 순간 이동하지 않는다. 이벤트에 슈팅이 있을 때만 골문 방향 비행을 만든다. 골·슈팅·선방의 최종 결과와 득점자는 기존 이벤트 기록을 따른다.

패스 대상은 거리 적합도, 상대와의 간격, 전진 가치, 받을 선수의 예측, 지원·침투 상태로 가중 선택한다.

```text
선호 거리 = passRange + 패스 능력 × passingRange
거리 적합도 = exp(-abs(실제 거리 - 선호 거리) / 선호 거리)
공간 가치 = 0.3 + clamp(가장 가까운 상대까지 거리 / pressureRadius, 0, 1) × spaceWeight
전진 가치 = exp(clamp(전진 거리 / 30 × 팀 위험 성향 × progressWeight, -1, 1))
패스 대상 가중치 = 거리 적합도 × 공간 가치 × 전진 가치 × (0.5 + 예측) × 상태 보정
받을 위치 = 선수 위치 + 선수 속도 × 예상 비행 시간 × 예측 × receiverAnticipation
```

한 경기 분의 통계 이벤트와 패스 비행 전체는 서로 다른 해상도다. 현재 움직임은 확정된 사건을 일관되게 보여 주는 관전 모델이다. 이후 위치 기반 득점 모델을 도입할 때는 이 상태·위치 정보를 결과 엔진에 연결하되, 관전 여부가 결과를 바꾸지 않도록 같은 seed 경로를 사용해야 한다.

## 이동 안정성과 조정 순서

모든 선수의 의도를 먼저 계산한 뒤 위치를 함께 적분한다. 배열 앞쪽 선수가 먼저 움직여 뒷선수에게 영향을 주지 않는다. 목표 속도는 도착 거리에 따라 줄고, 가속도와 최대 속도를 제한한다. 선수는 필드 경계 안에 머물며 목표에는 경계 여유를 둔다. 공도 속도가 제한된다.

1. `decisions`의 유지 시간, 판단 빈도, 상태 유지 가중치로 반전 빈도를 먼저 조정한다.
2. `tactics`와 `manager`로 팀별 차이가 보이는지 조정한다.
3. `formationWeight`, `recoverWeight`, `formationPull`, `roamDistance`로 대형과 자유도의 균형을 맞춘다.
4. `possession`의 패스 간격, 거리, 공간·전진 가중치로 공의 흐름을 조정한다.
5. `maxSpeed`, `acceleration`, 분리 반경으로 이동 속도와 밀집을 조정한다.

`motion.test.ts`는 같은 seed의 재현성, 빠른 처리와 관전의 기록 일치, 위치·속도·가속도·공의 연속성, 22명의 서로 다른 판단, 전술·감독에 따른 압박·대형 차이를 검증한다. 계수를 바꿀 때 이 조건을 유지하고 여러 전술의 실제 관전을 함께 확인한다.
