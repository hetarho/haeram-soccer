# 캐주얼 클럽 키우기 개선 가이드라인

목표는 쉽게 시작하고, 클럽의 성장을 즐기며, 선수·전술·육성·재정을 잘 조합해야 높은 성과를 내는 게임이다. 앱스토어 순위와 실제 재미는 배포·사용자 플레이테스트가 필요한 외부 성과이며, 아래 제품 기준과 구분한다.

## 재미와 전략

- 핵심 루프: 목표 확인 → 빌드 선택 → 경기 → 결과와 성장 확인 → 다음 선택. 기본 경기 시작은 한 번의 조작이다.
- 최소 네 전술이 선수 능력·상대·피로에 따라 달라진다. 모든 상황에서 우월한 전술은 두지 않는다.
- 최강 선발과 휴식 선발은 한 번의 선택으로 준비하고, 상세 선수 교체는 선택 사항이다.
- 육성은 미래 성장과 당장 경기 준비 사이의 선택이다. 투자·영입은 즉시 비용과 반복 비용을 함께 공개한다.
- 성장과 목표 달성은 실제 선수·경기·구단 기록으로 계산한다. 장식용 숫자·가짜 보상·무작위 재추첨을 쓰지 않는다.
- 결과에서 실제 득점·슛·패스 등의 근거와 다음 행동을 볼 수 있어야 한다. 승리 보장 수치는 표시하지 않는다.

## 모바일 화면

- 기준 뷰포트: 360×740, 390×844 CSS px. 기본 홈과 기본 관전 화면은 문서 세로·가로 스크롤 없이 핵심 정보를 보여준다.
- 홈에는 현재 목표, 클럽의 성장 모습, 핵심 자원, 다음 상대, 다음 경기 버튼이 함께 보인다.
- 관전에는 점수, 경기장, 최신 사건, 재생·속도·결과 조작이 함께 보인다. 통계와 선수 판단은 선택해서 연다.
- 기본 조작은 44px 이상의 터치 영역, 읽을 수 있는 대비, 키보드 포커스, 모션 감소 설정을 지원한다.
- 선수 목록·시장·순위표·역사·고급 설정은 필요한 상세 탐색이므로 내부 목록 또는 별도 화면의 스크롤을 허용한다. 필수 행동을 긴 목록 아래에 두지 않는다.
- 하단 메뉴는 엄지로 접근 가능하며 안전영역을 존중한다. 대화창은 포커스·닫기·조작 중 자동 진행 중지를 보장한다.

## 연속성

- 기존 저장은 유지되고, 새 선택은 저장·재시작 후 이어진다.
- 같은 시드·명령은 같은 결과다. 관전과 빠른 진행은 결과가 같다.
- 실패·다른 탭·필수 알림에서 자동 진행은 멈추며 저장을 덮어쓰지 않는다.
- 각 사이클은 검토·기획/디자인 → SSOT 개정 → 태스크 → 구현·검증 순서로 기록한다. 최소 10회 완료 후 위 기준을 다시 검사하고 실패한 기준은 추가 사이클로 해결한다.

## 검증 근거

각 사이클 기록: `docs/iterations/`. 현재 규칙: `spec/ssot/`. 완료 태스크: `spec/tasks/done/`. 최종 기계 검증과 화면 증거는 개선 보고서에 기록한다. 재미·난이도 균형의 최종 사용자 검증은 별도로 남긴다.
