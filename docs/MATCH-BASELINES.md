# 실제 축구 기준값 (경기 엔진 개편용, 2026-10-19)

격자 칸 엔진 개편(spec/ideation/match-engine-rebuild.md)의 확률표와 보정 목표에 쓸 실제 경기 통계와 공간 용어를 모았다. 판단 기준이 아니라 **참고 자료**다. 무엇을 목표로 삼을지는 SSOT(MATCH)가 정한다.
