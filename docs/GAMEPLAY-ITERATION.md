# 시즌을 따라가는 재미와 선수 판단

이번 변경은 사용자가 요청한 순위 경쟁, 진행 속도, 독립적인 선수 움직임을 우선한다.

- 클럽 일지에서 순위 변동, 승격선/강등선과 승점 차, 최근 5경기, 다음 상대와 결과별 승점을 확인한다.
- 리그에서 라운드별 순위 그래프를 비교하고 같은 라운드의 전체 경기 결과를 읽는다. 지난 시즌의 순위 기록은 저장된 시즌을 선택한다.
- 관전 뒤에도 리그 현황과 순위표가 이어진다. 재생, 시간 이동, 결과 확인, 다시 보기가 가능하다.
- 장식용 축구장 SVG를 없애고 클럽 색을 작은 표식으로 표현한다. 경기장과 데이터 그래프는 필요한 곳에만 사용한다.
- 자동 진행은 1초에 1일, 1초에 3일, 1초에 다음 우리 경기의 세 단계다. 진행이 느릴 때 명령을 쌓지 않는다. 관전 탭에서는 경기 종료를 기다린 뒤 다음 경기를 바로 시작한다. 통계 탭에서는 날짜 진행을 이어가며 중요한 알림, 저장 오류와 경기 준비는 진행을 멈춘다.

선수 움직임의 계산식과 조절할 계수는 [MATCH-MOTION.md](MATCH-MOTION.md), 날짜/일정/저장 규칙은 [SEASON-PROGRESSION.md](SEASON-PROGRESSION.md)에 정리한다. 실제 관전의 **선수 판단 보기**에서 현재 행동, 성향과 목표 위치를 확인할 수 있다.

- [선수별 움직임 분리](https://github.com/hetarho/soccer_simulator/commit/dd8fa610e3777be5971b2d3542ec1a07981fac36), [볼을 가진 선수와 나머지 선수](https://github.com/hetarho/soccer_simulator/commit/55ecf42c5656dd9567f4764194e611c9bf4dac09): 개인 판단과 팀 형태를 함께 보이게 한다.

## 검증

엔진 검증은 같은 시드의 결과 일치, 이동 범위와 연속성, 선수별 판단 차이, 감독/전술 영향, 날짜 진행 방식 간 결과 일치, 저장 복원, 라운드별 순위와 승강권 계산을 확인한다. 브라우저 검증은 세 진행 속도와 정지/복원, 선수 선택, 재관전, 경기 뒤 순위표, 모바일 화면을 확인한다.

2026-10-07 로컬 검증: 타입·린트·포맷·카탈로그·프로덕션 빌드, 단위 테스트 59개, 계약 테스트 5개, Chromium/Firefox/WebKit의 브라우저 테스트 39개 통과. 관전 중 순위표는 숨기고 종료 후 표시하는 흐름도 브라우저에서 확인한다.

별도의 장기 저장 확인은 `release-century-baseline` 시드로 100시즌을 진행했다. 저장 크기는 보수적인 UTF-16 계산으로 1,458,298바이트이며 1,572,864바이트 한도 이내였다. 순위 스냅샷 424개를 포함해 저장 후 복원한 전체 세계가 원본과 정확히 일치했다. 빠른 시즌 진행에서는 관전 계산을 생략해 같은 전체 결과를 유지한다. 이 측정은 해당 시드/시나리오의 결과다.


## 실시간 탭과 모바일 개입 (2026-10-08)

날짜를 처리할 때 로딩·중단 행을 매번 삽입하고 저장 검증의 복제된 세계가 화면을 다시 덮어쓰던 경로를 수정했다. 전역 진행 컨트롤러와 외부 상태 저장소를 사용하며 화면은 필요한 상태만 구독한다. 경기·순위표·순위 추이·득점 순위·득점왕 추이·전술/선발·일정 탭은 계속 마운트해 캔버스와 선택 상태를 유지한다. 탭 선택은 URL에 남겨 새로고침 후에도 복원한다.

관전 중에는 날짜 간격으로 새 경기를 덮어쓰지 않는다. 현재 경기 종료 신호를 받은 뒤 다음 경기를 바로 시작한다. 통계 탭에서는 기존 날짜 속도를 사용한다. 같은 관전을 다시 재생하거나 멈추면 그 재생이 끝날 때까지 기다린다.

득점 순위는 현재 우리 리그의 모든 선수의 실제 경기 득점으로 집계하며 라운드별 누적 득점/순위 추이를 저장한다. 이전 저장은 새 추적을 시작한 라운드를 표시하고 과거 상대 득점을 만들어 넣지 않는다.

경기 준비에서 11명을 직접 선택하거나 전력/피로 중심으로 추천받고 감독에게 전술을 요청한다. 실제 적용과 조건부 요청을 구분하며 선발 전력, 공격수 마무리와 골키퍼 능력이 실제 다음 경기 계산에 들어간다. 이미 기록된 현재 경기는 다시 계산하지 않는다.

모바일은 하단 탐색, 48px 터치 영역, 안전 영역, 가로 표의 독립 스크롤을 사용한다. 모달은 고정된 헤더/주요 행동과 스크롤 가능한 본문을 가진 시트로 표시한다. 포커스, Escape, 배경 스크롤 잠금, 닫은 뒤 위치와 초점 복원을 검증한다. 경기 준비의 저장 버튼도 본문 스크롤과 독립적으로 보인다.

재정 모델은 [FINANCES.md](FINANCES.md)에 정리했다. 후원금은 실제 리그 경기마다 분할 지급하며 승리/무승부 수당, 후원 성과 보너스, 최종 순위 상금, 관중 수요, 급여/시설/경기 개최비를 실제 장부로 표시한다. 구단주 출자는 운영 매출과 별도로 표시하며 자동으로 지급하지 않는다.

2026-10-08 검증: 전체 `verify` 통과. 단위 테스트 125개, 계약 테스트 5개, Chromium/Firefox/WebKit 브라우저 테스트 69개가 통과했다. 자동 진행 중 로딩 표시가 나타나지 않는 것, 탭 변경 시 캔버스 동일성, 경기 종료 후 즉시 다음 경기 연결, 모바일 선발 저장/복원, 모달의 포커스/스크롤/확인 버튼, 저장 실패와 복구를 포함한다. 새 장부와 득점 기록을 포함한 100시즌+23라운드 기본/적극 운영 데이터는 모든 기록을 유지하면서 각각 1,501,246/1,564,832바이트로 기존 1,572,864바이트 한도에 들어갔고 전체 세계 복원 결과가 원본과 일치했다.
